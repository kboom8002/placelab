# kplacelab

**지자체 AI 응답 측정 플랫폼**

전국 243개 지방자치단체와 자체 도메인을 가진 특별구역에 대해, 생성형 AI가 **무엇이라고 답하는지**를 측정하고 그 변화를 시계열로 추적하는 웹 플랫폼.

- 자동 수집으로 **편향 없는 기준선**을 만들고
- 자발적 참여로 **실제 질문**을 모은다.

이 두 가지는 성격이 다른 데이터이며, **절대 섞지 않는다.**

---

## 이 제품이 존재하는 이유

공공 도메인의 상당수가 AI 수집기에 닫혀 있다. 주민이 AI에 행정정보를 물었을 때 오답으로 실제 피해가 발생했는지에 대한 독립 증거는 아직 없다. 정부·지자체가 이를 공식 지표로 제도화한 사례도 없다.

즉 **"AI 응답 부정확이 행정적으로 중요한 문제인가"는 아직 증명되지 않은 가설이다.** 이 플랫폼의 1차 목적은 상품 판매가 아니라 **그 가설의 검증**이다. 검증에 실패한다면 — 즉 측정 결과가 대체로 양호하거나 참여자가 문제의식을 갖지 않는다면 — 유료 상품 라인 전체를 재검토해야 한다. 그 판단을 6개월 안에 데이터로 내리는 것이 이 제품의 존재 이유다.

---

## 무엇이 다른가

인접 영역에 선행이 있다. LLM의 지역 지식을 재는 학술 벤치마크(LocalBench, CitizenQuery-UK), `robots.txt` 수집 제한을 감사한 연구(Consent in Crisis), 브랜드 AI 가시성 SaaS, 정부 AI 준비도 지수. **개별 요소는 거의 전부 선행이 있다.** → [`K11`](./docs/knowledge/K11-prior-art-positioning.md)

다른 것은 **측정의 방향**이다.

| | 학술 벤치마크 | kplacelab |
|---|---|---|
| 측정 대상 | 모델 | **기관** — 모델은 측정 도구 |
| 산출 | 리더보드 | 리더보드 **금지** · 상태 표시 |
| 시간 | 정적 1회 | 주간 시계열 · 개입 전후 |
| 절차 | 불필요 | 사전통지 · 정정 · 설명 게재권 **필수** |
| 실패의 의미 | 모델 점수가 낮다 | **주민 한 명이 헛걸음한다** |

> **"모델을 재는 벤치마크가 아니라, 기관을 재는 운영 서비스."**

측정 대상이 실명 공공기관이라는 사실이 제품을 규정한다. 통지·정정·설명 게재권은 불편이 아니라 **진입장벽**이다.

**해자는 방법론이 아니다.** 방법론은 전면 공개하며(FR-8), 그것은 신뢰의 조건이자 해자의 파괴자다. 지킬 수 있는 것은 **시계열·기관 관계·인용 지위** 셋뿐이고, 셋 다 시간이 만든다. 따라서 이 사업의 유일한 전략 변수는 **속도**다. → [`ADR-0008`](./docs/adr/0008-moat-is-time.md)

그중 **인용 지위**는 개념 선점으로 만들어진다. 이름을 먼저 붙이는 쪽이 시장을 갖고, 두 번째로 붙인 쪽은 첫 번째가 만든 언어 안에서 말하게 된다. 주력 프레임은 **「AI 응답 격차」** 이며, 표현을 변주하지 않는다. → [`K13`](./docs/knowledge/K13-diffusion-track.md)

**과학성은 해자가 아니라 탄약이다.** 공공기관 대상 수치가 한 번 정정되면 프레임은 회복되지 않는다. 확산이 목표이고, 엄밀성은 **계속 말할 수 있는 자격**이다.

## 세 개의 시계

| 시계 | 정의 | 선행 조건 |
|---|---|---|
| **C0** | 첫 칼럼 게재 — 개념 선점 개시 | **없음. 지금 가능하다** |
| **T0** | 243곳 첫 전수 스캔 개시 | 판정 규칙표 · 단위 마스터 · 강건성 파일럿 |
| **P0** | 첫 전수 결과 공표 | T0 + 2주 연속 + 사전 통지 완료 |

C0는 다른 둘을 기다리지 않는다. 다만 **개념만으로 끌 수 있는 것은 칼럼 두 편까지**이므로, 확산이 측정을 앞서 달리되 측정이 곧 따라붙어야 한다.

## 공개 표면 + 4개 측정 레이어

측정 스택의 구조는 **무엇을 자동화할 수 있고 무엇이 사람을 요구하는가**로 결정된다. 그 위에 측정하지 않는 층이 하나 더 있다.

| | 수집 | 편향 | 공개 | 과금 |
|---|---|---|---|---|
| **L0 공개 표면** | **없음** | — | 전면 | 무료 |
| **L1 기술 접근성** | 자동 · 전수 | **없음** | 전면 | 무료 |
| **L2 셀프체크** | 수동 · 자발 | 자기선택 | 집계만 | 무료 |
| **L3 통제 측정** | 자동 · API | 통제됨 | 기관 전용 | 연 300~600만원 |
| **L4 진단 · 정비** | 사람 | — | 발주기관 | 건당 1,200~2,000만원 |

**L0는 측정하지 않는다.** L1~L3의 결과를 사람이 남에게 보낼 수 있는 형태로 만든다 — 공유 카드, 지역 페이지, 프롬프트 팩, 인용 가이드, 보도 키트. 설계 기준이 다르다: L1~L3은 **타당도**, L0는 **전달성**. 그리고 **새 사실을 만들지 않는다** — 나르는 숫자는 이미 게이트를 통과한 것이어야 한다. → [`ADR-0010`](./docs/adr/0010-diffusion-first.md)

**L1이 이 제품의 발명이다.** 기술 접근성은 공개 정보이고 서버가 전수 자동 수집할 수 있으므로, 자기선택 편향 없이 *"전국 243곳 중 N곳이 AI 수집기에 닫혀 있다"* 고 말할 수 있는 유일한 층이다. 나머지 세 레이어는 이 문장이 만든 관심 위에서 작동한다.

반대로 **L2의 점수를 전국 통계처럼 쓰면 방법론 전체가 무너진다.**

## 시작하기

```bash
pnpm install
cp .env.example .env.local        # 값은 docs/SDD.md §11 참조
pnpm supabase start               # 로컬 Postgres + Studio
pnpm db:reset                     # 마이그레이션 + 시드(단위 마스터)
pnpm dev
```

시드는 `supabase/seed/` 의 단위 마스터 CSV를 읽는다. 마스터의 출처와 갱신 규칙은 [`docs/knowledge/K02-units-taxonomy.md`](./docs/knowledge/K02-units-taxonomy.md).

## 이 저장소에서 하지 않는 것

- 지자체 **순위표·등급 산출**
- AI **노출·인용 보장**을 시사하는 문구
- AI **응답 원문의 대외 공개·재배포**
- 자발적 표본으로 만든 **"전국 평균"**
- **강건성 검사를 통과하지 않은 문항의 결과 공표**
- **Floor Risk 없이 평균 정확도만 제시**
- **사전 등록 없는 측정 결과 공표**
- **"세계 최초 · 국내 유일" 류의 표현**
- 지자체 누리집 콘텐츠의 **크롤링·복제**
- 수집 **차단의 우회**

이유는 [`docs/PRD.md` §02 비목표](./docs/PRD.md)에 있다. 이것들은 "나중에 한다"가 아니라 **하지 않는다.**
