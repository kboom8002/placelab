# 제주특별자치도 글로벌 AI 가시성 심화 진단 보고서
## — 고급 관광·외국인 투자유치(FDI)·출처 채널 전수 분석

> **조사 대상**: 제주특별자치도 (`lg-50000`)  
> **조사 범위**: 영문 1차(35문항) + 2차 심화(45문항) = **총 80문항 × 3회 = 240회 실측 전수 분석**  
> **핵심 주제**: 럭셔리 관광(5성급·골프·MICE·미식) / 외국인 투자유치(FDI·JDC·부동산이민) / 118개 인용 도메인 채널 기여도  
> **측정 모델**: `gpt-5.6-luna` (Global Server Baseline)  
> **발행**: (주)디지털미디어네트워크 · K Place Lab 연구팀  
> **일시**: 2026년 9월
