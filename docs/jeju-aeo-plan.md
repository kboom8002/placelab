## 1. 추진 배경 및 행정단위 구조적 특성

### 1.1 왜 제주도는 특별한 AEO 측정 모델이 필요한가?
일반적인 시·군·구 기초자치단체(예: 수원시, 화성시)는 정주민 중심의 생활민원 행정이 중심축을 이룹니다. 반면 제주도는 **연간 1,300만 명 이상의 내외국인 관광객이 유입되는 글로벌 관광지**이자, **70만 제주도민이 정주하는 특별자치도**입니다.

현재 생성형 AI(ChatGPT, Gemini, Claude, Perplexity 등)는 관광객과 도민이 제주에 대한 정보를 얻는 최우선 창구로 급부상하고 있습니다. 그러나 AI가 제공하는 정보는 다음과 같은 치명적인 문제를 안고 있습니다:
1. **제도 변경 미인지**: '새별오름 들불축제 불놓기 폐지', '출산지원금 5년/9년 분할 개편', '2035 탄소중립' 등 최신 정책 변화를 반영하지 못하고 과거 정보 반복
2. **부정 평판의 증폭 및 작화**: '비계 삼겹살', '입도세(환경보전분담금 1만원) 부과 루머' 등 온라인 상의 자극적 논란을 AI가 사실로 왜곡 생성(Confabulation)
3. **공식 출처 단절**: 공공 1차 출처(`jeju.go.kr`, `visitjeju.net`) 대신 부정확한 바이럴 블로그나 오래된 여행 카페 글을 주로 인용

### 1.2 광역 도정 vs 행정시의 2원적 사무 분장 (INV-1 절대 불변식 준수)
kplacelab의 핵심 원칙인 **INV-1(모집단 합산 금지)** 및 행정 분류 규격(`K02-units-taxonomy.md`)에 따라, 제주도의 특수한 2원적 구조를 엄격히 분리하여 측정합니다:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   제주특별자치도 (광역 자치단체 lg-50000)                   │
│  - 권한: 도정 비전, 조례 제정, 산업 육성, 에너지·기후 정책, 광역 교통망        │
│  - 누리집: www.jeju.go.kr / 관광: www.visitjeju.net                    │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 사무 분장 및 집행
            ┌───────────────────────┴───────────────────────┐
            ▼                                               ▼
┌───────────────────────────────┐   ┌───────────────────────────────┐
│     제주시 (행정시 admin_city)  │   │    서귀포시 (행정시 admin_city) │
│ - 권한: 기초 생활행정, 폐기물 수거│   │ - 권한: 기초 생활행정, 폐기물 수거│
│   민원실, 보건복지 전달체계       │   │   민원실, 보건복지 전달체계       │
│ - 누리집: www.jejusi.go.kr    │   │ - 누리집: www.seogwipo.go.kr  │
└───────────────────────────────┘   └───────────────────────────────┘
```

- **측정 및 집계 분리 원칙**: 광역 단위 정책(예: 2035 탄소중립, UAM, 입도세 입장)과 행정시 단위 집행(예: 제주시 클린하우스 수거, 서귀포시 목욕바우처)을 질문 수준에서 태깅(`unit_scope: province_wide | jejusi | seogwipo`)하여 혼선을 차단합니다.
- **순위화 배제(INV-3)**: 제주시와 서귀포시 간, 또는 제주도와 육지부 시·도 간의 '점수 순위'를 매기지 않고, 객관적 정합성 및 가시성 지표로만 진단합니다.

## 2. 5대 특화 측정 축 및 핵심 가설

제주도 AEO 진단은 표준 지자체 3-Tier를 발전시킨 **5대 특화 축(Total 90문항)**으로 구성됩니다.

| 측정 축 | 대상 영역 | 문항 수 | 주 대상 페르소나 | 핵심 가설 |
|---|---|---|---|---|
| **축 1. 기본 행정·생활복지** | 요일별배출제, 탐나는전, 출산·양육, 어르신/청년, 민원실 | 20문항 | 정주민, 영유아 부모, 청년, 어르신 | 도민 생활 밀착 정보 중 수치(지원금, 요금) 및 요일제 변경 정보의 AI 오류율이 30%를 상회할 것이다. |
| **축 2. 관광·체류·문화** | 사계절 명소, 올레길, 들불축제, 대중교통, 향토미식 | 25문항 | 내외국인 관광객, 미식가, 도보여행자 | 최신 축제 개편(들불축제 불놓기 폐지)과 예약제(한라산) 등 최신 제도에 대한 구버전(stale) 응답이 다수일 것이다. |
| **축 3. 미래 신산업·청정에너지** | 2035탄소중립, 그린수소, 분산에너지, UAM, 우주산업 | 15문항 | 기업·투자자, 산업분석가 | 미래 먹거리 신산업 정보에서 제주도의 선도적 실증 정책이 AI에 거의 학습되지 않았을 것이다(가시성 결여). |
| **축 4. 정주·이주·인프라** | 귀농귀촌, 렌터카총량제, BRT, 국제학교, 의료(닥터헬기) | 15문항 | 전입희망자, 학부모, 정주민 | 렌터카 총량제, 영어교육도시, 상급종합병원 부재 등 제주 특유의 인프라 이슈가 왜곡되어 전달될 것이다. |
| **축 5. 위기·오버투어리즘·평판** | 바가지요금, 비계삼겹살, 입도세 루머, 가짜뉴스 탐지 | 15문항 | 전국민, 잠재 관광객, 언론 | '입도세 징수', '렌터카 전면금지' 등 온라인 괴담에 대해 AI가 반박하지 못하고 동조(작화)할 위험이 높을 것이다. |

## 3. 프로브 질문 세트(90문항) 및 Ground Truth(32건) 설계 명세

### 3.1 파일 아키텍처
모든 질문과 기준 데이터는 `docs/` 디렉토리 하위에 표준 JSON 규격으로 저장되어 자동 측정 엔진(`measure-3tier.ts`)과 호환됩니다:

- `docs/aeo-questions/jeju-axis1-admin.json` (20문항)
- `docs/aeo-questions/jeju-axis2-tourism.json` (25문항)
- `docs/aeo-questions/jeju-axis3-industry.json` (15문항)
- `docs/aeo-questions/jeju-axis4-residence.json` (15문항)
- `docs/aeo-questions/jeju-axis5-reputation.json` (15문항)
- `docs/ground-truth/jeju.json` (32건 공공 1차 팩트 데이터베이스)

### 3.2 핵심 프로브 질문 상세 예시 (발췌)

#### [축 1: 생활민원] 요일별 배출제 및 출산지원금
```json
{
  "id": "JJ-A1-01",
  "tier": "T1",
  "category": "waste_system",
  "body": "제주도 생활폐기물 재활용품 요일별 배출제 시간과 버리는 방법 알려줘",
  "targetKeywords": ["제주도", "요일별 배출제", "클린하우스", "15시", "오후 3시"],
  "unit_scope": "province_wide",
  "persona": "resident"
}
```

#### [축 3: 미래 신산업] 하원테크노캠퍼스 민간우주산업
```json
{
  "id": "JJ-A3-06",
  "tier": "T2",
  "category": "space_industry",
  "body": "서귀포 하원테크노캠퍼스 도시첨단산업단지에 입주하는 우주산업 기업과 개발 방향은?",
  "targetKeywords": ["하원테크노캠퍼스", "한화우주센터", "민간우주산업", "옛 탐라대 부지"],
  "unit_scope": "seogwipo",
  "persona": "investor"
}
```

#### [축 5: 가짜뉴스 탐지] 환경보전분담금(입도세) 작화 테스트
```json
{
  "id": "JJ-A5-04",
  "tier": "T3D",
  "riskCategory": "confabulation_test",
  "body": "현재 2026년에 제주도에 도착하면 공항이나 항만에서 환경보전분담금을 실제로 징수하고 있어?",
  "targetKeywords": ["환경보전분담금 미시행", "입도세 미징수", "공항 징수 안함"],
  "unit_scope": "province_wide",
  "persona": "tourist"
}
```

### 3.3 Ground Truth(GT) 구축 기준 (32건)
제주특별자치도청, 제주시, 서귀포시, 제주관광공사(VisitJeju), 제주개발공사(JPDC) 등의 공식 공고 및 자치법규를 교차 검증하여 정답셋을 구축하였습니다.

```json
{
  "id": "GT-JJ-27",
  "category": "policy_factcheck",
  "field": "환경보전분담금(입도세) 징수 현황",
  "value": "2026년 9월 현재 환경보전분담금은 징수되지 않고 있으며(사실무근), 경기침체 및 관광여건 고려해 도입 잠정 보류 상태",
  "acceptableVariants": ["현재 징수 안함", "미징수", "도입 유보/보류 상태", "입도세 없음"],
  "errorType": "procedure",
  "source": "제주특별자치도 기후환경국 공식 입장",
  "verifiedBy": "jeju.go.kr"
}
```

## 4. 평가·분석 지표 체계 및 다차원 진단 매트릭스

### 4.1 지표 산식 (DIR-01 가이드라인 준수)

1. **T1 응답률 (Response Rate)**
   $$\text{응답률} = \frac{\text{판정 불가가 아닌 유효 응답 수}}{\text{총 질문 수} \times \text{반복 횟수}} \times 100\%$$
2. **T1-V 사실 정확률 (Fact Accuracy Rate)**
   $$\text{사실 정확률} = \frac{\text{GT와 완전히 일치(correct)한 문항 수}}{\text{검증 대상 문항 수}} \times 100\%$$
   *(오류 유형: `numeric` 수치 오차, `outdated` 구버전 답습, `confabulated` 작화)*
3. **T3 점유율 (Share of Voice)**
   $$\text{SoV} = \frac{\text{무지명 추천/연상 질문 중 '제주'가 언급된 횟수}}{\text{전체 T3 질문 횟수}} \times 100\%$$
4. **공식 출처 인용률 (Canonical Citation Rate)**
   $$\text{공식 인용률} = \frac{\text{답변 내 } \text{*.go.kr} \text{ 또는 visitjeju.net 링크가 인용된 횟수}}{\text{총 질문 횟수}} \times 100\%$$
5. **Floor Risk (최저 위험도 판정)**
   - `critical`: AI가 허위 제도나 가짜 논란을 단정적으로 생성한 경우 (예: "입도세 1만원이 현재 부과되고 있다")
   - `high`: 구버전 정보로 인해 금전적·시간적 피해를 초래하는 경우 (예: 요일별 배출 시간 틀림, 지원금 수백만원 축소)
   - `low`: 경미한 뉘앙스 차이

### 4.2 다차원 진단 매트릭스 (경쟁 및 대체지 분석)
- **국내 경쟁(T3-C)**: 강원도(강릉/속초), 부산과의 여름 휴가/미식 여행 추천 경합 시 AI의 추천 우위 분석
- **해외 경쟁(T3-C)**: 일본(후쿠오카, 오키나와) 대비 '가성비/만족도' 프레이밍에서 AI가 제주도를 어떻게 묘사하는지 추적

## 5. 도정·시정 정책 사후 활용 및 액션 플랜

측정 결과는 단순한 리포트에 그치지 않고, 제주도청 및 양 행정시가 즉시 실행할 수 있는 **비용 0원 ~ 단기 조치**로 연계됩니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   AEO 측정 결과 기반 도정 개선 3단계 로드맵                │
├────────────────────────────────────────────────────────────────────────┤
│ 1단계: 즉시 조치 (D+7, 비용 0원)                                        │
│   - 도청/행정시 공식 누리집 메타태그 및 robots.txt, sitemap.xml 개방 상태 정비│
│   - '입도세 미시행', '요일별 배출 요령' 공식 FAQ JSON-LD 구조화 마크업 삽입    │
│                                                                        │
│ 2단계: 단기 정책 브랜딩 (D+30)                                           │
│   - 비짓제주(VisitJeju) 내 '새별오름 들불축제 친환경 미디어아트 개편' 공식 팩트│
│   - 흑돼지 품질관리 매뉴얼(지방 1cm 기준) 등 안심식당 데이터셋 오픈API 제공    │
│                                                                        │
│ 3단계: 신산업 및 미래 비전 전파 (D+90)                                  │
│   - '2035 탄소중립', '하원테크노캠퍼스 한화우주센터', '제주 UAM' 영/한 브리핑   │
│   - 글로벌 AI 검색 엔진이 크롤링하기 쉬운 시맨틱 지식 그래프(Knowledge Graph)구축│
└────────────────────────────────────────────────────────────────────────┘
```

### 결론
본 계획에 따라 90문항 × 3회(270회) 실측을 가동할 경우, **제주특별자치도 도정의 혁신 정책이 AI 세상에서 얼마나 정확하게 전달되고 있는지**, 그리고 **제주 관광의 치명적 오해(바가지, 입도세 등)가 어디서 확산되고 있는지**를 정량적 데이터로 규명할 수 있습니다.
