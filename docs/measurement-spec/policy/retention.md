# 보존과 공표 시기

## 1. 보존

| 대상 | 방침 |
|---|---|
| 응답 원문 | **전량 보존.** 요약본으로 대체하지 않음 |
| 회차별 응답 | 전부 보존. 대표값 하나만 남기지 않음 |
| 거절·오류 응답 | 보존. 결측 처리하지 않음 |
| 수집 로그 | 로봇 규칙 확인 결과 포함해 보존 |
| 관측 조건 | 판본 단위로 고정해 보존 |
| 원장 사본 또는 그 소재 | 판정의 근거이므로 보존 |

재현 자료로 납품해야 합니다. 용량을 이유로 원문을 지우지 마십시오.

## 2. 익명 원자료

`channel: anonymized_dataset`로 나가는 자료에서:

- 기관은 손잡이로만 표기합니다
- **동류 집단과 계열을 동시에 넣을 때 조합 크기를 확인합니다.**
  `min_cell_size` 미달 조합은 제외합니다. 좁은 조합에서는 익명화가
  무의미해집니다
- 개별 확장·역점사업 지번을 넣지 않습니다
- 민감도 `restricted` 문항을 넣지 않습니다

## 3. 공표 시기

### 3.1 사전 통지

**사전 통지와 확인 기간을 거치지 않은 결과를 공표하지 않습니다.**

```
관측 종료
  → 기관별 통보 (notified_at)
  → 확인 기간 (기관이 정정 요청할 수 있는 기간)
  → 확인 기간 종료 (review_closed_at)
  → 공표
```

`output` 스키마가 전국 공표문에 대해 두 시각을 필수로 요구합니다.
파이프라인에서도 막으십시오.

### 3.2 선거 구간

**지방선거일 전 6개월 구간에는 전국 공표를 하지 않습니다.**

제9회 전국동시지방선거는 2026년 6월 3일에 치러졌고, 다음 지방선거는
2030년 6월입니다. 따라서 다음 제한 구간은 2029년 12월경부터 열립니다.

```
2026-07 ~ 2029-11   전국 공표 가능 구간
2029-12 ~ 2030-06   전국 공표하지 않음
```

기관별 통보서는 이 구간에도 나갈 수 있으나, 통보서가 홍보물로 전용되지
않도록 재사용 제한을 계약에 적어야 합니다.

> 공직선거법 관련 조문의 현행 자구와 일수는 인용 전에 국가법령정보센터에서
> 대조해야 합니다. 우리가 참조한 자료는 게시 시점이 오래되었습니다.

## 4. 정정

공표 후 오류가 확인되면 조용히 고치지 않습니다.

```
정정 사실을 판본에 남기고, 정정 전 내용을 함께 보존합니다.
이미 통보한 기관에는 정정본을 다시 보냅니다.
```
