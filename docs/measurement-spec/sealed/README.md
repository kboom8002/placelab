# sealed — 산식이 들어가는 자리

이 디렉터리는 **버전 관리에 포함되지 않습니다**(`.gitignore` 참조).
여기에만 계산식·가중치·임계값·구간 경계가 들어갑니다.

`interface.md`가 이 모듈이 제공해야 하는 함수의 모양을 정의합니다.
인터페이스 문서와 이 안내만 저장소에 남고, 구현은 남지 않습니다.

## 왜 이렇게 하는가

출원 중인 사항의 공개 범위가 아직 확정되지 않았습니다. 공개된 자리에 적힌
산식은 되돌릴 수 없습니다. 변리사 검토가 끝나 공개 범위가 정해지면 그때
어디까지 저장소로 옮길지 다시 정합니다.

## 여기에도 적지 않는 것

- 새 지표의 **약칭**. 한글 서술명만 씁니다
- 기관 실명. 손잡이만 씁니다

## 배포

구현은 저장소 밖에서 관리하고, 실행 환경에 별도로 넣습니다.
배포 경로와 접근 권한은 운영 문서에서 정합니다.
