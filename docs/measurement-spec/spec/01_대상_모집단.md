# 01 대상과 모집단

## 1. 모집단

전국 기초자치단체 전수입니다. 표본을 뽑지 않습니다.

**기관 목록은 조사 기준일의 행정안전부 자료로 고정합니다.** 위키 문서나
과거 판본의 목록을 그대로 쓰지 마십시오. 통합·분리로 기관 수가 바뀝니다.

```
data/registries/population_frame.json 에
  - 기준일
  - 출처 문서명
  - 기관 목록 (손잡이, 표시명, 유형, 광역)
을 둡니다. 이 파일을 갱신하는 것이 판본을 여는 첫 작업입니다.
```

## 2. 손잡이

기관을 코드 안에서 가리킬 때는 **손잡이(handle)**를 씁니다. 실명 문자열을
레코드 안에 직접 넣지 마십시오. 공표 경로에서 익명화할 수 있어야 합니다.

```
handle    안정적인 식별자. 판본이 바뀌어도 유지
display   표시명. 공표 경로에서는 치환 대상
```

## 3. 동류 집단

비교는 동류 집단 안에서만 합니다.

```
동류 집단 = 유형 × 인구 구간
  유형     시 / 군 / 자치구
  인구 구간 3구간 (경계는 sealed 참조)
```

인구 구간의 경계값은 이 저장소에 적지 않습니다(README §0.1).
구현은 `sealed`가 제공하는 함수로 구간을 받습니다.

## 4. 계열

계열은 **공식 지정과 공표 통계로만** 배정합니다. 우리가 판단해서 넣지 않습니다.

`data/registries/archetype_assignment.json`에 계열마다 다음을 적습니다.

- 배정 근거 문서명
- 지정 주체
- 기준일
- 근거 확인 상태 (`confirmed` / `to_verify`)

`to_verify`인 계열은 **판본에 싣지 않습니다.** 근거를 확인한 뒤에 엽니다.

### 4.1 다중 소속

한 기관이 여러 계열에 속할 수 있습니다. 계열별로 독립 집계하고 합산하지
않습니다.

### 4.2 역추적 방지

계열 조합별 기관 수를 세어, 조합에 속한 기관이 적으면 그 조합의 결과를
공표하지 않습니다. 조합이 좁으면 익명화가 무의미해집니다.

```
data/registries/archetype_assignment.json 의
  min_cell_size 를 확인하고, 미달 조합은 공표 산출에서 제외합니다.
```

## 5. 문항 배정

```
기관 하나가 받는 문항
  = 공통 코어 전부
  + 소속된 각 계열의 계열 코어
  + (의뢰가 있는 경우) 개별 확장 · 역점사업 지번
```

공표 조사에는 **개별 확장과 역점사업 지번을 넣지 않습니다.**
입도가 맞지 않고, 전국 공표물이 선거 자료가 됩니다.
