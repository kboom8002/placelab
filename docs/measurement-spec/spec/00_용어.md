# 00 용어

용어를 먼저 맞춥니다. 아래에 없는 말은 문서와 코드에 쓰지 마십시오.
특히 **새 지표의 약칭을 만들지 마십시오.** 한글 서술명만 씁니다.

---

## 1. 대상

| 용어 | 뜻 |
|---|---|
| 기관 | 관측 대상이 되는 지방자치단체 한 곳 |
| 동류 집단 | 유형과 인구 구간이 같은 기관들의 묶음. 비교는 이 안에서만 |
| 계열 | 공식 지정으로 배정되는 기관의 성격 분류. 다중 소속 허용 |
| 역점사업 | 예산이 편성되고 소관이 지정된 개별 사업. **"공약"이라 쓰지 않음** |

## 2. 문항

| 용어 | 뜻 |
|---|---|
| 질문 필지 | 문항 하나가 차지하는 사실의 범위. 겹치지 않고 경계가 선언됨 |
| 지번 | 문항의 영속 식별자. 한 번 부여하면 바꾸지 않음 |
| 공통 코어 | 모든 기관에 같은 형태로 던지는 문항 |
| 계열 코어 | 같은 계열에 속한 기관에만 던지는 문항 |
| 개별 확장 | 한 기관 전용 문항. 기관 사이 비교에 쓰지 않음 |
| 값형 | 원장에 단일한 정답이 있는 문항 |
| 서술형 | 단일한 정답이 없는 문항. 상태로만 기록 |

## 3. 층위

"가시성"이라는 단일 용어를 쓰지 않습니다. 네 층으로 나누어 말합니다.

| 층 | 무엇을 보는가 |
|---|---|
| 접근성 | 기계가 그 자료에 닿을 수 있는가 |
| 판독성 | 닿은 자료를 기계가 읽어낼 형태인가 |
| 인용 | 답을 만들 때 무엇이 근거로 쓰였는가 |
| 정확 | 답의 값이 원장과 맞는가 |

## 4. 관측

| 용어 | 뜻 |
|---|---|
| 프록시 지표 | 조회 응답은 사용자가 실제로 보는 답과 같지 않음. 모든 산출에 이 선언을 붙임 |
| 응답 원문 | 조회로 받은 텍스트 전량. 요약해 저장하지 않음 |
| 본문 주소 | 응답 본문 안에 나타난 주소 |
| 근거 목록 | 응답이 별도로 제시한 출처 목록 |

본문 주소와 근거 목록은 **따로 셉니다.** 합치지 마십시오.

## 5. 판정

| 용어 | 뜻 |
|---|---|
| 무응답 귀책 | 답이 나오지 않은 이유의 분류 (`N1`~`N5`) |
| 부정합 | 답이 원장과 어긋난 형태의 분류 (`C0`~`C4`) |
| 난도 | 해당 사항을 확인하는 데 드는 품 (`D0`~`D3`) |
| 값의 성격 | 실측·추정·계획 가운데 무엇인가 |
| 확인되지 않음 | 자료가 없어 판정할 수 없는 상태 <!-- lint:allow-banned --> |

## 6. 격자

| 용어 | 뜻 |
|---|---|
| 질문과 주체의 격자 | 세로에 문항, 가로에 지역 안 공적 주체를 놓은 표 |
| 정본 부재 | 한 문항에 대해 지역 안 어느 주체도 발행하고 있지 않은 상태 |
| 부재의 귀속 | 그 사실을 실제로 바꿀 수 있는 주체를 지정하는 일 |
| 잔여 폭 | 여건을 고정한 뒤에도 남는 상태의 차이 |

## 7. 쓰지 않는 말

<!-- lint:allow-banned:start -->

| 쓰지 않는 말 | 대신 |
|---|---|
| 환각 | 어긋남 · 부정합 |
| 국가 표준 / 세계 최초 | (쓰지 않음) |
| 정합도 100% / 오류 0% | (수치 목표를 약속하지 않음) |
| 통계 · 평가 · 인증 | 조사 · 관측 · 확인 |
| 부존재 | 확인되지 않음 |
| 공약 | 역점사업 · 주요 투자사업 |
| 가시성 | 네 층위 중 해당하는 층의 이름 |
| 점수 · 등급 · 순위 | 상태 · 분위 밴드 |
