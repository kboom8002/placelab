# 04 판정 규칙

판정은 규칙으로만 합니다. 언어 모형은 추출까지입니다(`spec/03` §4.1).

---

## 1. 판정 결과는 셋뿐입니다

```
맞음              원장과 일치
어긋남            원장과 불일치 → 부정합 코드를 붙인다
확인되지 않음      판정할 자료가 없음
```

점수를 매기지 않습니다. 확인하지 못한 것을 없다고 단정하는 표현을 쓰지 않습니다
(`spec/00` §7의 대체어 표를 보십시오).

## 2. 답이 나오지 않은 경우 — 무응답 귀책

`data/codes/nonresponse_codes.json`

| 코드 | 이름 | 누구 몫인가 |
|---|---|---|
| `N1` | 기술 차단 | 기관. 구조적으로 해소 가능 |
| `N2` | 내용 부재 | 기관. 작업으로 해소 가능 |
| `N3` | 형식 미비 | 기관. 구조적으로 해소 가능 |
| `N4` | 경쟁 배제 | 기관 통제 밖 |
| `N5` | 엔진 회피 | 기관 통제 밖 |

`N4`·`N5`는 기관이 고칠 수 없습니다. **처방 목록에 올리지 마십시오.**
고칠 수 없는 문제만 잔뜩 적힌 진단서는 기관을 무력하게 만듭니다.

## 3. 답이 어긋난 경우 — 부정합

`data/codes/mismatch_codes.json`

| 코드 | 이름 |
|---|---|
| `C0` | 대조 불가 |
| `C1` | 값 불일치 |
| `C2` | 출처 부적절 |
| `C3` | 시점 어긋남 |
| `C4` | 대상 혼동 |

`C3`는 원장의 기준일과 답이 말하는 상태의 차이입니다. 역점사업에서
지배적으로 나타납니다.

`C4`는 같은 이름의 다른 대상을 말한 경우입니다. `N4`와 구분하십시오 —
`N4`는 우리 대상이 아예 밀려난 것이고, `C4`는 답은 나왔는데 다른 것을
말한 것입니다.

## 4. 난도

`data/codes/difficulty_codes.json`

| 코드 | 뜻 |
|---|---|
| `D0` | 무료 도구로 확인 가능 |
| `D1` | 공개 자료 대조로 확인 |
| `D2` | 반복 관측이 필요 |
| `D3` | 원장 열람이 필요 |

**`D0` 항목은 청구하지 않습니다.** 기관이 스스로 확인할 수 있는 것을
비용으로 청구하면 신뢰를 잃습니다. 산출물에는 넣되 `billable: false`로
표시합니다.

## 5. 값의 성격

`data/codes/value_nature.json`

```
measured   실측
estimated  추정
planned    계획
```

원장이 계획치라고 적고 있는 값을 실적처럼 판정하지 마십시오.
원장과 답이 모두 성격을 밝히지 않았다면 `C0`(대조 불가)입니다.

## 6. 판정하지 않는 경우

아래는 판정을 내리지 않고 그대로 기록만 합니다.

| 상황 | 표시 |
|---|---|
| 회차마다 답이 갈림 | `unstable: true` |
| 원장 자체가 낡아 있음 | `ledger_stale: true` |
| 서술형 문항 | 애초에 값 판정 대상이 아님 |
| 민감도 `restricted` | 판정하되 공표 경로에서 제외 |

## 7. 인과를 단정하지 않습니다

관측된 것은 상태이고, 그 상태가 왜 생겼는지는 관측 범위 밖입니다.

```
쓸 수 있는 문장   "이 문항에 대해 답이 나오지 않았고, 귀책은 N2입니다"
쓸 수 없는 문장   "기관이 관리를 소홀히 해서 답이 나오지 않습니다"
                "이 항목을 고치면 인용이 늘어납니다"
```

판정 레코드에 원인이나 효과 예측을 담는 필드는 없습니다.

## 8. 서술형 문항의 처리

서술형에는 값 판정을 하지 않습니다. 대신 격자에 기록합니다.

```
정본 발행 (published)     그 주체가 답이 될 사실을 발행하고 있음
부분 발행 (partial)       일부만 또는 간접적으로
해당 없음 (not_applicable) 그 주체의 소관이 아님
공란 (blank)              소관이나 발행하지 않음
```

**"해당 없음"과 "공란"을 반드시 구분하십시오.** 소관이 아닌 주체가 발행하지
않은 것은 결손이 아닙니다. 구분하지 않으면 격자가 온통 빈칸으로 보입니다.

행 판정:

```
모든 칸이 공란 또는 해당 없음  → 정본 부재
정본 발행이 하나 이상          → 발행됨
```

정본 부재인 행에는 귀속 주체와 계층을 부여합니다.

```
귀속 기준: 그 사실을 실제로 바꿀 수 있는 주체가 정본을 가진다
계층: direct(직접) / affiliate(산하) / partner(협력) / out_of_reach(통제 불가)
```

**빈칸의 개수를 세지 마십시오.** 목록으로만 산출합니다. `grid` 스키마에
개수 필드가 없고, 린트가 `empty_count` 계열의 키를 잡습니다.
