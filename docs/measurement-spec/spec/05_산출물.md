# 05 산출물

## 1. 산출 순서

**맨 앞에 무엇을 놓느냐가 이 조사의 성격을 정합니다.** 아래 순서를 바꾸지
마십시오. 화면 배치와 보고서 목차도 이 순서를 따릅니다.

```
1. 정본 부재 영역과 그 귀속      겹치지 않음
2. 서술형 개체의 실재·등록 상태   부분적으로만 겹침
3. 무응답 귀책 분포              겹치지 않음
4. 공적 출처가 근거로 쓰인 정도   겹침 — 앞에 내세우지 않는다
5. 여건 고정 후 잔여 폭          겹치지 않음
```

4번을 1번 자리에 놓으면 상용 도구의 열등한 복제품이 됩니다. 모형 수와
관측 주기에서 우리가 열세이기 때문입니다.

## 2. 만들지 않는 산출

`README §0.2`와 같습니다. 여기서는 구현상의 의미만 적습니다.

| 금지 | 스키마에서 |
|---|---|
| 총점 | `output`에 `total`·`score`·`weight` 키 없음 |
| 순위 | `rank`·`ranking`·`top_n` 키 없음 |
| 등급 | `grade`·`tier` 키 없음 |
| 빈칸 수 | `empty_count`·`blank_count` 키 없음 |
| 목표치 | `target`·`forecast`·`projected_*` 키 없음 |

`tools/validate.py`가 저장소 전체에서 이 키들을 검사합니다.
애플리케이션 코드에도 만들지 마십시오.

## 3. 분위 밴드

기관의 상대 위치는 밴드로만 표현합니다.

```
band       동류 집단 안에서의 구간
band_of    어느 동류 집단 기준인지
```

밴드의 경계값은 이 저장소에 적지 않습니다(README §0.1).
`sealed`가 밴드를 돌려주고, 산출 레코드는 그 결과만 담습니다.

밴드 안에서 다시 정렬하지 마십시오. 정렬하면 순위가 됩니다.

## 4. 세 갈래 공표

산출은 세 경로로 나뉘며, **경로마다 담기는 것이 다릅니다.**

| 경로 | 기관 표기 | 담기는 것 |
|---|---|---|
| 전국 공표문 | 익명 손잡이 | 분포와 밴드. 개별 기관 지목 없음 |
| 기관별 통보서 | 실명 (해당 기관만) | 그 기관의 상태와 고칠 목록 |
| 익명 원자료 | 익명 손잡이 | 재현용 원자료 |

세 경로를 합치면 순위를 복원할 수 있어서는 안 됩니다. 익명 원자료에
동류 집단과 계열을 동시에 넣으면 좁은 조합에서 역추적이 가능합니다.
`min_cell_size` 미달 조합은 제외하십시오(`spec/01` §4.2).

### 4.1 인접 기관 표기

대외 문서에서 인접 지자체를 실명으로 적지 않습니다. `A군`·`B시`로 익명화합니다.
광역이 산하 기초를 보는 롤업 문맥에서만 실명을 허용합니다.

### 4.2 민감도 `restricted`

재난·안전 영역은 답을 만드는 대상이 아니라 **답이 나가지 않게 관리하는
대상**입니다. 측정하되 공표하지 않고 해당 기관에만 비공개로 통보합니다.

공표 파이프라인은 `sensitivity == "restricted"`인 문항을 무조건 제외해야
합니다. 설정으로 켤 수 있게 만들지 마십시오.

## 5. 필수 동봉 문구

모든 산출물에 아래를 포함합니다. 스키마에서 필수 필드입니다.

```
proxy_notice     조회 응답은 사용자가 보는 답과 같지 않다는 선언
run_profile_id   고정한 관측 조건의 참조
observed_at      관측 기간
ledger_as_of     대조한 원장의 기준일
```

## 6. 사전 통지

**사전 통지와 확인 기간을 거치지 않은 결과를 공표하지 않습니다.**
파이프라인에 `notified_at`과 `review_closed_at`이 채워지지 않은 레코드는
공표 산출로 넘어갈 수 없게 막으십시오.

## 7. 공표 시기

지방선거일 전 6개월 구간에는 전국 공표를 하지 않습니다.
`policy/retention.md`의 일정표를 참조하십시오.

## 8. 역점사업 산출의 특례

역점사업 산출은 **기관별 통보서 경로로만** 나갑니다.
전국 공표문과 익명 원자료에 넣지 않습니다(`spec/01` §5).

산출 형태는 사업별 네 층위 상태표와 고칠 목록입니다.
사업 사이 비교, 기관 사이 비교를 하지 않습니다.
같은 기관의 앞 시점과만 비교합니다.

단체장의 성명·사진·업적을 담지 않습니다. 산출물이 홍보물로 읽히면
기관이 위법 소지를 안습니다.
