# 증거 대장

**이 제품이 주장하는 것과, 그 주장이 지금 어느 단계에 있는가.**

2026-09-05 루브릭 평가에서 드러난 것은 설계 89% · **실증 20%** 였다. 설계가 좋은 것은 문서로 확인되지만, 무엇이 실제로 증명되었는지는 어디에도 추적되지 않았다. 이 문서가 그 자리다.

---

## 사용 규칙

**공개 문서·영업 자료·발표에 쓰는 모든 주장은 이 대장에 있어야 한다.** 대장에 없는 주장은 쓰지 않는다.

그리고 **상태를 그대로 표기한다.** `미검증` 주장을 확정처럼 말하지 않는다.

| 상태 | 뜻 | 말할 수 있는 것 |
|---|---|---|
| `미검증` | 근거 없음. 가설 | *"~일 것으로 보고 검증 중이다"* |
| `파일럿` | 소규모 관측 있음. 일반화 불가 | *"N곳 예비 조사에서는 ~였다"* |
| `검증됨` | 사전 등록한 방법으로 확인 | *"~이다"* |
| `반증됨` | 사전 등록한 반증 조건 충족 | **공표한다.** 조용히 지우지 않는다 |
| `철회됨` | 주장 자체를 거둠 | 철회 사유를 남긴다 |

> **이 대장은 공개한다.** AI 가시성 도구들은 방법론조차 공개하지 않는다. 우리는 **아직 증명하지 못한 것의 목록**을 공개한다. 이것은 약점 고백이 아니라 복제 불가능한 신뢰 자산이며, LC-7(이해충돌) 방어의 실질 수단이다.

## 대장

### C-1 · 공공 도메인의 상당수가 AI 수집기에 닫혀 있다

| | |
|---|---|
| 상태 | **파일럿** |
| 근거 | 2026-09-05 경제자유구역 9곳 예비 조사 — 정상 판정 3곳, 차단 1곳, 판정 불가 3곳 (`K09`) |
| 한계 | 단일 시점 1회 관측. 9곳은 자치단체 243곳을 대표하지 않는다 |
| 검증 방법 | 243곳 전수 2주 연속 스캔 |
| **반증 조건** | 전수에서 `blocked_*` + `undetermined` 합계가 **10% 미만** |
| 다음 | T0 전수 스캔 (`ADR-0008`) |

### C-2 · AI 응답 부정확이 실제 행정 문제를 만든다

| | |
|---|---|
| 상태 | **미검증** — 이 제품 전체의 근거 |
| 근거 | 없음 |
| 검증 방법 | 삼각 검증 — AI 확신도 × 부서 확인 정답 × **실제 민원 통계** (`K10` §9) |
| **반증 조건** | 오답률 상위 주제와 민원 발생 상위 주제 사이에 **관련이 확인되지 않음** |
| 다음 | 민원 통계를 대조할 지자체 1곳 확보 (FR-41) |

> **반증되면 유료 상품 라인 전체를 재검토한다.** PRD §01이 이미 그렇게 쓰고 있다. 이 대장은 그 약속을 추적 가능하게 만든다.

### C-3 · 우리 문항은 지자체 간 차이를 잰다 (프롬프트 아티팩트가 아니다)

| | |
|---|---|
| 상태 | **미검증** |
| 근거 | 없음. v1.0 문항 20종은 강건성 검사를 받은 적이 없다 |
| 검증 방법 | 변형 4축 × 단위 3~5곳 파일럿 (`K04` §3.6) |
| **반증 조건** | 20문항 중 **절반 이상이 민감 문항** |
| 다음 | 사전 등록 후 파일럿 (`ADR-0009`) |

> 반증되어도 사업이 끝나지 않는다. *"어떤 질문이 강건한가"* 가 새 연구 문제가 되고, 그것 자체가 발표 가치를 갖는다.

### C-4 · 정본 정비가 AI 응답을 개선한다

| | |
|---|---|
| 상태 | **미검증** — P2·P4 상품의 근거 |
| 근거 | 없음 |
| 검증 방법 | 개입 전후 측정 + **대조군 대비 차이** (`K06` §2.5) |
| **반증 조건** | 조치 단위의 변화가 **대조군 평균 변화와 구분되지 않음** |
| 다음 | P1 계약 1건에서 개입 전후 측정 |

> 절대값이 올랐다는 이유로 성과를 주장하지 않는다. 보고 가능한 개선 = (조치 단위 변화) − (대조군 평균 변화).

### C-9 · 인구감소지역이 AI 응답에서 더 불리하다

| | |
|---|---|
| 상태 | **미검증** — 확산력이 가장 큰 토픽이자 방어력이 가장 낮은 토픽 (`K13` §4) |
| 근거 | 없음 |
| 검증 방법 | 인구감소지역 대 나머지의 Layer 1 판정 분포 · Layer 2·3 응답 정확도 비교 |
| **반증 조건** | 두 집단 사이에 차이가 확인되지 않거나 **반대 방향** |

> **검증 전에는 이 주장을 쓰지 않는다.** 반대 결과가 나올 가능성이 실재하고, 그때 「AI 응답 격차」 프레임 전체가 흔들린다. 폭발력이 큰 토픽일수록 사전 등록이 필요하다.

### C-8 · Layer 1이 AI 응답 품질과 관련이 있다

| | |
|---|---|
| 상태 | **미검증** |
| 근거 | 없음 |

| 검증 방법 | 전수 Layer 1 판정 × Layer 2·3 응답 정확도 상관 분석 |

## 정책 예외 및 거버넌스 등록부

### P-1 · K13 §3 예외 승인 — 전국 공식 근거 3구간 지도 및 능동 관측 등장 지역 실명 공개

| 항목 | 내용 |
|---|---|
| 승인 일자·주체 | 2026-10-09 · 운영자 명시 승인 (`U-3`, `ADR-0017`, `ADR-0021`) |
| 기존 규칙 (`K13` §3) | 전국 집계는 익명 분포로만 내고, 개별 지자체 실명은 좋은 사례만 언급하며 특정 지자체를 나쁜 사례로 지목하지 않는다 |
| 승인된 예외 범위 | ① **전국 공식 근거 지도(2027-03 공개)**: 광역 16 · 기초 227 전수를 고정 경계 3구간(「공식 근거 많음 / 보통 / 공식 근거 적음」)으로 나누어 실명 공개. ② **능동 관측(주간 기상도·추천 지도)**: AI 응답에 **등장한 지역(`안정`·`신규`)의 실명**만 공개 |
| 필수 안전장치 (불변) | ① 구간 안은 **가나다순 무순위**(점수·석차 표시 금지). ② 구간 이름 옆에 고정 경계값과 직전 회차 대비 구간 이동·정비 사건 등록 여부를 함께 표시. ③ 능동 관측에서 **미등장 지역 명단은 산출·공개하지 않는다(`INV-15`)**. ④ 틀린 답 예시는 유형으로만 묶고 기관명은 익명 처리한다. ⑤ 산문·보도자료·해설에서 특정 지자체를 나쁜 사례로 지목하는 문구는 **계속 절대 금지**한다 |

## 갱신 규칙

1. **주간 갱신.** 새 관측이 생기면 상태와 근거를 갱신한다.
2. **반증 조건은 측정 전에 쓴다.** 결과를 본 뒤에 조건을 바꾸는 것은 금지한다 (`ADR-0009`).
3. **상태가 내려가는 것도 기록한다.** `파일럿` → `미검증` 으로 되돌아가는 일이 생기면 사유를 남긴다.
4. **주장을 지우지 않는다.** 철회하면 `철회됨` 으로 표시하고 사유를 남긴다.
5. 새 주장을 영업 자료에 쓰기 전에 **여기에 먼저 등록한다.**
