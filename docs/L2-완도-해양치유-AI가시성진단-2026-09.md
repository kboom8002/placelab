### 1. `wando.go.kr` 해양바이오 전용 페이지 신설

- **원인 추정**: 완도 해양바이오 연구단지·활성소재 인증시설 정보가 `wando.go.kr`에 구조화된 단일 페이지로 존재하지 않음
- **조치**: "해양바이오 투자환경" 단일 페이지에 연구소·인증시설·인센티브를 **표와 수치로** 정리

### 2. 생활행정 FAQ 구조화
- **현상**: 출산장려금·상품권·귀어지원 질문의 출처가 `bokjiro.go.kr`이나 블로그에 의존
- **조치**: `wando.go.kr/faq` 또는 `/life-support` 페이지에 제도별 Q&A를 구조화 → AI가 군 공식 페이지를 우선 인용하도록 유도

### 3. "제주 vs 청산도" AI 마케팅 메시지 활용
- **현상**: AI가 "조용한 힐링과 슬로라이프는 청산도가 제주보다 낫다"고 3회 연속 판정
- **활용**: 이 AI 판정 결과를 관광 마케팅 소재로 활용 가능 (단, 출처와 측정 조건 병기 필수)

### 4. wandohealing.or.kr의 영문 페이지 보강
- **현상**: EN SoV에서 1순위이나, 실제 치유센터 사이트에 영문 페이지가 충분한지 미확인
- **조치**: 영문 프로그램 안내·예약 페이지 신설 → 외국인 관광객 전환율 제고

### 5. `robots.txt` 개방 상태 확인
- **현상**: `wando.go.kr`와 `wandohealing.or.kr` 모두 AI의 검색에 응답하고 있으나, 정식 robots.txt 개방 선언 여부는 별도 확인 필요
