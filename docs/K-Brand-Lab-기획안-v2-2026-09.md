# K-Brand Lab — 고도화 기획안 v2
## 소비자 질문 기반 브랜드 연구 + 실측 검증 플랫폼

> **원안의 핵심 철학을 유지합니다**: K-Brand Lab의 중심은 *'소비자의 질문에서 브랜드가 해결해야 할 과제를 발견하는 것'*이며, AI 가시성 측정은 그 안의 검증 기능입니다.
>
> **이 고도화안이 추가하는 것**: 이번 세션에서 실제로 수행한 1,230회 실측·1,923건 출처 분석·6종 측정 엔진의 경험을 검증 기능에 통합하여, 원안의 "④ 검증" 단계를 구체적인 실행 체계로 구현합니다.

---

## 1. 제품의 핵심 정의 (원안 유지 + 검증 루프 강화)

K-Brand Lab은 소비자가 한국 브랜드와 제품군에 대해 실제로 묻는 질문과 그 배경을 수집·분석하여, **정보 부족·구매 장벽·사용 문제·미충족 수요를 발견하고, 발견된 과제가 AI 세계에서 어떻게 나타나는지를 실측으로 검증하는** 질문 기반 브랜드 연구 플랫폼이다.

### 브랜드 담당자가 얻는 답 (원안 5개 + 실측 검증 3개)

**원안의 5가지 질문 (발견)**
1. 사람들이 우리 브랜드를 알기 전에는 무엇을 묻는가?
2. 우리 브랜드를 검토하면서 어디에서 망설이는가?
3. 구매 이후 어떤 기대와 실제 경험의 차이를 겪는가?
4. 이런 질문에 기존 콘텐츠와 AI는 제대로 답하고 있는가?
5. 설명을 개선하면 되는가, 아니면 제품·서비스 자체를 바꿔야 하는가?

**실측 검증이 추가하는 3가지 질문**

6. **AI가 우리 브랜드를 설명할 때 어디서 정보를 가져오는가?** — 출처 채널 중 우리가 직접 교정할 수 있는 비율은?
7. **AI가 우리 브랜드를 어떤 형용사·프레임으로 묘사하는가?** — 우리가 의도한 포지셔닝과 AI의 묘사 사이에 괴리는?
8. **"추천해줘"라고 물었을 때 우리 브랜드가 경쟁사보다 앞서 나오는가?** — 카테고리별 AI 점유율(SoV)은?

## 2. 소비자 질문의 여정 단계 (원안 6단계 유지 + 측정 연결)

원안의 6단계 소비자 여정을 유지하되, 각 단계에서 **어떤 측정 엔진이 검증을 담당하는지**를 명시합니다.

| 여정 단계 | 소비자의 질문 | 발견할 과제 | **검증 측정 엔진** |
|---|---|---|---|
| **①** 필요·상황 발견 | "출근길에 새지 않는 용기가 있을까?" | 미충족 수요 | **응답률 엔진** — AI가 이 질문에 답하는가? |
| **②** 제품군 탐색 | "보온병과 텀블러 중 어떤 것이 맞을까?" | 제품군 이해 부족 | **프레이밍 엔진** — AI가 카테고리를 어떻게 설명하는가? |
| **③** 브랜드·제품 비교 | "A와 B는 세척이 어떻게 다르지?" | 차별점 전달 부족 | **SoV 엔진** — AI가 비교 질문에서 우리를 추천하는가? |
| **④** 구매 조건 확인 | "교체 부품 계속 살 수 있나? 해외 배송?" | 구매를 막는 불확실성 | **출처 엔진** — AI가 어디서 가격·배송 정보를 가져오는가? |
| **⑤** 사용·문제 해결 | "냄새가 남는데 어떻게 관리하지?" | 사용 안내 부족 | **정확도 엔진** — AI의 관리법 답변이 공식 가이드와 일치하는가? |
| **⑥** 재구매·이탈 | "다음에도 이 브랜드를 살 이유가 있나?" | 이탈 원인 | **다중 모델 엔진** — ChatGPT와 Gemini가 재구매 가치를 어떻게 평가하는가? |

> **핵심**: 브랜드명이 등장하지 않는 질문(①②)이야말로 가장 큰 기회입니다. 잠재 고객은 자신의 상황과 문제로 질문합니다.

## 3. 실측으로 검증된 6개 측정 엔진

이번 세션에서 **실제 가동하고 결과를 확인한** 6종 측정 엔진을 K-Brand Lab의 검증 기능으로 통합합니다.

### 엔진 ①: 응답률 측정 (Response Rate Engine)

> **실증**: 제주도 한국어 69.6% vs 영문 97.1% — 같은 내용도 언어에 따라 AI가 답하거나 침묵함

| 항목 | 설명 |
|---|---|
| **측정 대상** | 소비자 여정 각 단계의 질문을 AI에 던졌을 때, 응답이 돌아오는 비율 |
| **산출물** | 단계별 응답률 히트맵 (어느 여정에서 AI가 침묵하는가) |
| **브랜드 활용** | 응답률 0%인 질문 = AI 세계에서 브랜드가 존재하지 않는 영역 → 최우선 콘텐츠 대상 |

```
소비자 여정별 AI 응답률 (가상 예시 — 텀블러 브랜드 X)

필요·상황 발견   ████████████████████░░░░░░░░░░  67%  "새지 않는 용기" → 브랜드X 미언급
제품군 탐색      █████████████████████████████░  95%  "보온병 vs 텀블러" → 잘 답함
브랜드 비교      ████████████████████████░░░░░░  80%  "A vs X 세척" → X 정보 부족
구매 조건        ██████████░░░░░░░░░░░░░░░░░░░░  33%  🔴 "교체 부품 구매" → AI 침묵
사용·관리        █████████████████████████░░░░░  83%  "냄새 제거법" → 일반론 답변
재구매           ██████████████████████████████  100% "다시 살 이유" → 잘 답함
```

---

### 엔진 ②: 출처 지배력 분석 (Source Dominance Engine)

> **실증**: 김민석 1,923건 그라운딩 출처 분석 → 나무위키(10.5%)가 AI 교과서 1위, 당 공식 채널(0.6%)은 사실상 부재

| 항목 | 설명 |
|---|---|
| **측정 대상** | AI가 브랜드에 대해 답할 때 참조하는 출처 도메인의 전수 캡처 |
| **산출물** | 출처 채널 점유율 파이차트 + **관리 가능 채널 비율** |
| **브랜드 활용** | 관리 가능 비율이 높으면 웹사이트 개편만으로 AI 답변 교정 가능 (비용 0원 레버리지) |

```
                    AI 인용 빈도 (높음 → 낮음)
                    ━━━━━━━━━━━━━━━━━━━━━━
 관리 가능성        [A그룹: 최우선 교정]          [B그룹: 전략적 확장]
 (높음)             • 공식 사이트 (직접)          • 네이버 스토어 (입점)
                    • 자사 블로그               • 쿠팡·마켓컬리 상세
                    ───────────────────────────────┤
 관리 가능성        [C그룹: 협업]                 [D그룹: 감시]
 (낮음)             • 나무위키·위키백과           • 유튜브 리뷰어
                    • 포털 지식인               • 커뮤니티·SNS
```

**제주도 실측 사례 전이**: 제주도의 경우 `visitjeju.net`(18.9%)과 `jeju.go.kr`(9.2%)가 AI의 1·2위 출처였고, 공공 채널 비율이 57.8%로 매우 높아 **도정이 웹페이지만 수정하면 AI 답변을 직접 통제 가능**했습니다. 브랜드도 같은 논리가 적용됩니다.

### 엔진 ③: 정성적 프레이밍 분석 (Framing Engine)

> **실증**: AI가 김민석을 "86세대 학생운동 선두주자 → 최연소 국회의원 → 18년 야인 → 국무총리 → 당대표"라는 5단계 서사로 일관 묘사. 의도한 포지셔닝과 AI 묘사의 괴리를 정량화.

| 항목 | 설명 |
|---|---|
| **측정 대상** | AI가 브랜드를 소개·묘사할 때 선택하는 핵심 수식어·서사·형용사 |
| **질문 유형** | "브랜드 X를 한 문장으로 소개하면?", "X의 강점 3가지는?", "X의 약점은?" |
| **산출물** | **프레이밍 매트릭스** — 브랜드가 의도한 이미지 vs AI가 실제로 사용하는 이미지 |
| **브랜드 활용** | 의도-실제 괴리가 큰 항목 = 나무위키·위키·공식 사이트에서 수정할 서술 |

| 브랜드 의도 | AI 실제 프레이밍 | 괴리 | 교정 우선도 |
|---|---|---|---|
| "프리미엄 스테인리스 보온" | ✅ "고급 보온병 브랜드" | 일치 | 유지 |
| "환경 친화적" | ❌ "가격이 비싼" | 🔴 괴리 | **최우선** |
| "한국 장인 정신" | ⚠️ "한국 중소기업" | 🟡 약화 | 보강 |

### 엔진 ④: 경쟁 점유율 — Share of Voice (SoV Engine)

> **실증**: 김민석이 10개 분야 "추천해줘" 질문 중 3개(20%)에서만 이름 등장. "경제 전문가" "영어 소통" 등 핵심 역량에서 0%.

| 항목 | 설명 |
|---|---|
| **측정 방식** | 2종 질문으로 구성 |
| | **오픈 추천**: "~에 좋은 브랜드 추천해줘" → 브랜드명 등장 여부 + 등장 순서 |
| | **1:1 대결 (H2H)**: "A와 B 중 ~에 더 좋은 것은?" → AI의 비교 판정 |
| **산출물** | **SoV 대시보드** — 카테고리별 추천 점유율 + 경쟁사별 H2H 승률 |

```
카테고리별 AI 추천 점유율 (가상 예시)

"보온력 좋은 텀블러"   브랜드X ██████░░░░  2/3회 (67%)  🟢
"가성비 텀블러"        브랜드X ██████████  3/3회 (100%) 🟢
"친환경 텀블러"        브랜드X ░░░░░░░░░░  0/3회 (0%)   🔴 ← 의도 대비 실종
"세척 쉬운 텀블러"     브랜드X ███░░░░░░░  1/3회 (33%)  🟡

H2H 경쟁사 대비:
vs 스탠리(Stanley)     "보온력은 X가 우세, 디자인은 스탠리"  🟢 우위
vs 스타벅스 텀블러      "가격은 스타벅스, 보온은 X"          🟡 호각
vs 예티(Yeti)          "미국 시장에서 예티가 인지도 압도"     🔴 열세
```

### 엔진 ⑤: 번역 격차 측정 (Translation Gap Engine)

> **실증**: 제주도 한국어 69.6% vs 영문 97.1% = **27.5%p 번역 격차**. 영어교육도시·상급종합병원이 한국어에서 0%이나 영문에서 100% 응답.

| 항목 | 설명 |
|---|---|
| **측정 대상** | 동일 질문의 한국어·영어(·일본어·중국어) 응답 비교 |
| **산출물** | 언어별 응답률·정확도·출처 채널 비교 매트릭스 |
| **브랜드 활용** | 해외 소비자에게 보이는 브랜드 vs 국내 소비자에게 보이는 브랜드의 격차 발견 |

**K-브랜드 특화**: 한국 브랜드가 글로벌 AI에서 어떻게 보이는지는 수출·인바운드 관광 전략에 직결됩니다. K-뷰티·K-푸드·K-라이프스타일 브랜드의 영문 AI 가시성은 별도 시장 기회입니다.

### 엔진 ⑥: 다중 모델 비교 (Multi-Model Engine)

> **실증**: OpenAI는 김민석을 "국무총리"로 아는데 Gemini는 "당대표"로 정확히 인지. 모델에 따라 존재 자체가 달라짐.

| 항목 | 설명 |
|---|---|
| **측정 대상** | 동일 질문을 ChatGPT·Gemini·Claude·Perplexity 등 복수 AI에 투입 |
| **산출물** | 모델별 응답률·정확도·프레이밍·SoV 교차 비교표 |
| **브랜드 활용** | "어떤 AI에서 우리가 약한가"를 특정하여 모델별 교정 전략 수립 |

```
모델별 브랜드 인지 비교 (가상 예시)

                  ChatGPT    Gemini+SG   Claude    Perplexity
응답률              78%        100%        85%       95%
브랜드명 정확       ✅          ✅          ✅        ✅
최신 제품 반영      ❌(구버전)   ✅          ❌        ✅
가격 정확도         🟡          🟢          🟡        🟢
공식 사이트 인용    12%         35%         8%        50%
```

## 4. 측정의 3개 층 — 무엇을 측정하고 무엇은 측정하지 않는가

원안이 강조한 "빈도만으로 구매 영향력을 판단하면 안 된다"는 원칙을 측정 체계에 명시적으로 반영합니다.

| 층 | 측정 가능 | 해석 주의 | 이 제품이 하는 것 |
|---|---|---|---|
| **L1. AI 응답 사실** | AI가 무엇을 답하는가, 어디를 인용하는가, 얼마나 정확한가 | — | ✅ **자동 측정** |
| **L2. 소비자 판단** | "이 답으로 판단할 수 있었는가", "무엇이 더 궁금한가" | 참여자 진술이므로 대표성 한계 | ✅ **참여자 피드백 수집** |
| **L3. 구매 영향** | AI 답변이 실제 구매·이탈에 영향을 미쳤는가 | 행동 기록이나 비교 실험 없이는 **가설** | ⚠️ **"가설"로 표시**, 확정 아님 |

> **원칙**: L1은 사실이고, L2는 진술이고, L3는 가설이다. 이 세 가지를 혼동하지 않는다.
>
> - 'AI가 브랜드를 추천했다' (L1) ≠ '소비자의 문제가 해결됐다' (L2)
> - '소비자가 도움이 됐다고 말했다' (L2) ≠ '구매로 이어졌다' (L3)

## 5. 핵심 작동 방식 — 실측 검증이 통합된 6단계 루프

원안의 흐름(질문 수집 → 맥락 → 테마 → 검증)에 실측 검증을 구체적으로 끼워 넣습니다.

│                                                                     │

│  │고객 문의 │         │질문+상황 │          │정보 공백  │             │
│  │리뷰·Q&A │─────▶  │+의도    │──────▶  │구매 장벽  │             │

### ① 실제 질문과 경험을 수집합니다 (원안 유지)

원안 그대로 유지합니다. 수집 원칙의 핵심을 재확인합니다:

- **3종 질문의 구분**: ⓐ 소비자가 실제로 한 질문 / ⓑ 연구자가 도출한 질문 / ⓒ AI가 탐색용으로 제안한 질문 — 이 세 가지를 **섞지 않고 출처를 표기**합니다.
- **질문 형태가 아닌 경험도 수집**: "뚜껑을 씻기 어렵다" → "분리 세척이 가능한가?"로 변환할 때 **원문과 연구자의 해석을 함께 남깁니다**.
- **검색 추세는 보조 자료**: Google Trends 등은 소비자 전체의 수요를 대표하지 않습니다.

### ② 질문 뒤의 맥락을 파악합니다 (원안 유지)

분석 단위는 질문 한 문장이 아니라 **'질문 + 사용 상황 + 하려는 일 + 망설임 + 이미 찾아본 답'**입니다.

### ③ 질문 묶음을 브랜드 과제로 전환합니다 (원안 유지 + 판정 체계화)

원안의 5가지 발견 유형(정보 공백·검증 공백·구매 장벽·제품 부적합·새로운 수요)을 유지하되, **주된 과제와 보조 과제의 구분** 원칙을 시스템에 내장합니다.

### ④ AI 실측으로 검증합니다 ← **신규 강화**

이 단계에서 6개 측정 엔진이 가동됩니다.

**실측 검증 프로세스**:

```
[과제에서 도출된 질문 세트]
        │
        ▼
   ┌────────────────────────┐
   │ 질문 → 프로브 변환      │  소비자 질문을 AI 진단용 프로브로 정제
   │ (원문·맥락 보존)        │  
   └────────────────────────┘
        │
        ▼
   ┌────────────────────────┐
   │ 다중 모델 실측          │  ChatGPT · Gemini+SG · Claude · Perplexity
   │ × 다중 언어 (KR/EN/JP)  │  문항당 3회 반복 (안정성 검증)
   └────────────────────────┘
        │
        ▼
   ┌────────────────────────┐
   │ 자동 분석               │  응답률 · 출처 도메인 · 프레이밍 · SoV
   │ + GT 대조               │  Ground Truth와 사실 대조
   └────────────────────────┘
        │
        ▼
   [검증 보고서: 어디가 비어있고, 어떻게 채울 수 있는가]
```

### ⑤ 개선을 실행합니다

검증 결과에 따라 실행을 분류합니다:

| 검증 결과 | 실행 유형 | 비용 |
|---|---|---|
| AI가 답은 하지만 출처가 구버전 | 공식 사이트·FAQ 갱신 | **0원** |
| AI가 카테고리를 잘못 분류 | 위키·나무위키 문서 교정 + 구조화 데이터 삽입 | **0원** |
| AI가 경쟁사만 추천 | 비교 콘텐츠·리뷰 확보 전략 | 중간 |
| AI가 질문 자체에 침묵 | 해당 정보의 웹 존재 자체가 없음 → 콘텐츠 제작 | 투자 |
| AI가 정확히 답하지만 소비자가 불만족 | **제품·서비스 자체의 문제** → 콘텐츠로 해결 불가 | 제품 개선 |

### ⑥ 새롭게 드러난 질문으로 진단을 갱신합니다

- 소비자에게 *"이 답으로 판단할 수 있었는가?"*, *"무엇이 더 궁금한가?"*를 묻습니다 (L2).
- 새로운 질문을 수집하여 **다음 스프린트의 진단 질문 세트를 개선**합니다.
- 질문 세트의 버전을 관리합니다 (`method_version` — INV-7 원칙 전이).

## 6. 납품물 5종 (원안 유지 + 실측 데이터 보강)

| # | 납품물 | 원안 내용 | **실측이 추가하는 것** |
|---|---|---|---|
| **1** | **소비자 질문 지도** | 무엇을, 어떤 상황에서 묻는가 | + 여정 단계별 AI 응답률 히트맵 |
| **2** | **우선 해결 질문 목록** | 답변 부족과 소비자 어려움이 어디에 있는가 | + AI 모델별·언어별 침묵 지점 특정 |
| **3** | **브랜드 과제·기회 테마 3~5개** | 콘텐츠·운영·제품 과제 구분 | + 출처 채널 교정 전략 (관리 가능 비율 산출) |
| **4** | **AI 진단 질문 세트** | 실제 질문에서 도출한 검증용 질문 | + 실측 원자료 JSON (재현 가능) + GT 대조표 |
| **5** | **다음 실행·검증 계획** | 무엇을 바꾸고 어떤 결과를 확인할 것인가 | + SoV 경쟁 벤치마크 + 프레이밍 목표 vs 현실 괴리표 |

## 7. 수익 모델 3단계 (원안 유지 + 측정 상품 구체화)

원안의 "초기 연구 프로젝트 → 정기 분석 → 개선안 검증" 흐름을 유지합니다.

| 단계 | 상품 | 내용 | 가격대 (안) |
|---|---|---|---|
| **Ⅰ. 스프린트** | 질문 발견 스프린트 (1회) | 질문 수집 + 5종 납품물 + AI 실측 1회 | 300~500만원 |
| **Ⅱ. 정기 구독** | 분기별 질문 변화 분석 | 질문 지도 갱신 + AI 응답 변화 추적 + SoV 트렌드 | 월 100~200만원 |
| **Ⅲ. 검증 리테이너** | 개선안 검증 + A/B 측정 | 공식 사이트 개편 전후 AI 응답 변화 실측 | 건별 150~300만원 |

> **콘텐츠 제작은 선택 상품**: 연구 결과가 무조건 콘텐츠 발주로 이어지게 만들지 않습니다. "설명을 개선하면 되는가, 아니면 제품 자체를 바꿔야 하는가?"가 연구의 결론이며, 콘텐츠는 전자일 때만 의미 있습니다.

## 10. 골디락스 초기 사업안 (원안 유지 + 실측 포함)

초기에는 협력 브랜드 한 곳과 제품군 하나를 대상으로 **질문 발견 + AI 실측 검증 스프린트**를 판매합니다.

### 파일럿 스프린트 실행 계획 (예: 텀블러 브랜드)

| 주차 | 활동 | 산출물 |
|---|---|---|
| **W1** | 고객 문의·리뷰·Q&A에서 질문 수집 (100~200건) | 질문 원자료 DB |
| **W2** | 맥락 분석 → 여정 6단계 배치 → 과제·기회 테마 도출 | 질문 지도 초안 + 테마 3~5개 |
| **W3** | 테마에서 AI 진단 질문 세트 50~80문항 설계 + GT 구축 | 진단 질문 JSON + GT JSON |
| **W4** | **AI 실측**: 문항 × 3회 × 2~3개 모델 × 2개 언어 = 300~720회 | 실측 원자료 JSON |
| **W5** | 분석: 응답률·출처·프레이밍·SoV + GT 대조 | 검증 보고서 |
| **W6** | 5종 납품물 정리 + 다음 실행·검증 계획 수립 | **최종 납품** |

### 실측 규모 산정 (PlaceLab 경험 기반)

| 요소 | 산정 | 근거 |
|---|---|---|
| 질문 수 | 60문항 | 여정 6단계 × 10문항 |
| 반복 | 3회 | INV-9 원칙 (분포 보존) |
| 모델 | 2개 (ChatGPT + Gemini+SG) | 다중 모델 비교 |
| 언어 | 2개 (한국어 + 영어) | 번역 격차 측정 |
| **총 호출** | **60 × 3 × 2 × 2 = 720회** | 이번 세션 김민석 측정과 동일 규모 |
| 소요 시간 | ~30분 | 이번 세션 실측 속도 기준 |
| API 비용 | ~\$5~15 | 모델별 상이 |

## 결론 — 원안의 포지셔닝을 강화하는 실측

**원안의 결론을 유지합니다**: K-Brand Lab의 가장 강한 포지셔닝은 *'한국 브랜드를 AI에 더 많이 노출시키는 도구'*가 아니라 **'소비자의 질문을 통해 브랜드가 다음에 해결해야 할 문제를 발견하는 연구 시스템'**입니다.

**실측이 추가하는 가치**: 발견된 문제가 AI 세계에서 **구체적으로 어떻게 나타나는지를 1,923건의 출처까지 추적하여 보여주고**, 교정 가능한 채널과 교정 불가능한 채널을 분리하여 **비용 대비 효과가 가장 높은 실행 순서를 제시**하는 것입니다.

> AEO는 발견을 실행하는 한 방법이고, 더 큰 가치는 제품·서비스·시장 적합성을 개선하는 데 있습니다. 실측은 그 개선이 **어디서부터, 얼마의 비용으로 가능한지**를 알려주는 나침반입니다.
