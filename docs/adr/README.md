## 언제 ADR을 쓰나

- 스키마의 모양을 바꿀 때
- 배포 대상 서비스를 추가할 때
- `AGENTS.md` 의 불변식을 건드릴 때
- 측정 명세의 구조(버전 관리 방식, 승격 규칙)를 바꿀 때

## 형식

```
# ADR-000N · 한 줄 제목
- 상태: 제안 | 채택 | 폐기 | ADR-000M 으로 대체됨
- 일자
- 관련 문서

## 맥락      무엇이 문제였나. 사실과 제약
## 결정      무엇으로 정했나
## 근거      왜. 택하지 않은 대안과 그 이유
## 결과      좋아지는 것 / 감수하는 것
## 되돌리는 조건   (선택) 어떤 신호가 오면 재검토하나
```

**기존 ADR을 수정하지 않는다.** 결정이 바뀌면 새 ADR을 쓰고, 이전 것의 상태를 `폐기` 또는 `대체됨`으로 바꾼다.
