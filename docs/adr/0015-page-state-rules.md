# ADR-0015 · 화면 상태 규칙 (측정 전·중·엠바고·발행·정정)

- **상태**: 채택 초안 — **일부 전제는 ADR-0016 으로 폐기**
- **출처**: `jeongdap-note-repo-docs-v1.1/docs/knowledge/decisions.md` ADR-015

## 결정
화면은 상태 규칙(측정 전·측정 중·엠바고·발행됨·정정됨)을 따른다.

## 이유 (출처 원문)
데이터가 생기면 바로 켜지는 화면. 일정 단축.

## 검토한 대안
단계별 화면 개발.

## v1.1 변경
`jeongdap-note-repo-docs-v1.1/AGENTS.md` §0 은 엠바고·지자체 사실 확인 전제를 폐기했다(ADR-0016). 따라서 **엠바고 상태가 실제로 쓰이는지, 상태 집합을 어떻게 줄이는지는 원문에 명시되어 있지 않다.** 이 ADR 은 상태 집합을 확정하지 않으며, `sdd/06-frontend.md` §3 를 v1.1 기준으로 정리하는 작업(구현 계획 Phase 1)에서 결정한다.
