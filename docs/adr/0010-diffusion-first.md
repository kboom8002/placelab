# ADR-0010 · 확산 표면을 1급 제품으로 두고, 시계를 셋으로 나눈다

- 상태: **채택**
- 일자: 2026-09-05
- 관련: `K13` · `ADR-0008` · PRD §04 · FR-47
- 계기: 해자의 세 축 중 **인용 지위**가 개념 선점으로 만들어진다는 판단

## 맥락

[ADR-0008](./0008-moat-is-time.md)은 해자를 **시계열·기관 관계·인용 지위**로 정했고, T0(첫 전수 스캔 개시일)를 1급 마일스톤으로 두었다. 그 결론은 유효하다. 그러나 셋 중 **인용 지위**를 만드는 방법을 설계하지 않았다.

인용 지위는 저절로 생기지 않는다. **누가 먼저 이름을 붙였는가**로 결정된다 (`K13`). 그리고 두 번째로 이름 붙인 쪽은 첫 번째가 만든 언어 안에서 말하게 된다.

이 사실이 제품 설계에 두 가지 문제를 드러냈다.

**첫째, 공개 페이지가 부속으로 취급되고 있었다.** 지금까지 `/units/[id]` 나 OG 이미지는 Layer 1의 표시 수단이었다. 그러나 실제로 프레임을 나르는 것은 측정 결과 자체가 아니라 **사람이 남에게 보낼 수 있는 형태**다. 우리 시 이름과 상태가 박힌 이미지 한 장이 칼럼 열 편보다 멀리 간다.

**둘째, 시계가 하나뿐이었다.** T0 를 기준으로 모든 일정을 짰는데, **개념 선점은 데이터를 기다리지 않는다.** 첫 두 편의 칼럼은 지금 쓸 수 있고, 써야 한다. T0 하나로 계획하면 개념 선점이 자동으로 늦어진다.

## 결정

### 1. Layer 0 · 공개 표면을 제품 구조에 추가한다

Layer 0는 **측정하지 않는다.** Layer 1~3의 결과를 사람이 나를 수 있는 형태로 만든다.

| | Layer 0 · 공개 표면 |
|---|---|
| 하는 일 | 프레임을 나른다 |
| 수집 | 없음 |
| 과금 | 무료 |
| 구성 | 단위별 공유 카드 · 지역 페이지 · 셀프체크 프롬프트 팩 · 인용 가이드 · 보도 키트 |
| 성공 | **우리가 만든 단어를 남이 쓰는 횟수** |

Layer 0를 별도 층으로 두는 이유는 **설계 책임이 다르기 때문**이다. Layer 1~3의 설계 기준은 타당도이고, Layer 0의 설계 기준은 **전달성**이다. 같은 사람이 같은 기준으로 설계하면 둘 다 어중간해진다.

### 2. 시계를 셋으로 나눈다

| 시계 | 정의 | 선행 조건 |
|---|---|---|
| **C0** | 첫 칼럼 게재 — 개념 선점 개시 | **없음.** 지금 가능하다 |
| **T0** | 243곳 첫 전수 스캔 개시 | 판정 규칙표 · 단위 마스터 · 강건성 파일럿 |
| **P0** | 첫 전수 결과 공표 | T0 + 2주 연속 + 사전 통지 완료 |

**C0 → T0 → P0 순서이며, C0는 다른 둘을 기다리지 않는다.**

다만 **개념만으로 끌 수 있는 것은 칼럼 두 편까지다.** 세 번째 편부터는 `전국 243곳 중 N곳` 이 필요하다. 따라서 C0와 T0 사이의 간격이 벌어지면 확산이 끊긴다 — **확산이 측정을 앞서 달리되, 측정이 곧 따라붙어야 한다.**

### 3. 개념 선점을 측정한다

우리는 측정을 파는 회사다. 자기 확산을 측정하지 않으면 우습다.

`citations` 를 확장해 **용어 채택**을 추적한다.

```sql
alter table citations
  add column used_our_term boolean,
  add column term          text,
  add column attributed    boolean;
```

- `used_our_term` — 「AI 응답 격차」 등 우리가 만든 용어를 썼는가
- `term` — 어느 용어인가
- `attributed` — 출처를 밝혔는가

> **`used_our_term = true` 이고 `attributed = false` 인 인용이 늘어나는 것이 개념 선점의 성공 신호다.** 출처 없이 우리 단어를 쓴다는 것은 그 단어가 **일반명사가 되었다**는 뜻이다. 이 지표를 낮추려 하지 않는다.

### 4. 우선순위를 다시 정한다

확산 표면이 기관 대시보드보다 앞선다.

| 앞으로 | 뒤로 |
|---|---|
| 단위별 공유 카드 (FR-47) | 기관 대시보드 (FR-12) |
| 지역 페이지 · 조회 URL | 리포트 내보내기 (FR-21) |
| 인용 가이드 (FR-9) | 개선 전후 비교 (FR-13) |
| 보도 키트 | 알림 (FR-14) |

## 근거

### 왜 Layer 0인가 — 4가 아니라 0인 이유

번호를 0으로 둔 것은 **측정 스택 밖**임을 표시하기 위해서다. Layer 1~4는 "무엇을 남기는가"로 위계가 있지만, Layer 0는 그 위계에 속하지 않는다. 아무것도 측정하지 않고 아무것도 남기지 않는다 — **다른 층의 산출물을 옮길 뿐이다.**

Layer 5로 두면 "가장 나중에 하는 것"으로 읽히고, Layer 1에 흡수시키면 다시 부속이 된다.

### 왜 시계를 나누는가

하나의 시계로 계획하면 **가장 늦은 선행 조건이 전부를 늦춘다.** 강건성 파일럿이 4~5주 걸리므로, 시계가 하나면 개념 선점도 5주 늦는다. 그런데 개념 선점에는 그 파일럿이 필요 없다.

동시에, 시계를 나눈다고 해서 순서가 사라지는 것은 아니다. C0가 P0보다 지나치게 앞서면 *"말만 하고 데이터가 없는 곳"* 이 된다. 세 시계의 간격을 관리하는 것이 이 결정의 실제 내용이다.

### 확산과 엄밀성의 관계를 제품 구조로 못박는다

Layer 0가 별도 층인 것은 **엄밀성 기준이 느슨해도 된다는 뜻이 아니다.** 정반대다 — Layer 0가 나르는 모든 숫자는 Layer 1~3의 게이트(승격·사전 등록·증거 대장)를 이미 통과한 것이어야 한다.

Layer 0는 **새 사실을 만들지 않는다.** 이미 방어되는 사실을 전달 가능한 형태로 바꿀 뿐이다. 이 제약이 있어야 확산이 엄밀성을 잠식하지 않는다.

## 결과

**좋아지는 것**

- 개념 선점이 데이터 일정에 묶이지 않는다. C0를 지금 칠 수 있다.
- 공유 카드·인용 가이드가 "나중에 할 것"에서 "MVP 필수"로 올라온다.
- 개념 선점의 성패가 지표로 관리된다. `used_our_term` 이 그 자체로 해자의 크기다.

**나빠지는 것 / 감수하는 것**

- **기관 대시보드가 늦어진다.** 초기 계약 기관은 이메일과 PDF로 결과를 받게 된다. 감수한다.
- **C0와 T0 사이에 "데이터 없이 말하는 기간"이 생긴다.** 이 기간에는 미검증 주장을 확정처럼 말할 유혹이 커진다. `EVIDENCE.md` 상태 표기와 INV-12가 이것을 막는다.
- Layer 0의 설계 기준(전달성)이 다른 층과 달라, **같은 사람이 둘 다 설계하면 둘 다 어중간해진다.** 담당을 나누거나 최소한 작업을 시간적으로 분리한다.

## 되돌리는 조건

- 확산이 기대만큼 일어나지 않으면(6개월간 외부 인용 0건, `EVIDENCE.md` C-6 반증) 개념 선점 가설 자체를 재검토한다. 그 경우 자원을 Layer 3·4의 직접 영업으로 되돌린다.
