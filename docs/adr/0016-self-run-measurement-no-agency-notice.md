# ADR-0016 · 자체 사업 측정 — 기관 통지·엠바고·사실 확인 생략

- **상태**: 채택 초안 (운영자 검토 전). 출처 문서 기준으로 **출처의 ADR-009(발행 전 엠바고 + 지자체 사실 확인)를 폐기**한다.
- **출처**: `jeongdap-note-repo-docs-v1.1/docs/knowledge/decisions.md` ADR-016, `.../AGENTS.md` §0 (D103)
- **구 파일명**: 앞서 `0016-skip-agency-notice.md` 로 작성한 초안은 이 파일로 대체한다.

## 결정
자체 사업으로 수행하는 측정에서는 기관 통지·엠바고·지자체 사실 확인을 하지 않는다. 공개 문서만 읽어 측정·분석하며, 발행은 **운영 승인**만 거친다(`AGENTS.md` §0).

## 이유 (출처 원문)
- 14일 대기가 사전 등록 일정과 충돌한다.
- 공개 문서만 읽는 측정에는 동의 절차가 필요 없다.
- 참여 지자체 없이도 진행할 수 있다.

## 검토한 대안
통지 유지, 1주 순연.

## 이 저장소와의 충돌 (후속 작업 필요 — 이 ADR 이 처리하지 않음)
기존 코드·문서가 사전 통지를 전제한다.
- 현재 `AGENTS.md` v1 / PRD FR-24 (14일 사전 통지)
- `supabase/functions/verdict-promote/index.ts` 가 신규·변경 판정에 `notice_until = +14일` 을 설정하고 `published=false` 로 둔다.
- `notifications` 테이블, `docs/EVIDENCE.md` 의 관련 주장.

위 항목을 어떻게 정리할지는 구현 계획 Phase 1 에서 다룬다. 이 ADR 채택만으로 해당 코드가 바뀌지는 않는다.
