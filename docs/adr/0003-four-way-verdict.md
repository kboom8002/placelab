# ADR-0003 · robots 판정을 4분하고 "판정 불가"를 남긴다

- 상태: **채택**
- 일자: 2026-09-05
- 관련: `PRD.md` §06 · `K03` · `K09` · `AGENTS.md` INV-2

## 맥락

초기 명세는 판정을 사실상 2분으로 두었다 — **열림 / 닫힘**. 화면도 그렇게 그렸다.

2026-09-05 경제자유구역 9곳 예비 실측에서 이 설계가 무너졌다.

| 관측된 상태 | 곳 |
|---|---|
| 정상 개방 | 3 |
| `robots.txt` 404 | 1 |
| 연결 시간 초과 | 2 |
| `robots.txt` 존재, 홈 접근까지 거부 | 1 |
| `/robots.txt` 자리에 **HTML 홈페이지 반환** | 1 |
| 시·도 도메인과 공유 — 단독 판정 불가 | 1 |

**9곳 중 정상 판정이 가능한 곳은 3곳이었다.** 나머지 6곳은 값이 나쁜 것이 아니라 *값을 읽을 수 없는* 상태다.

## 결정

`robots_verdict` 를 5값 열거형으로 두고, `undetermined` 는 반드시 사유 코드를 동반한다.

```
open · blocked_all · blocked_selective · no_file · undetermined
undetermined_reason: timeout · malformed · parse_fail · shared_domain · dns_fail · other
```

공개 집계 문장은 **네 값을 모두** 낸다: `개방 N · 차단 N · 파일 없음 N · 판정 불가 N`.

DB 제약으로 강제한다.

```sql
constraint tech_scans_undetermined_needs_reason
  check ((robots_verdict = 'undetermined') = (undetermined_reason is not null))
```

## 근거

`undetermined` 를 어느 쪽으로 뭉뚱그려도 **정정 요청의 정당한 사유**가 된다.

- **차단으로 합치면** — 서버가 잠깐 느렸을 뿐인 기관을 "AI 수집을 정책적으로 막는 기관"으로 공표하게 된다. 해당 기관이 자기 `robots.txt` 를 열어 보이면 우리 판정이 틀린 것이 되고, 이 한 건이 전수 집계 전체의 신뢰를 무너뜨린다.
- **개방으로 합치면** — 실제로는 크롤러가 도달하지 못하는 곳을 "정상"으로 보고하게 된다. 이 경우 우리가 하려는 측정 자체가 성립하지 않는다. `robots.txt` 조회에 실패하면 다수 크롤러는 보수적으로 전체 수집을 중단하므로, 무응답은 사실상 차단에 가깝게 작동한다 — 그러나 그것은 *해석*이지 *관측*이 아니다.

관측과 해석을 분리하는 것이 이 설계의 요점이다. 우리는 관측만 공표하고, 해석은 이용자에게 맡긴다(PRD §03 이해충돌 설계).

`MALFORMED` 를 독립 코드로 둔 것은 별도의 이유가 있다. 이것은 차단 *의도*가 아니라 **설정 오류**이므로, 통보받은 기관이 예산 없이 당일 고칠 수 있다. 고발이 아니라 **무예산 즉시 조치 대상**이며, P1 진단의 가장 설득력 있는 첫 페이지가 된다. 이 구분이 제품을 "지적하는 도구"에서 "고칠 수 있게 하는 도구"로 바꾼다.

## 결과

- 화면·API·내보내기·리포트가 전부 4값을 다뤄야 한다. 2값 UI로 되돌아가는 지름길이 없다.
- 스캐너는 실패를 오류가 아니라 **데이터**로 다룬다. 예외를 삼키고 재시도하는 것이 아니라, 사유를 판정으로 기록한다.
- `K09` 의 9건을 회귀 픽스처로 고정해, 각 실패 유형이 정확히 그 사유 코드로 판정되는지 CI에서 검증한다.
- 단발 관측은 판정이 아니다 — 2주 연속 동일 결과일 때만 승격한다(ADR-0004).

**감수하는 것** — 발표 자료의 문장이 길어진다. "전국 243곳 중 N곳이 닫혀 있다"보다 네 값을 모두 읽는 쪽이 덜 자극적이다. 그 대신 **반박 가능한 지점이 없다.**
