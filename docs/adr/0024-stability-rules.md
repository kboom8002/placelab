## 권장 판단
두 규칙은 **서로 다른 대상**에 적용되므로 하나를 고를 필요가 없다. 충돌하지 않는다.

| 규칙 | 대상 | 원문 및 코드 정의 |
|---|---|---|
| 9회 블록 안정성 | 기준 단위 5곳 × 패널 550 (`judge_auto.py` L80–86) | 같은 인스턴스의 9회 판정 중 다수 `(s3, s4)` 판정과 다른 횟수가 **2회 이하**면 안정(`unstable = diff > 2`). H1: 두 개의 독립 3일 블록 간 문항별 일치도(3회 중 2회 공식 첫 인용) **0.8 미만**이면 반복 횟수·주 결과 정의 재검토 (`methodology/02` 73행) |
| 4주 12회 창 상태 | 상시 관측(월·수·금 관측 질문 50 + 외국어 40, 4주 = 12회) | `observe_weekly.py` L157–161 기준:<br/>- **신규**: 이번 주 2회 이상(`ht >= 2`) ∧ 지난 3주 0회(`hp == 0`)<br/>- **안정**: 4주 12회 중 9회 이상(`h >= 9`)<br/>- **가끔**: 4주 12회 중 3–8회(`h >= 3`)<br/>- **소멸**: 이번 주 0회 ∧ 최근 2주 연속 0회 ∧ 이전 3주 합계 6회 이상(`ht == 0 and hp >= 6 and all(byw[w] == 0 for w in weeks[:2])`)<br/>- **드묾**: 위 네 조건에 해당하지 않는 나머지(4주 1–2회 등). 지자체 카드 `appear` 목록과 전국 기상도에는 표시하지 않는다(`observe_weekly.py` L197) |
| 화요일 지명 한 줄 | 243단위 정체성 질문 (`ID-{unit_id}`) | `observe_weekly.py` L115–120·L147 에서 `mentions.jsonl` 과 12회 창 계산에서 제외하고 `identity.jsonl` 로 별도 분리하여 선언표(`알릴`·`낡은` 키워드) 등장 여부와 지난주 대비 변화만 판정한다 |

## 규칙 (INV-8 후속)
1. **단발 관측은 공개 판정이 아니다.** 한 번의 AI 응답으로 지역·질문 상태를 공개하지 않는다.
2. 공개 가능한 상태는 위 규칙의 출력뿐이다.
3. 상태가 **바뀔 때만** 알린다. 신규·소멸은 사람이 확인한 뒤 발행한다(운영 승인 — ADR-0016).
4. 임계값(0.8, 9회 중 변동 2회, 4주 12회 중 9회/3회/2회/6회)은 `lib/jeongdap/constants.ts` 상수 파일 하나에 모으고 출처 주석을 단다(`AGENTS.md` §3).
