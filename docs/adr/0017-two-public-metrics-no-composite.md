# ADR-0017 · 공개 지표는 둘 (공식 근거율 · 피해 위험 건수), 종합 점수 없음

- **상태**: 채택 초안 (운영자 검토 전)
- **출처**: `jeongdap-note-repo-docs-v1.1/docs/knowledge/decisions.md` ADR-017
- **구 파일명**: 앞서 `0017-metrics-without-score.md` 로 작성한 초안은 이 파일로 대체한다.

## 결정
공개 지표는 **공식 근거율**(자동 판정)과 **피해 위험 건수**(사람 판정) 둘뿐이다. 종합 점수·정답률·등급은 두지 않는다.

## 이유 (출처 원문)
자동/사람 비대칭으로 비용을 통제하고, 합산 지표가 낳는 서열화·조작 유인을 피한다.

## 검토한 대안
정답률 단일 지표.
