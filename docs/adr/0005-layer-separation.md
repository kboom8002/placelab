# ADR-0005 · 레이어별 데이터를 타입 수준에서 분리한다

- 상태: **채택**
- 일자: 2026-09-05
- 관련: `PRD.md` §04·§09 · `K06` · `AGENTS.md` INV-4

## 맥락

이 제품은 편향의 성격이 근본적으로 다른 데이터를 한 DB에 담는다.

| | 수집 | 편향 | 정당한 분모 |
|---|---|---|---|
| Layer 1 | 서버 자동 · 전수 | **없음** | 전국 243곳 |
| Layer 2 | 사람 · 자발적 제출 | 자기선택 | **참여한 N곳** |
| Layer 3 | API 자동 · 조건 통제 | 조건 고정 | 측정한 N곳 |

세 데이터는 모두 "지자체 AI 응답 상태"를 말하므로, 같은 화면·같은 표·같은 차트에 놓고 싶은 유혹이 항상 존재한다. 그리고 한 번 섞이면 **되돌릴 방법이 없다** — 인용된 숫자를 회수할 수 없기 때문이다.

특히 위험한 것은 Layer 2다. 참여자는 이미 문제의식을 가진 사람이고, 결과가 나쁘면 제출하지 않을 수 있다. 이 표본으로 "전국 평균"을 말하는 순간 방법론 전체가 무너진다(NG-4).

Layer 2와 Layer 3을 섞는 것도 위험하다. API 응답은 소비자 앱 응답과 다르다 — 모델 버전, 시스템 프롬프트, 검색 연동, 개인화가 다르기 때문이다. 둘을 같은 축에 놓으면 없는 추세가 보인다.

## 결정

레이어 분리를 **관행이 아니라 타입**으로 만든다.

```ts
declare const brand: unique symbol;

export type Layer1Stat = {
  [brand]: 'layer1';
  population: Population;   // 필수 — 기본값 없음
  denominator: number;      // 전수
  open: number; blockedAll: number; blockedSelective: number;
  noFile: number; undetermined: number;
};

export type Layer2Stat = {
  [brand]: 'layer2';
  participatingUnits: number;   // 분모는 '참여한 단위 수'
  observationCount: number;
  methodVersion: string;
};
```

- 두 타입은 브랜드가 달라 **서로 대입되지 않는다.**
- `Layer2Stat` 에는 `denominator` 필드가 **존재하지 않는다.** 전국 분모를 쓰려면 없는 필드를 만들어내야 한다.
- 하나의 컴포넌트가 `Layer1Stat | Layer2Stat` 을 받지 않는다. 리뷰에서 막고 불변식 테스트로 검사한다.

DB 층에서도 같은 원칙을 적용한다. `v_layer2_participation` 뷰는 **참여한 단위만** 행으로 낸다. 전국 분모가 스키마에 아예 존재하지 않는다.

## 근거

문서에 "섞지 마시오"라고 쓰는 것으로는 부족하다. 마감에 쫓기는 개발자, 문맥이 없는 AI 에이전트, 6개월 뒤의 본인이 그 문장을 읽지 않는다. **읽지 않아도 막히게** 해야 한다.

브랜드 타입은 런타임 비용이 0이고, 잘못된 조합을 컴파일 단계에서 잡는다. 뷰 설계는 잘못된 쿼리를 데이터 부재로 잡는다. 둘 다 "실수하면 불편하다"가 아니라 **"실수할 수 없다"** 쪽에 가깝다.

같은 논리로 `population` 도 필수 인자다(ADR-0002).

## 결과

- 대시보드에서 Layer 1과 Layer 2를 나란히 보여주려면 **두 컴포넌트를 나란히 두어야 한다.** 하나의 범용 차트 컴포넌트로 통합하려는 리팩터링은 반려 대상이다.
- 문구도 타입을 따라간다. `Layer2Stat` 을 렌더하는 컴포넌트는 `참여한 N곳 중` 을 하드코딩하고, 그 문구를 파라미터로 받지 않는다.
- Layer 3 통계는 별도 브랜드(`Layer3Stat`)를 갖는다. Layer 2·3 비교 뷰는 만들 수 있으나 **"다른 측정"임을 화면에 명시**하고, 별도 전용 컴포넌트에서만 한다.

**감수하는 것** — 컴포넌트 재사용이 줄고 코드가 조금 늘어난다. 이 제품에서 중복 코드보다 비싼 것은 **잘못 인용된 숫자 하나**다.
