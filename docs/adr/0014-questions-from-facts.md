# ADR-0014 · 질문은 정본에서 생성한다 (답안지 동반)

- **상태**: 채택 초안 (운영자 검토 전)
- **출처**: `jeongdap-note-repo-docs-v1.1/docs/knowledge/decisions.md` ADR-014

## 결정
질문은 정본(확인된 사실)에서 생성하며, 답안지를 함께 만든다.

## 이유 (출처 원문)
판정 재현성. 정본이 없는 측정을 방지한다.

## 검토한 대안
질문을 먼저 작성한다.

## 이 저장소에 미치는 영향 (검토 필요)
현재 `question_bank`·measurement-spec 문항은 질문 중심으로 작성되어 있고 `docs/ground-truth/` 는 단위별 파일이다. 정본 → 질문 → 답안지 순서로 바꾸려면 데이터 모델 변경이 필요하다. 구체 설계는 구현 계획 Phase 2 에서 다룬다.
