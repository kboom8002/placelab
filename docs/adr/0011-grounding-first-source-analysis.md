# ADR-0011 · 측정 기본 조건을 검색 증강(on)으로 전환하고, 출처를 1급 측정 대상으로 둔다

- 상태: **채택**
- 일자: 2026-09-06
- 관련: `K03` · `ADR-0006` · `ADR-0007` · PRD §03
- 계기: 수원시 파일럿 실측에서 off/on 조건 간 정확도 격차 78pp, 작화 완전 소멸 관측

## 맥락

v1.0은 `web_search=off`를 기본 조건으로 두었다. 근거는 **"검색을 끄면 AI가 원래 알고 있는 것이 드러난다"**였고, 그것이 개선 대상이라고 보았다.

2026-09-06 수원시 파일럿에서 이 전제가 깨졌다.

| | off | on |
|---|---|---|
| 정확도 | 15% | 93% |
| 작화 | 10% (6건) | 0% |
| Floor Risk | critical (4문항) | low |

세 가지 사실이 드러났다.

**첫째, off 측정은 조치 불가능한 진단을 내놓는다.** "AI 모델의 가중치에 수원시 정보가 부족하다"는 관측은 지자체가 고칠 수 없다. 모델을 재학습시킬 수 없기 때문이다.

**둘째, 2026년 9월 기준 주요 AI 서비스는 모두 검색을 기본으로 켠다.** ChatGPT(search on by default), Gemini(Grounding on by default), Perplexity(검색 전용), Copilot(검색 통합). 사용자의 80% 이상이 검색이 켜진 상태에서 AI를 쓴다. off는 실험실 조건이지 실제 사용 환경이 아니다.

**셋째, on 측정은 출처를 보여준다.** "AI가 어떤 출처를 인용하는가"는 조치 가능한 진단이다. 공식 출처가 인용되지 않으면 SEO와 구조화 데이터를 개선하면 되고, 인용되지만 오래되었으면 정본을 갱신하면 된다.

동시에, 수원시가 `blocked_all`임에도 **공식 도메인 인용률이 90%**였다. 서브도메인(`waste.suwon.go.kr`, `suwonlib.go.kr`)이 독립적으로 개방되어 있고, 검색 엔진 인덱스를 경유하여 메인 도메인 정보에도 도달했다. robots.txt 차단의 실질적 타격은 **off 조건에 집중**되며, on 조건에서는 우회 경로가 존재한다.

## 결정

### D-1. 기본 측정 조건을 `web_search=on`으로 전환한다

- on이 주 측정이며, 공표 대상이다.
- off는 보조 진단("기저 지식 참고치")으로 남기되, 반복을 5회→3회로 줄인다.
- `method_version`을 `v2.0`으로 올린다.

### D-2. 출처를 1급 측정 대상으로 추가한다

on 측정에서 답변 정확도와 함께 **인용 출처를 6축으로 분석**한다.

| 축 | 측정 내용 |
|---|---|
| 출처 권위도 | 1차(공식) / 2차(뉴스·기관) / 3차(블로그) 비율 |
| 출처 시점 | 인용 정보의 게시·갱신 일자 |
| 정본 도달률 | 최종적으로 공식 URL을 안내하는지 |
| 구조화 데이터 연관 | JSON-LD 존재 페이지의 인용 비율 |
| 인용 안정성 | 5회 반복 시 동일 출처 인용 비율 |
| 경쟁 출처 식별 | 타 도시/타 기관 페이지 경유 비율 |

이것이 v2.0의 핵심 차별화다. v1.0은 "정확한가"만 물었다. v2.0은 **"왜 정확한가(또는 부정확한가), 그 정보는 어디서 왔는가"**를 물으며, **조치 가능한 처방**을 내놓는다.

### D-3. 문항을 페르소나 기반 35문항으로 확장한다

v1.0의 12+8 문항은 카테고리×1문항이라 해당 영역을 대표하지 못한다. v2.0은 6개 페르소나(20대 청년, 30대 학부모, 50대 전입자, 70대 어르신, 외국인, 소상공인) × 5~7시나리오 = 35문항으로 확장한다.

문항은 여전히 8블록으로 저장하며(ADR-0007), 강건성 검사를 통과해야 채택된다(INV-10).

### D-4. AI 서비스를 3대로 확장한다

ChatGPT + Gemini + Perplexity. 시장 점유율 80%+ 커버. 서비스 간 차이가 진단의 일부다.

### D-5. 측정을 API 기반으로 자동화한다

35문항 × 3서비스 × 5반복 = 525회/단위. 수동 불가능. API 파이프라인 + Judge 모델(K03 M-2.8의 5대 조건 준수).

## 되돌리기

- v2.0 파일럿에서 on 측정의 출처 분석이 조치 가능한 처방으로 이어지지 않는다면, off를 주 측정으로 복원한다.
- Judge 교차채점 일치도가 기준 미만이면 사람 채점으로 회귀한다.
- v1.0→v2.0 병행 측정 없이 전환하지 않는다. 시계열을 끊지 않는다.
