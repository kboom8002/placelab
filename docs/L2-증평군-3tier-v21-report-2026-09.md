## 섹션 1. AI가 아는 증평의 세 가지

### 🏆 1위: 좌구산휴양랜드

AI에게 "증평 하면 뭐가 떠올라?"라고 물으면 **3회 모두 좌구산을 1순위**로 답합니다.

| 반복 | AI 응답 |
|---|---|
| 1회차 | ① 좌구산휴양랜드 ② 증평민속체험박물관 ③ 인삼과 홍삼 |
| 2회차 | ① 좌구산 휴양랜드 ② 증평 인삼 ③ 보강천 미루나무숲 |
| 3회차 | ① 좌구산휴양랜드(출렁다리) ② 증평민속체험박물관 ③ 인삼과 홍삼 |

> **인사이트**: AI 세계에서 증평의 1순위 연상어는 좌구산이며, 인삼은 항상 포함되지만 **1위는 아닙니다.** "증평 = 인삼"이 되려면 콘텐츠 강화가 필요합니다.

### 🥈 2위: 인삼과 홍삼

3회 모두 인삼이 연상어에 포함됩니다. 그러나 **"한국에서 인삼 유명한 곳"을 물으면 금산·풍기·진안이 먼저 나오고 증평은 빠집니다.**

### 🥉 3위: 2003년 괴산군 분리

"증평이 독립된 군이 된 게 언제야?"에 대해 3회 모두 **"2003년 괴산군에서 분리"**를 정확히 답합니다. AI가 확실히 아는 사실입니다.

## 섹션 2. AI가 모르는 증평의 정보 — 군수님이 아셔야 할 빈칸

### 🔴 AI가 추천 질문에서 증평을 빼먹는 경우 (8/15건)

이것이 이 보고서의 **가장 중요한 발견**입니다.

| 질문 | AI 응답 (증평 없음) | 증평이 포함되어야 하는 이유 |
|---|---|---|
| "충북에서 살기 좋은 곳 3곳" | 청주·충주·제천 | 증평은 청주 30분, 교통 편리 |
| "충북에서 귀농귀촌 좋은 곳" | **괴산·보은·옥천·영동·단양** | 증평은 귀농귀촌 지원금·빈집수리비 지원 |
| "**인삼 산지로 유명한 곳**" | **금산·풍기·진안·홍천·괴산** | 증평 인삼축제, 보강천 사질양토 |
| "충북 자연휴양림 좋은 곳" | 옥화·계명산·속리산 | **좌구산자연휴양림** |
| "서울 1시간 30분 귀촌 후보지" | 양평·가평·괴산 | 증평IC 중부고속도로 |
| "은퇴 후 충북 조용히 살 곳" | 괴산·보은·옥천·제천·단양 | 증평 1읍 1면, 전원생활 |
| "50대 텃밭 가꾸기 좋은 소도시" | 공주·서천·남원·김제·상주·순천 | 에듀팜특구 |
| "한국 인삼 유명한 곳" | **금산·풍기·진안·홍천** | 증평 인삼축제 |

> **핵심 메시지: AI에게 "인삼 유명한 곳"을 물으면 증평이 나오지 않습니다.** 금산·풍기가 독점하고 있습니다. 증평 인삼의 온라인 콘텐츠가 AI가 참조하는 수준에 도달하지 못하고 있습니다.

### 🟡 AI가 증평을 정확히 아는 것 (의외의 강점)

| 질문 | AI가 정확히 답한 것 |
|---|---|
| 에듀팜특구 | **"충북 증평군 도안면의 증평 에듀팜특구"** — AI가 유일한 특구로 정확히 인식 |
| 괴산 분리 역사 | 2003년 분리, 23년차 |
| 행정 구역 | 1읍(증평읍) 1면(도안면), 면적 81.84㎢ |
| 서울까지 교통 | 중부고속도로 증평IC, 1시간 30분~2시간 |
| 인삼축제 음식 | 인삼튀김·인삼백숙·인삼막걸리·인삼주스 |
| 증평 vs 괴산 비교 | "생활 편의면 증평, 넓은 농지면 괴산" — **증평에 유리하게 답함** |
| 증평 vs 진천 비교 | "증평은 2003년 분리된 작은 군, 진천은 더 넓고 인구 많음" |

|---|---|---|
| 증평군 홈페이지 인삼 페이지 강화 | AI가 금산·풍기만 답함 | "증평 인삼"의 역사·재배환경·축제를 **단일 페이지**로 정리. 보강천 사질양토 6년근 재배 강조 |
