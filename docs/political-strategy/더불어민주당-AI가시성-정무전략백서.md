   > *"본 백서에 수록된 모든 실측 수치(동작구 120슬롯, 영등포구 120슬롯, 논산시 135슬롯, 서울시장 감사 및 김민석 대표 360회 실측 등)는 정식 사전 등록(Preregistration) 절차에 앞서 알고리즘 특성을 분석하기 위해 수행된 **탐색적 측정 · 사전 등록 전 파일럿(Exploratory Pilot)** 관측치입니다. 본 수치는 향후 정식 사전 등록 절차 및 2주 연속 동일 관측 승격(`INV-8`)을 거친 후 확정 공표용으로 승격됩니다."*

   > *"본 백서에서 다루는 유권자 표심 이동, 초접전 선거구 득표 영향(8,300~24,900명 추정치), 지역 경제 소비 방어 편익 등은 공학적 관측치와 유권자 행동 가정을 결합한 **시나리오 추정치이며 실측치가 아닙니다.**"*

4. **공직선거법상 여론조사 부인 고지 (공직선거법 제108조 준수)**:
   > *"본 조사는 유권자를 대상으로 표본을 추출하여 지지도를 묻는 공직선거법상의 선거여론조사가 아니며, 특정 후보나 정당의 지지율 및 당선 가능성을 나타내지 않습니다. 본 데이터는 대형 언어 모델(LLM)의 웹 크롤링 인덱싱 및 텍스트 생성 특성을 진단한 **공학적 알고리즘 감사 결과**입니다."*

5. **행정구역 및 모집단 분리 고지 (INV-1 준수)**:

## 제1장. Executive Summary: 정무적 패러다임 전환과 더불어민주당의 기회

### 1.1. 포털 링크 검색에서 생성형 AI 직접 답변으로의 대전환
대한민국 유권자의 정보 획득 환경이 역사적인 대전환점을 지나고 있습니다. 지난 20여 년간 유지되어 온 '포털 사이트 파란 링크(10 Blue Links) 나열 및 클릭' 기반의 정보 유통 질서가 해체되고, 인공지능이 웹상의 데이터를 종합·압축하여 단일 결론으로 출력하는 **'제로 클릭(Zero-Click) 생성형 답변'**이 보편적 정보 인프라로 자리 잡았습니다.

```
[유권자 정치 정보 유통 패러다임의 진화]
┌────────────────────────────────────────────────────────────────────────┐
│ 제1물결 (1980~1990년대): 방송·신문 중심의 일방향 매스미디어 시대      │
│  - TV 토론, 활자 신문, 유세차 연설, 종이 공보물                       │
├────────────────────────────────────────────────────────────────────────┤
│ 제2물결 (2000~2010년대): PC 인터넷 포털 및 검색 엔진(SEO) 시대         │
│  - 네이버·다음 포털 검색, 1페이지 상위 노출 경쟁, 블로그 바이럴 홍보  │
├────────────────────────────────────────────────────────────────────────┤
│ 제3물결 (2010~2020년대): 소셜 미디어 및 동영상 알고리즘 시대          │
│  - 유튜브 쇼츠, 페이스북, 인스타그램, 알고리즘 피드 점유, 확증 편향   │
├────────────────────────────────────────────────────────────────────────┤
│ 제4물결 (2025년~현재): 기계 인지 공간(Machine Cognitive Space) 생성 검색│
│  - ChatGPT, Gemini, Perplexity, Naver Cue: 대화형 즉답                 │
│  - 포털 방문 없는 Zero-Click 단일 합성 답변, W3C 시맨틱 정본(SSOT) 독점│
└────────────────────────────────────────────────────────────────────────┘
```

Google AI Overviews, OpenAI SearchGPT, Perplexity, Naver Cue: 등 주요 플랫폼들은 유권자에게 웹사이트 방문을 유도하지 않고, 검색창 내부에서 직접 작성한 요약 텍스트를 제공합니다. 과거의 정무 홍보가 검색 결과 첫 페이지 유입을 목표로 하던 포털 검색 최적화(SEO)였다면, 현재와 미래의 정무 전략은 **'인공지능 모델이 정책과 공약을 어떤 사실(Ground Truth)로 인지하고 요약하게 만들 것인가'를 다루는 AEO(AI Engine Optimization) 및 GEO(Generative Engine Optimization)**로 완전히 재편되었습니다.

- 지역 소멸을 막고 국토 균형발전을 추구해 온 더불어민주당에게 **'지역의 디지털 정보 주권 확보'**는 단순한 기술 과제가 아니라 헌법적 책무이자 절체절명의 정무적 사명입니다.

### 1.4. 정무적 전략 프레임워크 요약: '기계 인지 공간'의 정본 독점
더불어민주당의 승리 전략은 명확합니다.

2. **kplacelab**의 6대 프로브 공학 엔진을 통해 인공지능이 무엇을 모르고(`canon_absent`), 무엇을 왜곡하고 있는지(`mismatch`) 정량 진단합니다.

4. **"기계 인지 공간의 단일 정본(SSOT)을 장악하는 자가 2030 유권자의 인지 세계를 지배한다."** 이것이 본 백서가 제시하는 선거 승리의 제1공식입니다.

## 제2장. kplacelab + kpolicylab 결합에 따른 구조적 비대칭 우위 (Unfair Advantage)

### 2.1. 두 엔진의 상호보완적 아키텍처: 정량 진단과 질적 수집의 융합
더불어민주당이 확보할 수 있는 구조적 비대칭 우위(Unfair Advantage)의 본질은, 기술적 텍스트 진단 엔진인 **kplacelab**과 주민 생활 밀착형 질문 발견 플랫폼인 **kpolicylab**의 유기적 결합에 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [kpolicylab] 주민 생활 맥락의 질적 발견 엔진                          │
│ - 5대 수집 채널: 온라인 질문함, 대면·전화 심층 채집, 민원 접점 일지 등 │
│ - 4대 입력 분류: 직접 질문, 불편·경험, 비교·선택, 기대·제안           │
│ - 7단계 중립 후속 질의 -> 생활언어 맥락 복원 및 5대 빈칸 검사          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 질문 묶음 -> 8블록 표준 진단 질문 조립
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [kplacelab] 기계 인지 공간의 정량 감사 엔진                            │
│ - 6대 프로브: Factual(사실), SoV(점유율), H2H(비교), Advisory, Reverse │
│ - 엄격한 판정: 규칙 대조(judged_by: rule), 4칸 판정, Floor Risk 산출   │
│ - 데이터 지표: match, mismatch, not_confirmed, canon_absent            │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 정본 부재(canon_absent) & 왜곡 추출
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [더불어민주당 정책·선거 대응] 기계 가독형 단일 정본(SSOT) 발행        │
│ - 조례 제정 및 행정감사 의제화 / 254개 선거구 킬러 공약 확정           │
│ - W3C Schema.org JSON-LD 시맨틱 마크업 배포 -> AI 답변 100% 영구 앵커링│
└────────────────────────────────────────────────────────────────────────┘
```

1. **kpolicylab의 역할 (Bottom-Up 질적 센서)**:
   - 유권자가 정책 용어가 아닌 생활언어로 호소하는 고통을 5개 채널을 통해 날것 그대로 수집합니다.
   - 유도 질문을 배제한 7단계 중립 시퀀스로 질문의 상황·목적·막힌 단계를 규명하고, 과업 단계(발견-이해-비교-신청-이용-사후)별 질문 지도에서 '행정 서비스 단절'을 포착합니다.
2. **kplacelab의 역할 (Top-Down 공학적 진단기)**:
   - kpolicylab에서 도출된 주민 질문을 8블록 표준 프로브 질문으로 변환하여, 주요 인공지능 모델(Gemini, GPT 등)에 3회 반복 투입합니다.
   - 인공지능이 해당 현안에 대해 정확한 수치를 말하는지(`match`), 과거 뉴스를 오독하여 엉뚱한 답을 내는지(`mismatch`), 아예 백지 상태로 침묵하는지(`not_confirmed / canon_absent`)를 수학적으로 진단합니다.

### 2.2. 이중 피드백 루프(Dual Feedback Loop) 메커니즘
이 결합 모델은 일회성 설문조사나 단순 여론조사와 달리, 지속적으로 스스로를 강화하는 **이중 피드백 루프(Dual Feedback Loop)**를 완성합니다.

```
[루프 1: 민생 문제 발굴 및 정책화 루프 (Qualitative Loop)]
주민 불편 수집(kpolicylab) 
  -> 질문 지도 매핑 & 정책 테마 도출 
  -> 당 정책위 킬러 공약 수립 및 지방의회 조례 발의 
  -> 주민 피드백 재확인 및 테마 고도화

[루프 2: 기계 인지 정본 앵커링 루프 (Quantitative Algorithmic Loop)]
공약·조례의 W3C Schema.org JSON-LD 구조화 발행 
  -> 검색 엔진 크롤러 인덱싱 
  -> kplacelab 6대 프로브 정기 추적 감사 
  -> 인공지능 단일 합성 답변 내 민주당 정책 영구 락인(Lock-in)
```

### 2.4. 선점의 영속성(First-Publisher Advantage)과 기술적 해자(Moat)
대형 언어 모델과 검색 그라운딩 엔진은 동일한 주제에 대해 웹상에 복수의 정보가 존재할 경우, **가장 먼저 W3C 표준 시맨틱 구조(Schema.org)를 갖추고 신뢰성 있는 도메인에 텍스트로 안착된 데이터**를 1차 정본(Canonical Ground Truth)으로 채택합니다.
- 더불어민주당 후보가 특정 지역구의 숙원 사업이나 청년 복지 공약을 구체적인 로드맵, 소요 예산, 수혜 조건이 포함된 정본 팩트시트(Canonical Fact Sheet)로 선제 공표하면, 인공지능은 이를 '기준 진실'로 영구 학습합니다.
- 이후 상대 당 후보가 아무리 유사한 공약을 발표하더라도, 인공지능의 시각에서는 민주당 공약의 아류(2차 출처)로 취급되어 추천 답변에서 밀려나게 됩니다. 이것이 바로 후발 주자가 결코 넘을 수 없는 **'AEO 선점의 영속적 해자(Permanent Moat)'**입니다.

### 2.5. 8블록 질문 아키텍처 및 5대 빈칸 검사(Blank-space Tests)
kpolicylab에서 수집된 질적 민원과 kplacelab의 공학적 프로브는 하드코딩된 자연어 문장이 아니라, `ADR-0007` 및 `INV-10`에 정의된 엄격한 **8블록 진단 질문 아키텍처(8-Block Question Architecture)**에 따라 동적으로 조립됩니다.

```
[8블록 표준 진단 질문 구조 사양]
1. Block-1 (Question ID): 고유 식별자 (예: DJ-GAP-001, NS-MIL-003)
2. Block-2 (Context Domain): 생활 주제 (주거·돌봄·이동·일·환경·문화·생활행정)
3. Block-3 (Task Stage): 과업 단계 (발견 -> 이해 -> 비교 -> 신청 -> 이용 -> 사후)
4. Block-4 (Target Persona): 유권자 페르소나 (청년 1인가구, 영유아 학부모, 고령 은퇴자 등)
5. Block-5 (Trigger Intent): 검색 의도 (사실 확인, 자격 판정, 절차 문의, 대안 탐색)
6. Block-6 (Core Prompt Template): 문법적 뼈대 및 슬롯 변수
7. Block-7 (Linguistic Variations): 3종 이상의 구어체·생활언어 변형 세트
8. Block-8 (Ground Truth Pointer): 검증 기준 사실 원장(JSON) 내 타겟 필드 포인터
```

또한 질문 지도에서 누락된 행정 사각지대를 판별하기 위해 **5대 빈칸 검사(Blank-space Tests)**를 의무 적용합니다:
1. **대상-이용 단절 검사**: 지원 대상은 명시되어 있으나 실제 신청·이용 방법 질문이 웹상에 존재하는가?
2. **공급자-수요자 격차 검사**: 관청의 홍보 설명은 있으나 실제 주민의 이용 경험 질문이 결손되어 있는가?
3. **조건-예외 결손 검사**: 지원 금액은 공표되었으나 소득 조건, 기간, 예외 조항에 대한 질문이 부재한가?
4. **포기-대체행동 검사**: 만족도 조사만 있고, 신청을 포기하거나 다른 사설 서비스로 이탈한 주민 질문이 방치되었는가?
5. **지명 비브랜드 검사**: 관공서 이름을 직접 넣은 검색 외에 지명이 없는 상태의 추천 탐색 질문이 존재하는가?

### 2.6. 기계 인지 공간 내 정보 엔트로피 감소의 수학적 모델
기계 인지 공간 $S$에서 특정 지역구의 정책 현안 $k$에 대한 인공지능 모델 $M$의 답변 불확실성(Entropy) $H(M_k)$는 다음과 같이 정의됩니다.

$$H(M_k) = - \sum_{i \in \{match, mismatch, not\_confirmed\}} P(i) \log_2 P(i)$$

- 정본이 부재한 상태(`canon_absent`)에서 $P(not\_confirmed) \to 1$ 또는 사설 블로그의 루머로 인해 $P(mismatch)$가 증가하면, $H(M_k)$는 최대치에 도달하여 유권자에게 심각한 혼란을 초래합니다.
- 더불어민주당이 W3C 표준 Schema.org 기반의 단일 정본(SSOT) $C_k$를 웹에 최초 발행(First Publishing)하여 검색 인덱스에 주입할 때, 인공지능 모델의 상호 정보량(Mutual Information) $I(M_k; C_k)$가 극대화되며 엔트로피는 0에 수렴합니다.
- 이는 결과적으로 **인공지능 모델의 응답 일치율($P(match)$)을 95% 이상으로 수직 상승**시키며, 상대 후보의 개입 여지를 수학적으로 봉쇄합니다.

### 5.1. 공직선거법 제250조(허위사실공표죄) 예방을 위한 3단계 소명 체계
- **법적 리스크**: 인공지능 모델의 오답이나 누락을 근거로 "상대 후보의 공약은 취소된 거짓 공약이다"라고 단정했다가 실제 사업이 추진 중일 경우 낙선 목적 허위사실공표죄(7년 이하 징역) 성립.
- **3단계 소명 및 방어 체계**:
  1. **SSOT Ground Truth 사전 동결**: 공적 고시, 예산서, 결산서 등 1차 관보를 기반으로 GT JSON을 작성하고 SHA-256 타임스탬프 해시로 사전 동결.
  2. **규칙 기반 판정 (`judged_by: 'rule'`)**: 모델에게 진위 판정을 맡기지 않고 규칙 엔진으로만 일치 판정.
  3. **비판 타겟의 기술적 분리**: 상대 후보 개인에 대한 비방이 아니라, 지자체 집행부의 AEO 방치 및 정보 주권 상실을 공격.

### 5.2. 공직선거법 제85조/제86조(공무원 중립 의무) 거버넌스 격벽
- **리스크 차단**: 단체장이 공무원에게 선거용 웹 개편을 지시하거나 지자체 예산 진단 리포트를 캠프에 이첩하는 행위 원천 차단.
- **격벽 수칙**: 지자체 공공 진단 계정과 선거캠프 전략 계정의 인프라(DB, 테넌트) 완전 분리 및 계약서상 전용 금지 의무화.

### 5.3. 공직선거법 제93조/제108조(여론조사 오인 방지) 체계
- **리스크 차단**: SoV나 1:1 비교를 여론조사 지지율로 오인하는 사태 방지.
- **방어 수칙**: 모든 대외 발표문 첫 문단에 "본 조사는 선거여론조사가 아님" 필수 고지 및 순위표·서열화 전면 배제(`INV-3`).

### 5.4. 정치자금법 제31조/제45조 및 연구플랫폼 3중 방화벽 (SoC)
- **리스크 차단**: 영리법인의 무상 데이터·소프트웨어 제공에 따른 불법 정치자금(재산상 편익) 기부죄 의율 방지.
- **3중 방화벽 구조**:
  - **1계층 (오픈 공공 표면)**: 243개 지자체 robots.txt 판정 등 Layer 1 데이터는 공공재로서 전 정당과 시민에 무상 공개.
  - **2계층 (정당·선거캠프 유상 서비스)**: 선거구별 120슬롯 진단 및 AEO 서비스는 K08 표준단가 기준 정식 B2B 계약 체결 및 정치자금 공식 계좌 정산.
  - **3계층 (지자체 행정 데이터 격벽)**: 공적 예산 납품 결과물의 정당 선거캠프 무단 공유 원천 차단.

### 5.7. 지방의회 조례 표준안 전문: 「디지털 정보주권 조례(안)」

```markdown
### 「지방자치단체 인공지능 검색 대응 및 디지털 정보주권 확보에 관한 조례(안)」

제1조(목적) 이 조례는 인공지능 생성형 검색 시대에 부응하여 지방자치단체의 행정·정책·문화 정보에 대한 디지털 정보주권을 확보하고, 기계 가독형 공공데이터 표준화를 통해 주민의 알 권리를 증진함을 목적으로 한다.
제2조(정의) 이 조례에서 사용하는 용어의 뜻은 다음과 같다.
  1. "인공지능 검색 대응(AEO)"이란 대형 언어 모델 및 생성형 검색 엔진이 지방자치단체의 공공정보를 왜곡 없이 인용하도록 최적화하는 일체의 기술적·행정적 조치를 말한다.
  2. "정본 데이터(Canonical SSOT)"란 웹 크롤러가 가장 신뢰성 높은 1차 출처로 인용할 수 있도록 W3C 웹 표준에 따라 구조화된 공식 문서를 말한다.
제3조(지방자치단체의 책무) 지방자치단체의 장은 관할 지역의 공공정보가 인공지능 검색 공간에서 왜곡되거나 누락되지 않도록 필요한 시책을 수립·시행하여야 한다.
제4조(기본계획의 수립) ① 단체장은 디지털 정보주권 확보를 위하여 3년마다 기본계획을 수립하여야 한다.
  ② 기본계획에는 다음 각 호의 사항이 포함되어야 한다.
  1. 인공지능 크롤러 접근성(`robots.txt`) 정책 및 개방 현황
  2. 부문별 10대 핵심 단일 정본 페이지(Schema.org JSON-LD) 구축 계획
  3. 인공지능 생성 정보의 정기 실태조사 및 왜곡 교정 방안
제5조(공식 정본 페이지 구축 및 표준화) 단체장은 공식 누리집에 게시되는 주요 정책 및 생활정보에 대하여 기계 가독형 텍스트 및 W3C Schema.org 시맨틱 마크업을 의무 적용하여야 한다.
제6조(정기 실태조사) ① 단체장은 반기별로 주요 생성형 인공지능 모델을 대상으로 관할 지역 정보에 대한 가시성 및 사실 정합성 실태조사를 실시하여야 한다.
  ② 실태조사 결과 확인된 왜곡·작화 정보에 대해서는 즉각적인 정본 데이터 게시 등 교정 조치를 취하여야 한다.
제7조(협력체계 구축) 단체장은 한국관광공사, 공공데이터포털, 포털 사업자 등과 협력하여 공인 정본 데이터가 원활히 유통될 수 있도록 민관 협력망을 구축할 수 있다.
제8조(예산의 지원) 단체장은 제5조 및 제6조에 따른 정본 페이지 구축 및 실태조사 수행에 필요한 예산을 편성할 수 있다.
제9조(시행규칙) 이 조례의 시행에 필요한 사항은 규칙으로 정한다.
부 칙 이 조례는 공포한 날부터 시행한다.
```

### 6.5. 선거캠프용 6대 프로브 설계 가이드라인 및 프롬프트 엔지니어링
선거캠프 정책실무자는 다음 6대 프로브 설계 원칙에 따라 질문을 구성해야 합니다:
1. **Factual (사실 검증)**: "OO구 OO동 옛 구청사 부지 복합개발 사업의 현재 추진 단계와 층수 계획은?"
   - 목적: 공식 관보(GT)와 인공지능 응답 간의 일치/부정합/미확인 판정.
2. **SoV (음성 점유율)**: "서울 서남권에서 청년 창업과 주거 지원이 가장 잘 되어 있는 자치구는?"
   - 목적: 후보자나 지역구 이름을 명시하지 않은 제로샷 추천 질의 시 자발적 등장 빈도 측정.
3. **H2H (정면 대결)**: "동작구와 영등포구의 청년 1인가구 복지 혜택을 비교해줘."
   - 목적: 인접 경쟁 지자체와의 비교 질의 시 다차원 우열 및 상호보완 분할 양상 분석.
4. **Advisory (상황별 추천)**: "동작구에서 20대 대학생이 지원받을 수 있는 월세 혜택과 신청 자격은?"
   - 목적: 특정 페르소나의 과업 수행에 필요한 구체적 해결책 제시 여부 확인.
5. **Reverse/Negative (역발상 편견)**: "사당역 일대는 비만 오면 상습 침수되는 위험 지역인가?"
   - 목적: 악성 루머나 지역 낙인에 대해 인공지능이 방재 인프라 팩트로 해명하는지 감시.
6. **EN (글로벌 영문)**: "What are the major business incentives in Yeouido Financial District?"
   - 목적: 해외 투자자 및 외국인 유권자 관점의 교차 언어 지식 격차(Cross-lingual Gap) 측정.

## 제7장. 결론: 기계 인지 시대의 진보 정치와 민주당의 역사적 책무

### 7.1. 정보 주권 확보가 곧 민주주의의 수호이다
인공지능이 유권자의 질문에 답하는 세상에서, 왜곡된 정보와 가짜뉴스가 방치되는 것은 민주주의의 근간을 뒤흔드는 일입니다.
- 상대 당이 기득권적 카르텔과 오프라인 조직 동원에 의존할 때, 더불어민주당은 가장 투명하고 공학적인 데이터 인프라로 유권자의 알 권리를 수호해야 합니다.
- 디지털 정보 주권을 장악하는 것은 단순한 선거 승리 기술을 넘어, 시민들에게 정확한 공공재를 되돌려주는 진보 정당 본연의 역사적 소명입니다.

### 7.2. 증거 기반 정치(Evidence-Based Politics)와 정본 데이터 인프라의 제도화
본 백서가 제시한 kplacelab과 kpolicylab의 결합은 대한민국 정치 역사상 선도적으로 시도되는 **'증거 기반 정치(Evidence-Based Politics)'**의 완성형 모델입니다. 감과 주관, 슬로건에 의존하던 구태 정치를 청산하고, 정밀한 실측 데이터와 W3C 웹 표준에 기반하여 정책을 입안하고 평가하는 선진 정치 문화를 더불어민주당이 선도할 것입니다.

### 7.3. 대장 연계(EVIDENCE.md) 및 지속 가능한 연구·실행 체계
본 백서의 모든 주장은 멈추어 있는 텍스트가 아니라, `docs/EVIDENCE.md` 대장을 통해 주간 단위로 검증되고 반증 조건을 시험받는 살아있는 과학적 가설입니다. 더불어민주당은 앞으로도 학술적 정밀성과 공직선거법 준수라는 엄격한 윤리적 기준 위에서, 기계 인지 공간의 승리를 일구어내고 대한민국 민주주의의 새로운 지평을 열어갈 것입니다.

### [부록 2: 공학·정무 용어 정의 및 약어집]
- **AEO (AI Engine Optimization)**: 인공지능 검색 엔진이 웹상의 정보를 인덱싱하고 요약 답변을 생성할 때, 특정 공공·정책 데이터가 왜곡 없이 정답으로 인출되도록 웹 구조와 메타데이터를 최적화하는 공학적 기법.
- **GEO (Generative Engine Optimization)**: 생성형 대형 언어 모델의 다차원 지식 표현 및 검색 증강 생성(RAG) 공간에서 특정 엔티티의 인지도와 호감도를 정량적으로 개선하는 전략.
- **SSOT (Single Source of Truth)**: 단일 진실 공급원. 분산된 웹 환경에서 인공지능 크롤러가 가장 권위 있는 정답으로 인용하도록 공인된 단일 정본 웹페이지.
- **SoV (Share of Voice)**: 비브랜드(Unbranded) 추천 질의 시 인공지능이 특정 지자체나 정치인을 자발적으로 추천하는 빈도 비율.
- **Floor Risk**: 인공지능 모델의 복수 회차 반복 질의 중 가장 나쁜 회차에서 관측된 위험도. 허위 사실 작화(Hallucination) 발생 시 `critical`로 판정.
- **canon_absent**: 공공기관이나 정당이 해당 현안에 대해 기계 판독 가능한 단일 정본 문서를 웹상에 발행하지 않아 인공지능이 정보를 인출할 수 없는 상태.
- **N-코드**: 인공지능이 공적 정보를 답변하지 못하는 원인을 분류한 코드 체계 (N1 기술차단, N2 내용부재, N3 형식미비, N4 경쟁배제, N5 엔진회피).
