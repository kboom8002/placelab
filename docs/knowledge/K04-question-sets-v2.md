## 0. 문항은 8블록으로 저장한다

v1.0과 동일한 8블록 체계. [K04 v1.0 §0](./K04-question-sets.md) 참조.

v2.0 변경점:
- `S` (Situation) 블록 기본값 변경: `웹 검색을 사용해서 최신 정보를 포함해 답해 주세요.` (on 조건)
- off 보조 측정 시 `S` 를 `웹 검색을 하지 마세요. 알고 있는 지식만으로 답해 주세요.`로 교체

## 1. 페르소나 정의

문항은 **사용자 유형(페르소나)**으로 구분한다. 각 페르소나는 연령·상황·핵심 관심사를 정의한다.

| ID | 이름 | 연령/특성 | 핵심 관심사 |
|---|---|---|---|
| `P1` | 20대 청년 | 만 19~29세, 취업준비/직장초년 | 기본소득, 월세, 창업, 취업, 교통, 문화 |
| `P2` | 30대 학부모 | 영유아~초등 자녀 동반 | 출산, 어린이집, 야간소아과, 학군, 돌봄, 안전 |
| `P3` | 50대 전입자 | 타 지역에서 이사 | 전입 혜택, 폐기물, 종량제, 민원, 관광, 부동산 |
| `P4` | 70대 어르신 | 디지털 취약, 복지 필요 | 교통비, 건강검진, 돌봄, 여가, 복지 |
| `P5` | 외국인 주민 | 결혼이민/유학/노동 | 체류, 의료, 다문화센터, 통역, 교육 |
| `P6` | 소상공인 | 자영업/소규모 사업 | 대출, 보조금, 세금, 상권, 인허가, 축제 |

## 3. 질문 유형 분류

| 유형 | 측정 포인트 | 해당 문항 수 |
|---|---|---|
| 자격 확인 | 조건 정확도 (나이·소득·거주 요건) | 6 |
| 팩트 확인 | 수치 정확도 (금액·가격·시간) | 6 |
| 절차 안내 | 단계별 정확도 (신청→심사→지급) | 7 |
| 존재 확인 | 제도·서비스 유무 정확도 | 7 |
| 시설 찾기 | 실재성 + 위치 정확도 | 5 |
| 탐색 | 정보 범위·다양성 | 4 |
| 비교/추천 | 편향·출처 다양성 | 2 |
| 시점 민감 | 최신성 (연도·일정) | 1 |

> **"존재 확인" 유형이 가장 위험하다.** "있어?"라고 물었을 때 없는 것을 "있다"고 답하면 confabulation이다.
> 수원시 파일럿에서 작화 4건 중 3건이 존재 확인 유형(전입축하금, 목욕권, 점심 휴무)이었다.

## 4. v1.0 문항과의 대응

v1.0의 12문항 중 10문항이 v2.0에 계승되었다. 2문항(N08 도서관, N10 노인복지)은 분할되었다.

| v1.0 | v2.0 | 변경 사항 |
|---|---|---|
| N01 폐기물 | P3-02 | 페르소나 P3(전입자)로 이동 |
| N02 전입 | P3-01 | 페르소나 P3로 이동 |
| N03 환경 | P3-03 | 페르소나 P3로 이동 |
| N04 복지(청년) | P1-01 + P1-02 | P1(청년)으로 분할 확장 |
| N05 출산 | P2-01 | 페르소나 P2(학부모)로 이동 |
| N06 관광 | P3-05 | 페르소나 P3로 이동 |
| N07 축제 | P6-06 | 페르소나 P6(소상공인)으로 이동 |
| N08 문화 | — | 도서관 단독 문항 제거, P4 여가에 통합 |
| N09 보건 | P2-03 | 페르소나 P2로 이동 |
| N10 노인복지 | P4-01 + P4-05 | P4(어르신)로 분할 |
| N11 경제 | P6-01 | 페르소나 P6으로 이동 |
| N12 행정 | P3-04 | 페르소나 P3으로 이동 |

v1.0의 무지명 8문항(U01~U08)은 v2.0에서는 **별도 측정 세트로 유지**하되, 본 문서의 범위 밖에 둔다.

## 5. 채점 기준 (on 조건 확장)

v1.0의 4단계 판정(정확/부분정확/부정확/부재)과 작화(confabulation)는 유지한다.

v2.0 추가 기록:

| 축 | 기록 내용 |
|---|---|
| `source_urls` | 인용된 URL 전수 (배열) |
| `source_authority` | 각 URL의 권위도 등급 (1차/2차/3차) |
| `source_freshness` | 인용 정보의 추정 게시 일자 |
| `canonical_reached` | 공식 URL을 최종 안내했는지 (boolean) |
| `structured_data` | 인용 페이지에 JSON-LD가 있는지 (boolean) |
| `competitor_source` | 타 도시/타 기관 페이지 경유 여부 |
