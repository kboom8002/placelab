# K07 · 공개 · 정정 · 인용 정책

무엇을 언제까지 보여줄 것인가는 기능이 아니라 **정책**이며, 한 번 정하면 바꾸기 어렵다.

> **공개는 의무이자 차별점이다.** 확인된 AI 가시성 도구들은 방법론 통제를 대체로 공개하지 않는다(`K11` §1). 우리는 방법론과 **아직 증명하지 못한 것의 목록**(`EVIDENCE.md`)까지 공개한다. 이것이 복제 불가능한 신뢰 자산이며, 동시에 우리 방법론을 누구나 가져갈 수 있게 만든다 — 그래서 해자를 시계열·관계·인용에 둔다(`ADR-0008`).

파생물: i18n 리소스 · 공문 서식 · 인용 가이드 페이지(`/cite`)

---

## 1. 첫 공개 절차

첫 전국 공개는 되돌릴 수 없다. **순서를 지킨다.**

```
1. 전수 스캔 2주 연속 안정          ← 승격 규칙 충족 (ADR-0004)
2. verdicts.published = false 상태로 확정
3. 해당 단위에 사전 통지 (2주)
4. 정정 요청 접수·처리
5. 인용 가이드 페이지 배포
6. verdicts.published = true 일괄 전환
7. 보도·인용 모니터링 가동
```

**3번을 건너뛰면 이 제품은 "몰래 채점해서 공개한 곳"이 된다.** 그 인상은 회복되지 않는다.

### 사전 통지문 골자

> 귀 기관 누리집의 AI 수집기 접근 설정 상태를 2026년 ○월 ○일과 ○월 ○일 두 차례 확인한 결과를 아래와 같이 알려 드립니다.
>
> **관측 결과**: `{판정}` `{사유}`
> **관측 방법**: `{method_version}` — 전문은 {방법론 URL}
>
> 이 결과는 ○월 ○일부터 공개될 예정입니다. 관측이 사실과 다르다고 판단하시면 아래 경로로 정정을 요청해 주십시오. 정정 요청 시 재점검 후 결과를 회신하며, 처리 이력은 공개 기록으로 남습니다.
>
> 또한 귀 기관의 설명을 해당 페이지에 함께 게재할 수 있습니다.
>
> **본 관측은 누리집의 공개된 설정 파일을 확인한 것이며, 기관의 업무 수행을 평가하는 것이 아닙니다.**

마지막 문장이 중요하다. 우리는 **관측만 공표하고 평가하지 않는다** — 이것이 LC-3 방어의 축이고, 순위표를 만들지 않는 이유와 같다.

## 2. 정정 절차 (FR-23)

| 단계 | 기한 | 내용 |
|---|---|---|
| 접수 | 즉시 | 익명 접수 허용. 신원 요구는 정정을 막는 장벽이다 |
| 1차 회신 | **5영업일** | 접수 사실과 처리 예정 안내 (NFR-8) |
| 재점검 | 회신 후 | 해당 도메인 즉시 재스캔 (주기와 무관하게) |
| 결과 회신 | 재점검 후 | 판정 유지/변경과 그 근거 |
| 기록 | 상시 | 접수·검토·재점검·회신 전 과정을 공개 기록으로 |

### 정정이 받아들여진 경우

- `verdicts` 를 갱신하고, **이전 판정을 지우지 않는다.** 정정 이력으로 남긴다.
- 우리 쪽 오류였다면 그 사실을 해당 단위 페이지에 표시한다.

### 정정이 받아들여지지 않은 경우

- 근거(관측 원자료의 해시·시각·응답 코드)를 회신한다.
- 그래도 이견이 있으면 **설명 게재권**으로 넘긴다. 우리가 이기는 것이 목적이 아니다.

---

## 3. 설명 게재권 (FR-22)

각 단위 페이지에 **해당 기관의 설명을 나란히 표시한다.**

- 기관이 직접 작성한다. 우리가 요약하거나 편집하지 않는다.
- 분량 제한만 두고 내용은 검열하지 않는다. 명백한 개인정보·비방만 반려한다.
- 우리 판정과 **같은 화면, 같은 크기**로 표시한다. 각주로 밀지 않는다.
- 작성 주체(부서명)를 함께 표시한다.

> 이 장치가 있기 때문에 우리는 "일방적으로 채점했다"는 비판에 답할 수 있다. 비용은 거의 들지 않고 효과는 크다.

## 4. 인용 가이드 (FR-9)

기자·연구자·의원 보좌진이 **틀리게 인용하지 않도록** 문장 템플릿을 함께 배포한다.

### 올바른 인용

```
kplacelab 측정에 따르면, 2026년 ○월 ○일 기준
전국 기초자치단체 227곳 중 N곳의 누리집이
주요 AI 수집기 접근을 전면 차단하고 있으며,
M곳은 응답 없음 등의 사유로 판정할 수 없었다.
(방법론 v1.0, 2주 연속 동일 관측 기준)
```

핵심은 셋이다 — **분모 명시 · 시점 명시 · 판정 불가 병기.**

### 잘못된 인용과 그 이유

| 잘못된 문장 | 문제 |
|---|---|
| `전국 지자체 절반이 AI에 막혀 있다` | 분모 불명. "지자체"가 243인지 227인지 249인지 알 수 없다 |
| `○○시가 최하위를 기록했다` | 순위를 산출하지 않는다 (NG-1) |
| `AI 대응 점수 32점` | 종합 점수를 산출하지 않는다 |
| `전국 249곳 중` | 두 모집단 합산 (ADR-0002) |
| `참여 지자체 평균 정확도는 전국 평균이다` | 자발적 표본 일반화 (NG-4) |
| `robots.txt를 열면 AI 노출이 늘어난다` | 인과 미증명 (`K06` §4) |

### 인용 요청 대응

- 원자료 요청에는 **공개 집계 CSV**(FR-10)로 응한다. 원시 스캔 로그는 제공하지 않는다.
- 특정 단위만 뽑아 달라는 요청은 응하되, **그 단위의 설명 게재문을 함께 전달한다.**
- 순위·랭킹 산출 요청은 거절하고, 왜 거절하는지 설명한다.

## 5. 공개 수준

| 데이터 | 공개 | 근거 |
|---|---|---|
| Layer 1 판정 (승격·통지 완료분) | **전면 공개** | 공개 정보 기반. 공익성 |
| Layer 1 원시 스캔 로그 | 비공개 | 재현 가능성은 해시로 담보 |
| Layer 2 집계 | 공개 (`참여한 N곳` 표기) | |
| Layer 2 개별 제출 | 비공개 | 제출자 보호 |
| 자유 질문 | **검수 통과분만** 집계 형태로 | 개인정보 (LC-4) |
| AI 응답 원문 | **공개하지 않음** | NG-3 · INV-6 |
| Layer 3 결과 | 발주 기관 전용 | 유료 |
| 방법론 | **전문 공개** | FR-8 · LC-7 완화 |
| 사전 등록 | **측정 전 공개** | ADR-0009 |
| 증거 대장 (`EVIDENCE.md`) | **공개** | 아직 증명하지 못한 것의 목록 |

## 6. 무료와 유료의 경계 — 문구

무료 화면은 **"막혀 있습니다 · 무엇이 막는지는 확인이 필요합니다"** 까지만 말한다.

```
✓  이 누리집은 주요 AI 수집기의 접근을 차단하고 있습니다.
   무엇이 차단하고 있는지는 이 확인만으로는 알 수 없습니다.
   설정 파일일 수도, 보안장비일 수도, 속도 제한일 수도 있습니다.

✗  robots.txt의 Disallow 규칙을 삭제하시면 해결됩니다.
```

**이것은 판매 전략이 아니라 정직이다.** 막는 주체는 진단 없이 실제로 판별되지 않는다. 원인을 안다고 말하면 그것이 거짓이 된다.

단, **무예산으로 확인할 수 있는 것은 알려 준다.**

```
담당 부서에 "무엇이 AI 수집기 접근을 막고 있는지 확인해 달라"고
요청해 보십시오. 설정 파일이라면 그 자리에서 답이 나옵니다.
보안장비나 속도 제한이라면 확인에 며칠 걸립니다.
어느 쪽이든 확인 자체는 비용이 들지 않습니다.
```

`MALFORMED` 판정은 예외적으로 조치를 안내한다 — 설정 오류는 원인이 명확하고, 당일 고칠 수 있으며, 알려 주지 않을 이유가 없다.

## 7. 위기 대응

### 특정 지자체 비난으로 확산되는 경우

- 해당 단위 페이지 상단에 설명 게재문을 끌어올린다.
- 우리 계정으로 순위·비교 게시물을 만들지 않는다.
- 문의에는 **"우리는 상태만 관측하며 평가하지 않는다"**로 일관되게 답한다.

### 우리 판정이 틀린 것으로 밝혀진 경우

- 즉시 정정하고, **정정 사실을 첫 화면에 게시한다.** 조용히 고치지 않는다.
- 같은 유형의 오류가 다른 단위에도 있는지 전수 재점검한다.
- 원인과 재발 방지책을 방법론 페이지에 추가한다.

우리가 남에게 요구하는 절차를 우리에게도 적용한다. 그러지 않으면 이 제품이 요구하는 모든 것이 위선이 된다.
