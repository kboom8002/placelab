# K08 · 유료 상품과 전환 설계

플랫폼(Layer 1·2)은 무료다. **매출은 Layer 3 SaaS와 Layer 4 사업에서 나온다.**

---

## 1. 4종 패키지 — MECE 축

네 사업은 **"무엇을 남기는가"** 로 나뉜다. 이 축이 분할계약 지적을 방어한다(`K05` §4).

| | 사업 | 남기는 것 | 단가 | 기간 |
|---|---|---|---|---|
| **P1** | 주민 질문 대응 실태 진단 | **측정값** | 19,800천원 | 8주 |
| **P2** | 지역정보 정본 정비 | **데이터** | 20,000천원/년 | 연간 |
| **P3** | 주민 AI 기자단 운영 | **사람과 기록** | 20,000천원 | — |
| **P4** | AI 정보체계 운영·갱신 | **지속** | — | 연간 |

각 제안서에는 **「포함하지 않는 범위」** 표가 들어간다. 제외 사유와 그 범위를 담당하는 형제 사업을 명시해, 네 사업이 하나를 쪼갠 것이 아님을 문서 자체가 증명하게 한다.

### P1 — 주민 질문 대응 실태 진단

| 과제 | 예산(천원) |
|---|---|
| 질문 200건 도출 (6개 출처 교차) | 6,200 |
| 대응 상태 4단계 전수 판정 | 6,000 |
| 층화표본 30건 반복 실측 | 2,500 |
| 무예산 조치 목록 | 2,500 |
| 스키마 처방 8종 | 2,000 |
| 작성 지침·견본 3건·우선순위 | 800 |
| **계** | **19,800** |

> **「질문 200건 도출 및 작성 전략」이 이 상품의 핵심이다.** 현장 컨설팅에서 수요가 가장 컸던 항목이며, 플랫폼의 자유 질문 코퍼스(`K04` §4)가 이 과제의 원료를 공급한다. **플랫폼과 사업이 만나는 지점이다.**

### P2 — 지역정보 정본 정비

필수 정본 콘텐츠 200건. **이중 게시** 구조를 쓴다.

- **정본** → 발주기관 공식 누리집 (JSON-LD 포함, 발주기관 귀속)
- **시민기자 기사** → 수행기관 지면 (작성자 권리 보존)

이 구조가 "왜 공공정보가 민간 사이트에 있는가"라는 질문을 해소하면서 SaaS 매출을 보존한다.

A형 특별구역에는 **다국어(영·중·일)** 항목이 추가된다. 투자유치 조직에는 다국어가 선택이 아니라 기본 요구이므로 단가 상승이 자연스럽게 정당화된다.

### P3 — 주민 AI 기자단 운영

30인 + 교육 과정 + 플랫폼 제공. **표준 단가 20,000천원.**

> **가격 방어** — "○○군은 1천만원이던데요?"에 대한 답은 **「최초 적용 사례 대비 확대 범위」 비교표**다. "할인이었다"고 말하지 않는다. 최초 사례는 범위가 좁았고 지금은 넓다 — 이것이 사실이고, 사실로 답한다.

**KPI에 콘텐츠 건수 목표를 넣지 않는다.** 주민 참여자에게 생산량을 부과하면 무상 노동 논란이 된다. 정본 100건은 **수행기관의 과업**으로 명시하고, 기사 송출료 항목은 두지 않는다.

### P4 — AI 정보체계 운영·갱신

연간 운영. **무지명 등장률을 공표 지표로 포함**한다 — 대외 홍보 성과가 이 사업의 존재 이유이기 때문이다.

## 2. Layer 3 SaaS

| | |
|---|---|
| 단가 | **연 300~600만원** |
| 근거 | 소액 수의계약 한도 내 · API 원가 + 운영 |
| 내용 | 자동 반복 측정, 구간 추정, 모델 버전 기록, 맞춤 문항 200건, 정기 리포트 |

**P1~P4와 겹치지 않는다.** Layer 3은 *측정을 계속하는 것*이고, P1은 *한 번 깊이 진단하는 것*이다. Layer 3 계약 기관에는 P1 견적에서 반복 실측 과제(2,500천원)를 제외한다.

---

## 3. 전환 경로

```
Layer 1 무료 조회
   └─ "우리 지역이 닫혀 있다"를 스스로 확인
        │
Layer 2 셀프체크 제출
   └─ 자유 질문 입력 → 우리는 코퍼스를, 그들은 문제의식을 얻는다
        │
기관 계정 개설 (FR-11)
   └─ 이력 추적 · 개선 전후 비교
        │
        ├── Layer 3 SaaS (연 300~600만원)  ← 계속 재는 수요
        └── Layer 4 P1 진단 (19,800천원)   ← 원인을 알고 싶은 수요
                 └── P2 · P3 · P4
```

전환 지표는 `PRD` §14 성공 지표에 있다. **6개월 안에 유상 계약 3건**이 가설 검증의 한 축이다.

## 4. 대상별 접근 논리

| 대상 | 압력 근거 | 예산 과목 | 핵심 메시지 |
|---|---|---|---|
| **기초 지자체** | 공공데이터 제공 운영실태 평가 (226곳 전수) | 정보화 · 평생학습 · 관광진흥 · 인구정책 | 평가 대응 + 주민 오안내 방지 |
| **광역** | 정부합동평가 | 정보화 · 관광진흥 | 시·군 총괄 · 광역 브랜드 |
| **A형 특별구역** | **없음** | 투자유치 · 홍보 · 마케팅 | **투자유치 성과 논리만** |

> **A형에 기초용 자료를 그대로 쓰면 실패한다.** 경제자유구역청은 합동평가·공공데이터 평가 어느 쪽의 대상도 아니다. "평가에 반영된다"는 문장이 통하지 않는다. 대신 그들에게는 **다국어 대외 노출**이라는 다른 축이 있고, 예산은 오히려 유연하다. → `K05` §2

## 5. 영업 일정

지자체 예산은 여름에 편성되고 **11월 21일**(회계연도 개시 40일 전)까지 의회에 간다. 새해 사업으로 들어가려면 **9~10월에 담당자 손에 근거 자료**가 있어야 한다.

Layer 1 무료 결과가 그 근거 자료다. 이것이 플랫폼을 무료로 여는 사업적 이유다.

## 6. 말하지 않는 것

| 금지 | 대체 |
|---|---|
| 세계 최초 · 국내 유일 · 독보적 | 각 요소는 선행이 있고, 우리는 이를 한국 지방행정에 처음 결합한다 (`K11` §6) |
| 우리만의 방법론 | 전면 공개된 방법론 |
| 할인 | 최초 적용 사례 대비 확대 범위 |
| AI 노출 보장 · 상위 노출 | 대응 체계 구축 · 정본 정비 |
| 순위 개선 | 상태 개선 (`차단` → `개방`) |
| 정확도 N% 향상 보장 | 대조군 대비 차이로만 보고 (`K06` §2.5) |

### 경쟁을 언급할 때

**선행 목록을 우리가 먼저 제시한다.** *"LocalBench가 이미 미국 526개 카운티로 했습니다. 우리가 다른 점은 이것입니다"* 로 시작하는 설명이, 나중에 상대에게 지적당하는 설명보다 압도적으로 신뢰받는다.

국내 경쟁을 물으면: *"확인된 국내 GEO·AEO 업체는 모두 기업 대상이고, 공공기관을 측정 대상으로 하는 서비스는 확인되지 않았습니다."* — **"없습니다"가 아니라 "확인되지 않았습니다"** 로 말한다.

---

성과를 계약 지표로 삼을 때는 **우리가 통제할 수 있는 것**만 쓴다 — 정본 게시 건수, 조치 완료 항목 수, 재측정 수행 여부. AI가 어떻게 답하는지는 우리 통제 밖이다(NG-2).
