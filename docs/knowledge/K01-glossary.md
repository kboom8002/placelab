# K01 · 용어 사전

이 제품이 쓰는 말의 정의. **UI 문구와 코드 식별자는 여기를 따른다.**

---

## 측정의 축

### 지명 질문 (named question)

질문에 **단위명이 포함된** 질문. `"포천시 대형폐기물은 어떻게 버리나요?"`

- 측정하는 것: **정확성**. AI가 우리 지역에 대해 아는 내용이 맞는가.
- 판정: `정확 / 부분정확 / 부정확 / 부재` 4단계.
- 실패의 의미: **오답이 나간다.** 주민이 잘못된 안내를 받는다.

### 무지명 질문 (unnamed question)

질문에 **단위명이 없는** 경쟁형 질문. `"가을에 가기 좋은 국내 여행지 5곳을 추천해 주세요."`

- 측정하는 것: **등장 여부**. 그 대화에 우리가 후보로 오르는가.
- 판정: 등장 여부 → 등장 시 내용 정확도.
- 실패의 의미: **대화에 없다.** 오답이 문제가 아니라 언급조차 되지 않는다.

> **이 둘의 구분이 이 제품의 중심 장치다.** 지명은 *정확성 문제*, 무지명은 *존재 문제*다. 담당 부서가 다르고(민원·정보통신 vs 홍보·관광), 조치 방법이 다르고, 예산 과목이 다르다. 하나의 지표로 합치면 둘 다 흐려진다.

### 자유 질문 (free-form question)

셀프체크 참여자가 표준 문항 외에 **직접 써 넣은 질문**. 코퍼스의 원료이며, Layer 2의 진짜 산출물이다.

점수는 편향된 표본에서 나오지만, **"사람들이 실제로 무엇을 묻는가"는 편향된 표본에서도 유효한 정보**다. 이것이 Layer 2를 운영하는 이유다.

---

## 레이어

| 용어 | 정의 |
|---|---|
| **Layer 1 · 기술 접근성** | 서버가 도메인의 수집 허용 규칙·사이트맵·구조화 데이터·TLS를 자동 전수 점검. 편향 없음 |
| **Layer 2 · 셀프체크** | 이용자가 직접 AI에 문항을 넣고 결과를 채점해 제출. 자기선택 편향 있음 |
| **Layer 3 · 통제 측정** | 플랫폼이 API로 조건을 고정해 반복 측정. 유료 |
| **Layer 4 · 진단·정비** | 사람이 수행하는 원인 진단과 정본 정비. 유료 |

## 단위와 도메인

| 용어 | 정의 |
|---|---|
| **모집단 (population)** | `자치단체` 또는 `특별구역`. **합산하지 않는다** (ADR-0002) |
| **자치단체** | 「지방자치법」상 단위. 광역 16 + 기초 227. 행정시 2는 자치단체가 아니므로 분리 집계 |
| **특별구역** | 경제자유구역·규제자유특구·기회발전특구 등 **비자치단체 지정 구역** |
| **A형** | 독립 도메인 구역 — 자체 누리집 + 자체 예산·계약. L1~L4 전부 적용 |
| **B형** | 종속 도메인 구역 — 시·도 도메인 안의 경로/서브도메인. **L1 단독 판정 불가** |
| **C형** | 누리집 없는 구역 — 중앙 포털·시·도 페이지에만 존재. L2 무지명 질문 대상일 뿐 |
| **본청 도메인** | 기관의 대표 누리집 |
| **분리 도메인** | 관광·투자유치 등 별도 운영 도메인. 본청과 판정이 다를 수 있어 별도 행 |

## 판정

| 값 | 의미 |
|---|---|
| `open` | 주요 AI 수집기가 전부 허용됨 |
| `blocked_all` | 대상 수집기 전부가 전면 차단됨 |
| `blocked_selective` | 일부 수집기만 차단됨 |
| `no_file` | `robots.txt` 가 404. 통상 개방으로 해석되나 **sitemap 선언 위치가 없다** |
| `undetermined` | **판정 불가.** 반드시 사유 코드를 동반 |

| 사유 코드 | 의미 |
|---|---|
| `timeout` | 무응답·시간 초과·5xx. 다수 크롤러는 이 경우 보수적으로 수집을 중단한다 |
| `malformed` | `/robots.txt` 자리에 HTML이 반환됨. 차단 의도가 아니라 **설정 오류** |
| `parse_fail` | 파일은 있으나 문법이 파손되어 규칙을 읽을 수 없음 |
| `shared_domain` | 상위 기관과 도메인을 공유해 단독 판정이 불가능함 (B형) |
| `dns_fail` | 도메인 해석 실패. 3주 연속이면 단위 마스터 오류 신호 |

> **관측(observation)과 판정(verdict)은 다르다.** 주간 스캔은 관측이고, 2주 연속 동일할 때만 판정으로 승격되어 공표된다 (ADR-0004).

## 통계

| 용어 | 정의 |
|---|---|
| **전수 (census)** | 모집단 전부를 측정. Layer 1만 해당 |
| **자기선택 편향** | 참여를 스스로 결정하는 구조에서, 참여자가 모집단과 체계적으로 다른 현상 |
| **제출 편향** | 결과가 나쁘면 제출하지 않는 현상. 익명 제출로 완화 |
| **채점자 편차** | 같은 응답에 대해 채점자마다 판정이 다른 현상. 교차 채점으로 일치도 산출 |
| **모델 드리프트** | AI 모델 갱신으로 시점 간 결과가 달라지는 현상 |
| **대조군** | 아무 조치도 하지 않은 채 계속 측정하는 고정 단위군. **개선 효과와 모델 드리프트를 분리하는 유일한 방법** |
| **기준 표본** | 편향 보정용으로 고정 추출한 단위군(30곳 목표). 대조군 역할을 겸함 |
| **구간 추정** | 반복 측정 결과를 점수 하나가 아니라 범위로 제시하는 것. LLM 비결정성 때문에 필수 |
| **명세 버전** | `method_version`. 문항·판정 기준·반복 횟수의 묶음. **버전이 다르면 비교하지 않는다** |

## 제도

| 용어 | 정의 | 이 제품과의 관계 |
|---|---|---|
| **AEO** | Answer Engine Optimization — 검색 노출이 아니라 **AI 답변에 포함되기 위한 정비** | Layer 4의 작업 대상 |
| **정본 (canonical record)** | 기관이 스스로 확정해 게시한 표준 정보. AI가 인용할 근거가 되는 원본 | P2 사업의 산출물 |
| **생활인구** | 「인구감소지역 지원 특별법」상 개념. 등록인구 + 체류인구(월 1회·1일 3시간 이상) | 대외 홍보 프레임의 법정 근거 |
| **합동평가** | 시·도 대상 정부합동평가. **기초 지자체와 특별구역은 대상이 아니다** | 영업 논리의 적용 범위를 가른다 |
| **공공데이터 제공 운영실태 평가** | 기초 226곳 전수 대상 | 기초 대상 영업의 압력 근거 |
| **소액 수의계약** | 일정 금액 이하 수의계약 가능 한도 | 상품 단가 설계의 상한 |
| **개조식** | 한국 공공문서의 항목 나열 서술 방식 (`□ → ○ → - → ·`, 명사형 종결) | 제안서·리포트 출력 형식 |

## 이 제품에서 쓰지 않는 말

| 금지 | 이유 | 대체 |
|---|---|---|
| 순위 · 랭킹 · 등급 · 1위 · 최하위 | NG-1. 측정 조건 차이가 순위를 뒤집는다 | 상태 표시 (`개방/차단/…`) |
| 노출 보장 · 상위 노출 · AI 최적화 보장 | NG-2. 플랫폼사가 결정하는 것을 팔 수 없다 | 정비 · 대응 체계 구축 |
| 전국 평균 (Layer 2에 대해) | NG-4. 자발적 표본은 모집단을 대표하지 않는다 | 참여한 N곳 중 |
| 차단당했다 (판정 불가인 경우) | 관측이 아니라 해석이다 | 판정 불가 · 응답 없음 |
| 할인 | 가격 방어가 무너진다 | 최초 적용 사례 대비 확대 범위 |
