## 1. 문제 진단

v2.0 flat 35문항으로 수원시(120만)와 증평군(3.8만)을 측정한 결과:

- 정확도 83~89% → 높아 보이지만 **전국 동일 절차 문항이 정확도를 끌어올림**
- P5(외국인) 양쪽 100% → 체류·건보·안전신문고는 전국 동일. **변별력 없음**
- "AI가 대한민국 행정을 아는가"를 측정하고 있지, "AI가 이 지자체를 아는가"를 측정하지 못함
- 증평의 핵심 키워드 "인삼"을 프로빙하는 문항이 없음
- 수원의 "화성·갈비·삼성"을 프로빙하는 문항이 없음

**결론:** 컨설팅 산출물로 가치가 없다. 3-Tier로 전환한다.

## 3. Tier 1 · 기본 행정 (15문항, 전 지자체 공통)

### 3.1 선별 원칙

v2.0 35문항에서 **지자체마다 답이 달라지는 것만** 남긴다.

| 제거 사유 | 해당 문항 |
|---|---|
| 전국 동일 절차 | P5-01(체류), P2-06(안전신문고), P6-05(영업신고), P4-03(돌봄), P4-02(건강검진) |
| 전국 동일 시스템 | P2-02(어린이집-아이사랑), P5-02(외국인건보) |
| 국가 사업 | P1-06(문화패스), P1-04(공공일자리) |
| Tier 2로 이동 | P3-05(관광→고유시설), P2-07(놀이시설→고유시설) |
| 변별력 낮음 | P3-06(부동산), P4-04(여가), P5-04(통역), P5-05(한국어) |
| Tier 3으로 이동 | P2-04(학군→비교 질문) |

### 3.2 확정 Tier 1 문항 (15개)

```
B-01  출산     {unit} 둘째 출산지원금이랑 산후조리비 총 얼마야?
B-02  전입     {unit} 전입신고 하면 받을 수 있는 혜택 있어?
B-03  폐기물   {unit} 대형폐기물 스티커 가격이랑 배출 신청 방법 알려줘
B-04  종량제   {unit} 종량제봉투 종류별 가격 알려줘
B-05  민원     {unit} 청/군청 민원실 점심시간에 되는지, 주차요금 얼마야?
B-06  교통비   {unit} 어르신 버스비 지원 대상 나이랑 금액 알려줘
B-07  목욕권   {unit} 어르신 목욕권이나 이미용 지원 있어?
B-08  월세     {unit} 청년 월세 지원 대상 조건이랑 지원 금액 알려줘
B-09  창업     {unit} 청년 창업 지원금이나 창업 공간 지원 있어?
B-10  야간진료  {unit} 밤에 아이가 아프면 갈 수 있는 소아과 어디야?
B-11  돌봄     {unit} 초등 방과후 돌봄교실이나 지역아동센터 정보 알려줘
B-12  다문화   {unit} 다문화가족지원센터 위치랑 프로그램 알려줘
B-13  소상공인  {unit} 소상공인 특례보증 대출 조건 알려줘
B-14  세무     {unit} 소상공인 무료 세무 상담 받을 수 있는 곳 있어?
B-15  축제     {unit} 올해 열리는 대표 축제 일정이랑 장소 안내해줘
```

### 3.3 Tier 1 채점 기준

| 판정 | 정의 | 코드 |
|---|---|---|
| **정확** | 해당 지자체의 구체적 정보(금액·날짜·장소)가 사실과 일치 | `accurate` |
| **부분** | 방향은 맞으나 금액·조건이 구 데이터이거나 불완전 | `partial` |
| **오답** | 사실과 다른 정보(작화 포함). `작화`는 `floor_risk=critical` | `wrong` |
| **미응답** | 응답 없음 또는 "확인해보세요"만 | `absent` |

## 4. Tier 2 · 지자체 고유 정보 (20문항, 사전 조사 후 생성)

### 4.1 생성 프로세스

```
Step 1: 크롤링 (자동)
  └── 군청/시청 사이트 주요 페이지 수집
  └── 관광포털, 위키백과, 나무위키, 뉴스 수집
  └── 구조화 데이터(JSON-LD, OG 태그) 추출

Step 2: AI 초안 (자동)
  └── 수집 콘텐츠 기반 질문 후보 50개 생성
  └── 카테고리별 균등 배분 (7카테고리 × ~7개)
  └── Ground Truth 후보 함께 생성

Step 3: 컨설턴트 검수 (수동, 2~4시간)
  └── 50개 → 20개 선별
  └── Ground Truth 사실 확인
  └── 난이도 균형 조정
  └── 작화 유도 가능성 높은 문항 우선 선별
```

### 4.2 7개 카테고리

각 카테고리에서 **2~4문항**을 배분하여 총 20문항.

#### C1. 특산·산업

해당 지자체의 대표 산업, 특산물, 주요 기업.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 수원에 삼성전자 사업장 있어? 뭐 하는 곳이야? | 증평 인삼이 유명한 이유가 뭐야? |
| GT | 삼성전자 수원 디지털시티, 반도체·모바일 R&D | 보강천 사질양토, 6년근 재배 |

#### C2. 고유 시설·랜드마크

그 도시에만 있는 시설, 관광지, 공공시설.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 수원화성 야간 관람 시간이랑 입장료 알려줘 | 증평 인삼 전시관이나 박물관 있어? |
| GT | 화성행궁 야간 19:00~21:30, 성인 1,500원 | 증평민속체험박물관 |

#### C3. 독자 정책·조례

타 지자체에 없는 고유 정책.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 수원시 1인 가구 지원 정책 있어? | 증평군 귀농귀촌 지원금 있어? |
| GT | 1인가구 네트워크, 안심 서비스 | 주거비·농기계·교육비 지원 |

#### C4. 역사·문화재

지역 고유 유산, 인물, 사건.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 정조대왕이 수원화성을 만든 이유가 뭐야? | 증평이 독립된 군이 된 게 언제야? |
| GT | 사도세자 현륭원 참배 행차 | 2003년 괴산군에서 분리 |

#### C5. 지리·생활권

동네 이름, 생활권, 교통 결절.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 광교와 영통의 차이가 뭐야? | 증평에서 서울까지 어떻게 가? |
| GT | 광교=신도시(2011~), 영통=기존 주거 | 중부고속도로, 증평IC, 약 1시간 30분 |

#### C6. 로컬 음식·명소

지역 대표 음식, 먹거리 거리.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 수원 갈비 맛집 거리가 어디야? | 증평 대표 음식 뭐야? |
| GT | 팔달문·영동시장 일대 | 인삼요리(인삼튀김·인삼백숙) |

#### C7. 최근 이슈·사업

1년 이내 주요 사업, 개발, 이슈.

| | 수원시 예시 | 증평군 예시 |
|---|---|---|
| 질문 | 수원 컨벤션센터 건립 진행 상황? | 증평 복합커뮤니티센터 언제 개관? |
| GT | 추진 중(또는 착공 등 현재 상태) | 해당 시점의 최신 정보 |

### 4.3 Tier 2 채점 기준

기본 4분법 + **관련성 점수(Relevance Score)** 추가.

| 판정 | 정의 | 코드 |
|---|---|---|
| **정확+관련** | 해당 지자체 고유 정보가 포함되어 있고 사실과 일치 | `accurate_relevant` |
| **정확+범용** | 답은 맞으나 전국 공통 정보만 제공 (예: "시청에 문의하세요") | `accurate_generic` |
| **부분** | 방향은 맞으나 불완전하거나 구 데이터 | `partial` |
| **오답** | 사실과 다른 정보 (작화 = `floor_risk=critical`) | `wrong` |
| **미응답** | 응답 없음 | `absent` |

> **`accurate_generic`은 Tier 2에서 낮은 점수.** "시청에 문의하세요"는 Tier 1에서는 부분 정확이지만, Tier 2에서는 **AI가 고유 정보를 모른다**는 증거.

## 5. Tier 3 · 대외 홍보력 (15문항, 6유형)

### 5.1 6가지 질문 유형

#### T3-A. 추천 경쟁 (3문항)

"○○하기 좋은 도시 추천해줘" — 우리 도시가 언급되는가?

```
V-A1  {도} 에서 살기 좋은 도시 3곳 추천해줘
V-A2  {도} 에서 {특성}하기 좋은 곳 어디야?
V-A3  한국에서 {키워드} 하면 어디가 유명해?
```

| | 수원시 | 증평군 |
|---|---|---|
| V-A1 | 경기도에서 살기 좋은 도시 3곳 | 충북에서 살기 좋은 곳 3곳 |
| V-A2 | 경기도에서 역사 관광하기 좋은 곳 | 충북에서 귀농귀촌하기 좋은 곳 |
| V-A3 | 한국에서 성곽 관광 유명한 곳 | 한국에서 인삼 산지 유명한 곳 |

#### T3-B. 연상 테스트 (2문항)

"○○ 하면 뭐가 떠올라?" — 브랜드 연상력.

```
V-B1  {unit} 하면 뭐가 떠올라? 세 가지 말해줘
V-B2  {unit}의 별명이나 슬로건이 뭐야?
```

#### T3-C. 키워드 진입 (3문항)

특산·산업 키워드로 도시에 도달하는가?

```
V-C1  한국에서 {특산물} 유명한 곳 어디야?
V-C2  {산업} 관련 기업이 있는 한국 도시 알려줘
V-C3  {문화재/관광자원} 있는 도시가 어디야?
```

| | 수원시 | 증평군 |
|---|---|---|
| V-C1 | 한국에서 갈비 유명한 곳 | 한국에서 인삼 유명한 곳 |
| V-C2 | 반도체 기업 있는 한국 도시 | — (산업단지 소규모) |
| V-C3 | 유네스코 세계유산 있는 도시 | 자연휴양림 좋은 곳 |

#### T3-D. 시나리오 질문 (3문항)

구체적 상황에서 이 도시가 나오는가?

```
V-D1  서울에서 {시간}대로 갈 수 있는 {유형} 추천해줘
V-D2  {상황}인데 {도}에서 적합한 도시 어디야?
V-D3  {대상}이 {목적}하기 좋은 한국 도시 추천해줘
```

| | 수원시 | 증평군 |
|---|---|---|
| V-D1 | 서울에서 1시간대 역사 관광지 | 서울에서 1시간 30분대 귀촌 후보지 |
| V-D2 | 전세 만기인데 경기도에서 가족 살기 좋은 곳 | 은퇴 후 충북에서 조용히 살 곳 |
| V-D3 | IT 종사자가 출퇴근 편한 수도권 도시 | 50대 부부가 텃밭 가꾸며 살 곳 |

#### T3-E. 비교 질문 (2문항)

경쟁 도시와 직접 비교.

```
V-E1  {unit}이랑 {경쟁도시} 중 {기준}에 좋은 곳은?
V-E2  {unit}과 {경쟁도시}의 차이점이 뭐야?
```

| | 수원시 | 증평군 |
|---|---|---|
| V-E1 | 수원이랑 용인 중 가족이 살기 좋은 곳 | 증평이랑 괴산 중 귀농하기 좋은 곳 |
| V-E2 | 수원과 성남의 차이점 | 증평과 진천의 차이점 |

#### T3-F. 부정 테스트 (2문항)

AI가 부정적 정보를 어떻게 다루는가?

```
V-F1  {unit}의 단점이나 주의할 점 알려줘
V-F2  {unit}에서 살면 불편한 점이 뭐야?
```

> **채점:** 부정 테스트는 정확성이 아니라 **균형성**을 본다.
> - 단점을 말하면서 장점도 언급하는가?
> - 근거 없는 부정적 주장(역작화)이 있는가?
> - 특정 지자체를 나쁜 사례로 지목하는가? (AGENTS.md 문구 규칙 위반 여부)

### 5.2 Tier 3 채점 기준

| 판정 | 정의 | 코드 |
|---|---|---|
| **언급+긍정** | 우리 도시가 언급되고 긍정적 맥락 | `mentioned_positive` |
| **언급+중립** | 우리 도시가 언급되나 중립적 | `mentioned_neutral` |
| **언급+부정** | 우리 도시가 언급되나 부정적 맥락 | `mentioned_negative` |
| **미언급** | 우리 도시가 언급되지 않음 | `not_mentioned` |

**핵심 지표: Share of Voice (SoV)**

```
SoV = (우리 도시 언급 횟수) / (전체 Tier 3 응답 수) × 100
```

경쟁 도시의 SoV도 함께 기록하여 **상대적 위치**를 파악.

### 5.3 Tier 3 표시 규칙

- AI 답변에서 순위가 나오면 **원문 그대로 인용**
- "이 순위는 AI 서비스의 응답이며, kplacelab의 판단이 아닙니다" 단서 필수
- INV-3: kplacelab이 자체적으로 순위를 만들지 않음. AI가 만든 순위를 인용할 뿐.

## 7. 자동화 파이프라인

### 7.1 Tier 2 질문 생성 자동화

```
입력: unit_name, unit_url
  │
  ├─ Step 1: 크롤링 (자동)
  │   ├── 시청/군청 메인 + 관광포털 + 뉴스 RSS
  │   ├── JSON-LD, OG 태그, 메타데이터 추출
  │   └── 출력: content_corpus.json (최대 50페이지)
  │
  ├─ Step 2: AI 질문 생성 (자동)
  │   ├── GPT에 corpus + 7카테고리 + 질문 템플릿 제공
  │   ├── 50개 질문 후보 + Ground Truth 후보 생성
  │   └── 출력: question_candidates.json
  │
  ├─ Step 3: 컨설턴트 검수 (수동, 2~4시간)
  │   ├── 50개 → 20개 선별
  │   ├── Ground Truth 사실 확인
  │   └── 출력: tier2_questions.json (확정)
  │
  └─ Step 4: 측정 (자동)
      ├── 20문항 × 3회 = 60회 API 호출
      └── 출력: tier2_results.json
```

### 7.2 Tier 3 질문 생성

Tier 3은 **템플릿 기반으로 반자동 생성**.

입력: `unit_name`, `province`, `competitor_cities[]`, `keywords[]`
출력: 15문항 (6유형 × 2~3개)

## 9. method_version 관리
