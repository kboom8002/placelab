파생물: `supabase/seed/questions.csv`

| | |
|---|---|
| `method_version` | `v1.0` |
| 지명 | 12문항 (`N01`~`N12`) |

> **문항을 바꾸면 `method_version` 을 올린다.** 코드나 CSV만 고치는 것은 금지한다. 문항이 바뀌면 과거 관측과 비교할 수 없다.

> ⚠️ **v1.0 문항은 아직 강건성 검사를 통과하지 않았다.** [ADR-0007](../adr/0007-questions-are-instruments.md)에 따라, 아래 20문항은 **파일럿 검사를 거쳐 v1.1에서 확정**된다. 검사에서 민감 문항으로 판정된 것은 문구를 다듬거나 제외하므로 **문항 수가 20에서 줄 수 있다.** 검사 완료 전에는 어떤 수치도 공표하지 않는다.

## 0. 문항은 8블록으로 저장한다

프롬프트를 자연어 덩어리로 두면 **무엇을 바꿨을 때 결과가 달라지는지 기술할 수 없다.** 문항을 바꿨는지, 지시문을 바꿨는지, 출력 형식을 바꿨는지가 버전 하나에 뭉친다.

| 블록 | 역할 | 지명 문항 기본값 |
|---|---|---|
| `A` Actor | 화자 프레임 | (없음) — 변형 시 `주민입니다` / `여행을 검토 중입니다` |
| `S` Situation | 상황·제약 | `웹 검색을 하지 마세요. 알고 있는 지식만으로 답해 주세요.` |
| `T` Task | 문항 본문 | 아래 §1 |
| `K` Knowledge | 제공 지식 | (없음) — 개입 조건(Intervention)에서만 정본 발췌 주입 |
| `W` Workflow | 수행 절차 | `각 항목마다 답변 2~3문장 + 확신도` |
| `F` Format | 출력 형식 | `[번호] 답변 / 확신도: 높음\|보통\|낮음` |
| `L` Language | 언어 | `ko` |
| `O` Output | 마무리 요구 | `마지막에 확신도를 표로 정리` |

각 블록이 **독립변수**다. `A` 만 바꾸면 화자 프레임 민감도가, `K` 만 바꾸면 정본 제공 효과가 측정된다. 강건성 검사(`K03` M-2.6)와 조건 민감도(`K03` M-2.7)가 **같은 장치로** 처리된다.

> **참여자에게는 블록을 보여주지 않는다.** 셀프체크 화면에는 조립된 자연어 프롬프트를 보여준다. 구조는 우리 쪽 저장 형식이며, 참여자에게 방법론을 설명하는 비용을 지우지 않는다.

### 문항 설계상의 주의

- `U03` 은 **수도권 기준으로 쓰여 있다.** 비수도권 단위에는 편향된 문항이다. v1.0에서는 그대로 두되 **한계로 공개 명시**하고, v1.1에서 권역별 변형을 검토한다.
- `U01`·`U04`·`U08` 은 `{상위광역}` 치환이 필요하다. 광역 단위를 측정할 때는 자기 자신이 들어가므로 치환 규칙이 달라진다 — 광역은 `U02`·`U03`·`U05`·`U06`·`U07` 5문항만 유효하며, 이 경우 슬롯 수가 25로 줄어든다. **집계 시 분모를 문항 수에서 계산한다.**
- 총 슬롯 = 유효 문항 수 × 5.

## 3. 채점 지침

### 3.1 원칙

> **채점은 AI에게 시키지 않는다.**
>
> "이 답이 맞는지 알려줘"라고 물으면 AI가 자기 답을 자기가 평가한다. 그것은 측정이 아니다. 맞는지 틀린지는 **사람이 직접 표시**해야 하고, 그래야 결과를 남에게 보여줄 수 있다.

### 3.1a 두 축을 먼저 본 뒤 4단계를 매긴다

채점자는 **골격과 세부를 따로** 판단한 뒤 4단계를 고른다. 이 순서가 판정을 일관되게 만든다.

```
① 절차의 뼈대가 맞는가?            → skeleton_match  ○ / ✕
② 금액·창구·기한·요일이 맞는가?    → detail_match    ○ / ✕ / 해당없음
③ 위 둘을 근거로 4단계를 고른다
```

| skeleton | detail | 통상 판정 |
|---|---|---|
| ○ | ○ | `정확` |
| ○ | ✕ | `부분정확` |
| ✕ | — | `부정확` 또는 `부재` |

**작화 표시** — 존재하지 않는 제도·창구·기한을 구체적으로 명시했다면 `confabulation` 을 별도 체크한다. 이것이 Floor Risk `critical` 을 만든다(`K03` M-2.3.1).

### 3.2 지명 4단계

| 판정 | 조작적 정의 | 예 |
|---|---|---|
| `정확` | 핵심 사실이 맞고, 그대로 따라 해도 문제가 없다 | 신청 창구·수수료·절차가 실제와 일치 |
| `부분정확` | 방향은 맞으나 세부(금액·기간·부서·절차)가 틀리거나 빠졌다 | 절차는 맞는데 수수료가 다름 |
| `부정확` | 핵심 사실이 틀렸다. 따라 하면 잘못된 행동을 하게 된다 | 없는 제도를 있다고 답함 |
| `부재` | 모른다고 했거나, 우리 지역이 아닌 일반론만 말했다 | "대부분의 지자체에서는…" |

**경계 사례**

| 상황 | 판정 |
|---|---|
| 일반론만 말했다 | `부재` — 우리 지역에 대한 답이 아니다 |
| 맞지만 오래된 정보다 | `부분정확` |
| 3개 물었는데 1개만 답했다 | `부분정확` |
| 맞는데 확신도를 낮음으로 표시했다 | 내용으로만 판정. 확신도는 별도 기록 |
| 다른 지자체 정보를 말했다 | `부정확` |
| 답변을 거부했다 | `부재` |

### 3.3 무지명 2단계

1. **등장했는가** — 우리 단위명이 추천 목록에 나왔는가. 인접 지역명이나 상위 광역명만 나온 것은 등장이 아니다.
2. 등장했다면 **추천 이유가 맞는가** — `맞음` / `틀림`.

### 3.4 채점자 편차 관리

- 판정 기준을 이 문서로 공개한다(FR-8).
- Layer 3 관측의 일부를 **교차 채점**해 일치도를 산출하고, 발표 자료에 함께 기재한다.
- 일치도가 낮은 문항은 v1.1에서 문구를 다듬거나 제외한다.

### 3.5 Judge 모델 — Layer 3 한정

**Layer 2의 채점은 사람만 한다.** 참여자가 직접 채점하는 것이 그 층의 의미다.

Layer 3은 문항 × 반복 × 조건 × 단위를 사람이 전부 채점할 수 없으므로 Judge 모델을 쓴다. 단, 다섯 조건을 모두 지킨다 — 응답 생성 모델과 분리 / 기준은 사람이 작성한 §3.2를 그대로 제공 / 표본 교차채점 / 일치도 기재 / Judge 모델·버전 기록. 상세는 `K03` M-2.8.

> **"AI에게 자기 답을 채점시키지 않는다"** 는 원칙은 유지된다. 별도 모델이 사람이 만든 기준으로 채점하고 사람이 일치도를 검증하는 것은 자기평가가 아니다.

## 3.6 강건성 검사 절차 (채택 조건)

파일럿 설계:

| 항목 | 값 |
|---|---|
| 대상 단위 | 3~5곳 (유형·규모 분산) |
| 문항 | 20문항 전부 |
| 변형 | 원문 + `punct` · `polite` · `order` · `frame` = 5종 |
| 반복 | 변형당 R회 |
| AI 서비스 | 최소 2종 |

산출:

1. 문항별 **변형 간 판정 분포 차이**
2. **임계값** — 파일럿 분포를 보고 정한다. 사전에 정하지 않는다
3. **민감 문항 목록** — 임계값 초과분
4. 개정 문항 세트 → `method_version v1.1`

민감 문항 처리:

- 1차: 문구를 다듬어 재검사 (예: 중의적 표현 제거, 문항을 둘로 분리)
- 2차: 재검사에도 민감하면 **명세에서 제외**

**검사 결과는 문항별로 공개한다.** 민감 문항이 있다는 사실을 숨기는 것이 아니라, 어떤 문항이 얼마나 민감한지를 밝히는 것이 성실성이다.

## 4. 자유 질문 수집

표준 문항 외에 참여자가 직접 써 넣는다. **Layer 2의 진짜 산출물이다.**

### 수집 문구

```
이 지역에 대해 AI에게 물어보고 싶었던 질문이 있다면 적어 주세요.
표준 문항에 없는 것일수록 좋습니다.
```

### 규칙

- **개인정보를 포함할 수 있다고 가정한다.** 자동 1차 필터를 거치되, 필터는 차단이 아니라 **표시**이고 최종 판단은 사람의 검수 큐에서 한다.
- `pii_checked = true` 가 되기 전에는 어떤 공개 경로로도 나가지 않는다(DB CHECK 제약).
- 지명/무지명 구분을 참여자에게 묻지 않고 **검수 단계에서 분류**한다. 참여자에게 개념을 설명하는 비용이 크다.
- 원문(`body`)과 정제본(`redacted_body`)을 모두 보관한다. 공개는 정제본만.

### 왜 가치가 있는가

점수는 편향된 표본에서 나온다. 그러나 **"사람들이 실제로 무엇을 묻는가"는 편향된 표본에서도 유효한 정보다.** 우리가 만든 12문항은 우리의 추측이고, 자유 질문은 현장의 사실이다. 이것이 P1 진단의 「질문 200건 도출」과 직접 연결되며, 실제로 지자체 컨설팅에서 가장 수요가 큰 항목이었다.
