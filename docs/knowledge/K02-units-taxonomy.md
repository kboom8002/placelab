> **신뢰 등급: 인용** — 광역 16은 전남광주통합특별시 출범을 반영한 값이다. 기초 227과 광역 16의 정확한 현재 값은 **행정안전부 자료로 착수 전 재확인**한다. 통폐합이 있으면 이 숫자가 바뀌고, 그것이 모든 공표 문장의 분모다.

### 식별자 규칙

```
자치단체   lg-{행정표준코드}        예) lg-41650  (포천시)
특별구역   sz-{제도}-{약칭}          예) sz-fez-ifez
```

행정표준코드를 쓰는 이유는 통폐합·명칭 변경이 있어도 **외부 통계와 조인 가능**하기 때문이다. 명칭 기반 식별자는 쓰지 않는다.

### 폐지·통합 처리

**행을 지우지 않는다.** `active = false` 로 내리고, 후신 단위가 있으면 `parent_unit_id` 대신 별도 이력 테이블에 기록한다. 과거 관측이 가리키는 단위가 사라지면 시계열이 끊긴다.

## 3. 특별구역

### 3.1 도메인 보유 형태 3분류

> **구역은 측정할 수 없다. 측정되는 것은 그 구역을 운영하는 주체의 누리집이다.**

Layer 1의 판정 대상인 `robots.txt`·sitemap·TLS는 **도메인 단위로만 존재**한다. 자체 도메인이 없는 구역은 기술적으로 단독 판정이 불가능하다.

| 형 | 정의 | 적용 레이어 | 계약 주체 |
|---|---|---|---|
| **A** | 독립 도메인 — 자체 누리집 + 자체 예산·계약 | L1~L4 전부 | 해당 청 |
| **B** | 종속 도메인 — 시·도 도메인 안의 경로/서브도메인 | L1 **불가**, 페이지 지표만 · L2~L4 가능 | 소관 시·도 |
| **C** | 누리집 없음 — 중앙 포털·시·도 페이지에만 존재 | **L2 무지명 질문만** | 소관 시·도 / 중앙부처 |

**자치단체는 정의상 전부 A형이다.** A/B/C는 특별구역만의 구분이 아니라 모든 단위에 적용되는 도메인 보유 형태이며, 자치단체는 자체 도메인을 갖는다.

### 3.3 규제자유특구 — C형

> **신뢰 등급: 인용** — 2019년 제도 도입 후 2026년 7월까지 누적 55개 지정. 2026-09-01 제19차 규제자유특구위원회에서 **광역연계형 2곳**(스마트농업 — 전남광주 중심·전북·충남 참여 / 신해양레저 — 경북 중심·부산 협력)이 처음 지정되었다.

특구는 대부분 **자체 누리집이 없다.** 중기부 통합 포털(`rfz.go.kr`)과 소관 시·도 페이지에만 존재하므로 Layer 1 대상이 아니다.

**측정 가치는 무지명 질문에 있다.** `"○○ 규제자유특구가 무엇인가요?"` `"자율주행 실증이 가능한 지역은 어디인가요?"` 에 AI가 답하는가 — 이것은 도메인 판정이 아니라 응답 측정의 문제다.

## 4. 도메인 등록 규칙

### 4.1 역할

| `role` | 대상 | 비고 |
|---|---|---|
| `main` | 본청 대표 누리집 | 집계의 기준. **단위당 정확히 하나** |
| `tourism` | 관광 전용 도메인 | 분리 운영 시에만. 본청과 판정이 다를 수 있다 |
| `invest` | 투자유치 도메인 | A형 특별구역에서 흔하다 |
| `other` | 그 외 | 집계에 포함하지 않는다 |

`v_layer1_coverage` 는 `role = 'main'` 만 집계한다. 관광 도메인을 섞으면 단위 수가 부풀려진다.

### 4.2 호스트 표기

- **`www` 유무를 확정해 기록한다.** 리다이렉트가 있어도 `robots.txt` 는 호스트별로 다를 수 있다.
- 스킴은 저장하지 않는다. 항상 `https` 로 조회하고, HTTP 전용 사이트는 관측 결과에 기록한다.
- **한 호스트는 스캔 대상으로 단 한 단위에만 귀속된다.** DB 유니크 인덱스가 강제한다 — 울산광역시와 울산경제자유구역이 같은 호스트를 각각 등록하는 사고를 막는다.

### 4.3 B형의 `path_prefix`

B형은 `path_prefix` 를 기록한다(`/eco`, `/s/ufez`). Layer 1 판정에는 쓰이지 않지만, **페이지 수준 지표**(meta robots, JSON-LD, hreflang)는 그 경로에서 측정할 수 있다.

화면에는 반드시 병기한다:

> 이 값은 소관 시·도 도메인(`www.ulsan.go.kr`)의 값입니다.

이를 생략하면 구역의 성과·책임을 시·도에 잘못 귀속시킨다.

## 5. 마스터 구축 절차 (사전 단계)

1. **행정표준코드 목록 확보** — 행정안전부 원문. 광역·기초·특례시·행정시 구분 확정.
2. **본청 도메인 수집** — 기관 목록에서 대표 누리집 추출. `www` 유무 확정.
3. **관광 도메인 식별** — 분리 운영 여부 확인. 판단이 애매하면 `other` 로 두고 집계 제외.
4. **특별구역 A/B/C 판정** — 자체 도메인 보유 여부를 직접 조회해 확인.
5. **중복 호스트 검출** — 같은 호스트를 두 단위가 쓰는 경우를 전부 찾아 B형으로 처리.
6. **검증 조회 1회** — 전 도메인에 대해 DNS 해석과 TLS 연결만 확인. 실패 도메인은 재수집.

이 절차가 끝나야 `4분 판정 규칙표 확정`과 함께 사전 단계가 종료된다(PRD §14).
