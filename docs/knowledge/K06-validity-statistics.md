# K06 · 타당도와 통계 규칙

**이 문서가 없으면 이 제품은 "그럴듯한 숫자 생성기"가 된다.**

여기 적힌 것은 스타일 가이드가 아니라 **무엇을 말할 수 있고 무엇을 말할 수 없는가**의 경계다.

---

## 1. 레이어별로 정당한 분모

| 레이어 | 수집 | 정당한 분모 | 정당한 문장 |
|---|---|---|---|
| Layer 1 | 서버 자동 · 전수 | **전국 243곳** (모집단별) | `자치단체 243곳 중 N곳이 …` |
| Layer 2 | 사람 · 자발적 제출 | **참여한 N곳** | `참여한 25곳 중 N곳이 …` |
| Layer 3 | API 자동 · 조건 통제 | **측정한 N곳** | `동일 조건으로 측정한 12곳에서 …` |

Layer 2에 전국 분모를 쓰는 순간 NG-4 위반이다. 이것을 타입과 뷰 설계로 막는다. → [ADR-0005](../adr/0005-layer-separation.md)

## 2. 여섯 가지 타당도 위협

### 2.0 측정 도구 아티팩트 (Measurement Phantom) — 가장 먼저 막아야 할 것

**문제** — 문항의 표현이 결과를 바꾼다면, 우리가 잰 "지자체 간 차이"가 대상의 속성이 아니라 **프롬프트의 아티팩트**일 수 있다. 재현은 잘 되는데, 재현되는 것이 우리가 재려던 것이 아닌 상태다.

**왜 첫 번째인가** — 다른 다섯 위협은 해석과 보고의 문제이지만, 이것은 **측정 자체가 성립하는가**의 문제다. 여기가 뚫리면 아래 모든 대응이 무의미하다. 그리고 소급 보정이 불가능하다.

**대응**

1. **문항 강건성 검사를 채택 조건으로 둔다** (`K03` M-2.6). 4개 변형 축(`punct`·`polite`·`order`·`frame`)에서 임계값을 넘는 문항은 명세에 넣지 않는다.
2. **임계값이 정해지기 전에는 어떤 수치도 공표하지 않는다.**
3. 문항을 8블록으로 저장해 **무엇을 바꿨는지 기술 가능**하게 한다.
4. 검사 결과를 문항별로 공개한다.

→ [ADR-0007](../adr/0007-questions-are-instruments.md) · `K10` §1

## 2.1~2.5 · 나머지 다섯 위협

### 2.1 자기선택 편향

**문제** — 재보는 사람은 이미 관심 있는 사람이다. 참여 표본이 모집단을 대표하지 않는다.

**대응**

1. **Layer 1 전수 자동 수집으로 편향 없는 기준선을 확보한다.** 이것이 유일한 근본 해법이다.
2. **무지명 기준 표본 30곳**을 별도로 추출해 측정하고, 참여 표본과 대조한다.
3. 모든 Layer 2 집계에 `참여한 N곳` 표기를 강제한다.

**기준 표본 추출 방식** — 유형(광역/시/군/자치구) × 인구 규모 × 권역으로 층화한 뒤 무작위 추출. 한 번 뽑으면 **고정한다.** 표본을 바꾸면 시계열이 끊긴다.

> 30곳이 편향 보정과 대조군 역할을 동시에 할 수 있는지는 통계 자문이 필요하다. `PRD` §15 미결.

### 2.2 제출 편향

**문제** — 결과가 나쁘면 제출하지 않는다.

**대응**

1. **익명 제출을 기본값으로** 한다.
2. 제출 즉시 요약 피드백을 준다 — 제출의 대가를 즉시 지급해야 나쁜 결과도 들어온다.
3. **익명분과 실명분의 분포 차이를 모니터링 지표로 관리한다.** 두 분포가 크게 다르면 제출 편향이 실재한다는 증거이며, 그 사실 자체를 공표한다.

### 2.3 채점자 편차

**문제** — 같은 응답에 대해 채점자마다 판정이 다르다.

**대응**

1. 판정 기준을 **조작적으로 정의**해 공개한다 (`K04` §3.2).
2. 일부 관측을 **교차 채점**해 일치도를 산출한다.
3. **일치도를 발표 자료에 함께 기재한다.** 숨기면 나중에 지적당하고, 먼저 밝히면 방법론의 성실성이 된다.

### 2.4 조건 불통제

**문제** — AI 종류·버전·개인화·검색 사용이 결과를 바꾼다.

**대응**

1. **조건 필수 입력.** 없으면 저장을 거부한다(DB NOT NULL).
2. 집계는 **동일 조건 내에서만** 한다.
3. Layer 2·3 데이터를 분리한다.

특히 **웹 검색**이 결정적이다. 켜면 대체로 정확해지므로 측정이 되지 않는다. 켠 상태의 관측은 저장하되 별도 조건으로 분리하고 같은 표에 넣지 않는다.

### 2.5 모델 드리프트 — 가장 위험한 것

**문제** — AI 모델이 갱신되면 시점 간 결과가 달라진다. **우리 개선 때문인지 모델이 좋아져서인지 구분할 방법이 없다.**

이것이 해결되지 않으면 이 제품의 성과 주장은 전부 무효다. "저희가 정비한 뒤 정확도가 40%에서 65%로 올랐습니다"라는 문장은, 같은 기간 아무것도 하지 않은 지자체도 60%로 올랐다면 **거짓말**이다.

**대응 — 대조군 설계**

> 아무 조치도 하지 않은 단위들을 **같은 시점에 같은 방법으로** 계속 측정한다. 그 집단의 평균 변화가 모델 드리프트이고, **개선 폭은 대조군 대비 차이만큼만 보고한다.**

```
보고 가능한 개선 = (조치 단위 변화) − (대조군 평균 변화)
```

이 값이 음수면 "개선되지 않았다"고 쓴다. 절대값이 올랐다는 이유로 성과를 주장하지 않는다.

**추가 장치**

- 모든 관측에 `model_version` 을 기록한다.
- 모델 갱신이 확인되면 그 시점을 시계열에 **표시**한다.
- 대조군은 기준 표본(FR-17)이 겸한다.

## 3. 반복과 구간 추정 — 그리고 Floor

### LLM은 비결정적이다

같은 질문에 다른 답이 나온다. **1회 관측은 측정이 아니라 일화다.**

### 평균은 피해자를 지운다

정확도 평균 80%는 안전해 보인다. 그러나 다섯 번 물어 네 번 맞고 **한 번 "그런 제도는 없습니다"** 라고 답한다면, 그 한 번은 주민 한 사람이 실제로 겪는 일이다.

**행정정보에서 보고의 기준 지표는 평균이 아니라 Floor(최악)다.** 산정 규칙은 `K03` M-2.3.1, 근거는 [ADR-0006](../adr/0006-distribution-over-score.md).

그리고 `부재`와 `작화`를 같은 무게로 평균하지 않는다. **"모르겠습니다"는 주민을 공식 창구로 보내지만, 그럴듯한 오답은 없는 창구로 보낸다.**

| 레이어 | 최소 반복 | 이유 |
|---|---|---|
| Layer 2 지명 | 1회 | 참여 부담. **참고값임을 명시** |
| Layer 2 무지명 | 3회 | 등장 여부는 변동이 크다 |
| Layer 3 | 5회 이상 | 유료 측정은 구간을 낼 수 있어야 한다 |

### 점 추정을 쓰지 않는다

```
✗  등장률 12%
✓  등장률 8~17% (5회 반복, 95% 구간)
```

구간을 낼 수 없는 데이터(Layer 2 지명 1회)는 **애초에 비율로 표시하지 않는다.** `12문항 중 5문항 정확` 처럼 원값으로 쓴다.

### 반복 횟수가 적을 때

반복이 3회 미만이면 구간이 무의미하게 넓다. 이 경우 **분포를 그대로 보여준다** — `3회 중 1회 등장` 처럼.

## 4. 절대 하지 않는 서술

| 금지 | 왜 |
|---|---|
| Layer 2 데이터로 `전국 N곳 중` | 자기선택 편향. NG-4 |
| Layer 1과 Layer 2를 같은 표·같은 축에 | 편향 성격이 다르다 |
| Layer 2와 Layer 3을 같은 표에 | 측정 조건이 다르다 (앱 vs API) |
| 두 모집단 합산 | ADR-0002 |
| 대조군 없이 개선 효과 주장 | §2.5 |
| 순위·등급 | NG-1 |
| 상관을 인과로 서술 | 도메인 접근성과 응답 정확도의 인과는 이 측정으로 증명되지 않는다 |
| `method_version` 이 다른 관측 비교 | 문항이 다르면 다른 측정이다 |
| 강건성 검사를 통과하지 않은 문항의 결과 공표 | 아티팩트일 수 있다 (§2.0) |
| 평균만 제시하고 Floor를 생략 | 평균은 피해자를 지운다 (§3) |
| AI 응답에서 감정·태도를 추론해 지자체 특성으로 귀속 | 감정 추론은 과학적 근거가 약하고 EU AI Act가 문제 삼는 영역이다 |

### 특히 조심할 문장 하나

> "`robots.txt` 를 열었더니 AI 응답 정확도가 올랐습니다."

**이 인과는 증명되지 않았다.** 도메인 접근성(Layer 1)과 응답 정확도(Layer 2·3) 사이에는 AI 학습 주기·인덱싱·모델 갱신이 끼어 있고, 그 경로를 우리는 관측할 수 없다.

말할 수 있는 것은 **"열었다"**(사실)와 **"그 뒤 값이 이렇게 변했다"**(사실)와 **"대조군 대비 차이는 이만큼이다"**(계산)까지다. 그 이상은 가설이며, 가설이라고 쓴다.

## 4.5 성과 주장 게이트

개선을 주장하려면 **네 조건을 모두** 만족해야 한다. 하나라도 빠지면 *"값이 이렇게 변했다"* 까지만 쓰고 *"우리가 개선했다"* 는 쓰지 않는다.

| # | 조건 | 없으면 |
|---|---|---|
| 1 | **개입 시점이 사전에 기록**되어 있다 | 사후에 시점을 고르면 원하는 결과가 나온다 |
| 2 | **대조군이 같은 시점에 같은 방법으로** 측정되었다 | 모델 드리프트와 구분되지 않는다 |
| 3 | 보고값이 **(조치 단위 변화) − (대조군 평균 변화)** 다 | 절대값 상승은 성과가 아니다 |
| 4 | `method_version` 이 전후 동일하거나 **환산 계수**를 거쳤다 | 다른 측정을 비교한 것이 된다 |

계산 결과가 **음수면 "개선되지 않았다"고 쓴다.** 이 게이트는 `EVIDENCE.md` C-4의 반증 조건과 같은 것을 본다.

## 5. 공표 전 체크리스트

숫자를 담은 문장을 대외로 내기 전에 전부 통과해야 한다.

- [ ] **사전 등록이 측정 전에 공개되었는가** (ADR-0009)
- [ ] **주장이 `EVIDENCE.md` 에 등록되어 있고 상태가 그대로 표기되었는가**
- [ ] **개선을 주장한다면 성과 주장 게이트 4조건을 통과했는가** (§4.5)
- [ ] **문항이 강건성 검사를 통과했는가** (§2.0)
- [ ] **평균만 제시하지 않고 Floor를 함께 냈는가** (§3)
- [ ] 분모가 레이어에 맞는가 (§1)
- [ ] 모집단이 명시되었는가, 합산하지 않았는가
- [ ] 측정 일시와 `method_version` 이 함께 있는가
- [ ] 판정이 승격을 거쳤는가 (2주 연속)
- [ ] 4분 판정 네 값을 모두 냈는가
- [ ] 반복 횟수와 구간이 있는가 (비율을 쓴 경우)
- [ ] 개선 주장에 대조군 대비 차이가 있는가
- [ ] 인과를 단정하지 않았는가
- [ ] 사전 통지 기간이 지났는가
- [ ] 해당 기관의 설명 게재 기회가 있었는가

## 6. 한계를 먼저 말한다

발표 자료·리포트·공개 페이지에 **한계를 우리가 먼저 싣는다.**

1. 참여 표본은 모집단을 대표하지 않는다.
2. 1회 관측은 측정이 아니다.
2-1. 문항의 강건성은 우리가 검사한 4개 변형 축 안에서만 보장된다.
2-2. **구성 타당도는 아직 확보되지 않았다** — AI 오답과 실제 주민 피해의 대응은 검증되지 않았다.
3. robots.txt 준수는 크롤러의 자율이며, 선언과 실제 수집은 다르다.
4. AI가 무엇을 근거로 답하는지 우리는 알 수 없다.
5. 판정 불가는 원인을 말하지 않는다.
6. 우리는 방법론의 작성자이자 이 측정으로 사업을 하는 당사자다 (LC-7).

**한계를 먼저 말하는 쪽이 나중에 지적당하는 쪽보다 언제나 강하다.**
