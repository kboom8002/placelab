## 01 · 배경과 문제

### 확인된 사실

- **공공 도메인의 상당수가 AI 수집기에 닫혀 있다.** 2026-09-05 표본 수집(경제자유구역 9곳)에서 정상 판정이 가능한 곳은 3곳뿐이었다. → `K09`
- **제도가 열려 있다.** AI기본법 제16조 우선구매·담당자 면책(2026-07-21), 공공AI법 제정(2026-08-28), 공공부문 AI 영향평가(2027-02-28 예정), 공공데이터 제공 운영실태 평가(기초 226곳 전수).
- **측정 주체가 없다.** 정부·지자체가 AI 응답 품질을 공식 지표로 제도화한 사례는 확인되지 않는다.

### 아직 증명되지 않은 것

> **핵심 미검증 가설**
>
> "AI 응답 부정확이 행정적으로 중요한 문제인가"에 대한 독립 증거가 없다. 주민이 AI에 행정정보를 얼마나 묻는지, 오답으로 실제 피해가 발생했는지에 대한 데이터가 존재하지 않는다.

이 플랫폼의 1차 목적은 상품 판매가 아니라 **이 가설의 검증**이다. 검증에 실패하면 — 즉 측정 결과가 대체로 양호하거나 참여자가 문제의식을 갖지 않으면 — 유료 상품 라인 전체를 재검토해야 한다. **그 판단을 6개월 안에 데이터로 내리는 것이 이 제품의 존재 이유다.**

## 03 · 사용자

| 사용자 | 동기 | 핵심 행동 | 주의 |
|---|---|---|---|
| **담당 공무원** (정보통신·기획·홍보) | 평가 대응 · 개선 근거 확보 | 우리 지자체 조회 → 셀프체크 → 결과 제출 → 개선 후 재측정 | 불리한 결과는 제출하지 않을 수 있다 → 익명 제출 필수 |
| **지방의원 · 보좌진** | 의정 질의 소재 | 우리 지자체 조회 → 비교 → 인용 | 집행부와 대립 구도로 쓸 수 있다. 도구는 중립을 유지 |
| **기자 · 연구자** | 기사 · 연구 소재 | 전국 집계 조회 → 방법론 확인 → 인용 | 순수로 각색될 위험. 인용 가이드를 함께 제공 |
| **주민 · 일반** | 호기심 · 문제 제기 | 우리 동네 조회 | SNS 확산 시 특정 지자체 비난으로 흐를 수 있다 |

> **이해 충돌 설계**
>
> 공무원은 결과가 나쁘게 보이지 않기를 원하고, 의원·기자는 문제가 드러나기를 원한다. 한쪽에 서면 다른 쪽을 잃는다. 해법은 **도구가 판단하지 않고 상태만 표시하는 것** — 등급·순위·평가 문구 없이 `열림/닫힘/무응답` 만 제시하고, 해석은 이용자에게 맡긴다. 그리고 해당 지자체에 **설명 게재권(FR-24)** 을 준다.

## 04 · 제품 구조 — 공개 표면 + 4개 측정 레이어

무엇을 자동화할 수 있고 무엇이 사람을 요구하는가가 측정 스택의 구조를 결정한다. **레이어마다 편향 성격과 과금이 다르다.**

그 위에 측정하지 않는 층이 하나 더 있다.

### Layer 0 · 공개 표면 — 무료 · 측정하지 않음

Layer 1~3의 결과를 **사람이 남에게 보낼 수 있는 형태**로 만든다. 단위별 공유 카드, 지역 페이지, 셀프체크 프롬프트 팩, 인용 가이드, 보도 키트.

- 수집: 없음 / 산출: **프레임** / 과금: 무료 / 성공: **우리가 만든 단어를 남이 쓰는 횟수**
- 설계 기준이 다른 층과 다르다 — Layer 1~3은 **타당도**, Layer 0는 **전달성**.
- **새 사실을 만들지 않는다.** 나르는 모든 숫자는 승격·사전 등록·증거 대장 게이트를 이미 통과한 것이어야 한다.

> 해자의 세 축(시계열·기관 관계·인용 지위) 중 **인용 지위**를 만드는 층이다. 인용 지위는 저절로 생기지 않고 **누가 먼저 이름을 붙였는가**로 결정된다. → [ADR-0010](./adr/0010-diffusion-first.md) · [`K13`](./knowledge/K13-diffusion-track.md)

### Layer 1 · 기술 접근성 — 무료 · 공개

243곳 전 도메인의 수집 허용 규칙·사이트맵·응답 상태를 서버가 주기적으로 자동 점검한다. 로그인 없이 지자체명 검색으로 즉시 조회.

- 수집: 자동 · 전수 / 편향: **없음** / 공개: 전면 / 가치: 언론 · 기준선
- 사람의 판단이 개입하지 않고 전수 수집되므로 **자기선택 편향이 없다.** 이 플랫폼에서 유일하게 *"전국 N곳 중"* 이라고 말할 수 있는 데이터다.

### Layer 2 · 셀프체크 — 무료 · 참여

표준 문항(지명 12 + 무지명 8)을 이용자가 직접 AI에 넣고, 결과를 채점해 제출한다. **자유 질문도 함께 수집한다.**

- 수집: 수동 · 자발 / 편향: 자기선택 / 공개: 집계만 / 가치: 코퍼스 · 리드
- 자발적 참여이므로 편향이 있다. 통계로 쓸 때는 반드시 `참여한 N곳` 으로 한정한다.
- **진짜 산출물은 점수가 아니라 자유 질문 코퍼스다.**

### Layer 3 · 통제 측정 — 유료 SaaS

플랫폼이 API로 직접 측정한다. 동일 조건·반복 실행·모델 버전 기록·구간 추정, 기관 맞춤 문항 등록, 정기 자동 재측정, 리포트 생성.

- 수집: 자동 · 통제 / 편향: 조건 고정 / 공개: 기관 전용 / 가치: 반복 매출
- 조건이 통제되므로 시점 간 비교가 성립한다. 다만 **API 응답은 소비자 앱 응답과 다를 수 있으며** 이 차이를 리포트에 명시한다.

### Layer 4 · 진단 · 정비 — 사람 · 유료

기존 P1~P4 사업. 원인 진단, 소관 부서별 조치 목록, 정본 정비, 주민 교육, 운영·갱신. 플랫폼은 근거 데이터와 재측정 증빙을 공급한다.

- 수집: 사람 / 산출: 조치 · 정본 / 과금: 건당 계약 / 가치: 본 매출
- **플랫폼의 목적지.** Layer 1~3은 여기로 오는 **설득 기제이자 증빙 도구**다.

> **이 구조의 핵심**
>
> **Layer 1이 이 제품의 발명이다.** 이 한 문장이 언론·중앙정부·의회에 그대로 나가고, 나머지 세 레이어는 그 문장이 만든 관심 위에서 작동한다.
>
> 반대로 Layer 2의 점수를 전국 통계처럼 쓰면 방법론 전체가 무너진다. **두 층의 데이터는 절대 섞지 않는다.**
>
> Layer 1은 **두 개의 독립된 전수**를 돌린다 — 자치단체 243곳, 그리고 자체 도메인을 가진 특별구역(A형) 6곳. 두 모집단은 근거 법률도 조직 성격도 달라 **합산하지 않고 병기**한다.

### "특별구역" 확정 — ③ 비자치단체 구역

특별구역은 **자치단체가 아닌 지정 구역**으로 확정한다. 다만 이 확정이 곧바로 측정 단위가 되지는 않는다.

> **구역은 측정할 수 없다. 측정되는 것은 그 구역을 운영하는 주체의 누리집이다.**

Layer 1의 판정 대상인 `robots.txt`·sitemap·TLS는 **도메인 단위로만 존재**한다. 자체 도메인이 없는 구역은 기술적으로 단독 판정이 불가능하며, 이를 무시하고 집계하면 시·도의 값을 구역의 값인 것처럼 보고하게 된다.

| 형 | 정의 | 해당 | 수 | 적용 레이어 | 계약 주체 |
|---|---|---|---|---|---|
| **A형** | 독립 도메인 구역 — 자체 누리집 + 자체 예산·계약 | 인천·부산진해·광양만권·대구경북·전남광주·강원 경제자유구역청 | 6 | **L1~L4 전부** | 해당 경제자유구역청 |
| **B형** | 종속 도메인 구역 — 시·도 도메인 안의 경로/서브도메인 | 경기·충북·울산 경제자유구역 | 3 | L1 **불가** · 페이지 지표만 · L2~L4 가능 | 소관 시·도 |
| **C형** | 누리집 없는 구역 — 중앙 포털 또는 시·도 페이지에만 존재 | 규제자유특구(누적 55 + 광역연계형 2), 기회발전특구(비수도권 14개 시·도) | 57+ | **L2 무지명 질문만** | 소관 시·도 / 중앙부처 |

> **243과 특별구역은 절대 합산하지 않는다.** 보고는 언제나 `자치단체 243곳 중 N곳` / `A형 특별구역 6곳 중 M곳` 으로 병기한다. → `AGENTS.md` INV-1

### A형은 사업적으로 매력적이지만 규제 레버리지가 없다

A형은 존재 이유가 **투자유치와 대외 홍보 그 자체**다. 예산 과목도 정보화가 아니라 투자유치·홍보·마케팅이어서 상대적으로 유연하고, 영·중·일 다국어가 기본 요구이므로 P2 정본의 다국어 항목이 자연히 정당화된다.

반면 **자치단체가 아니어서 합동평가·공공데이터 제공 운영실태 평가의 압력이 미치지 않는다.** 기초 지자체 영업에서 쓰던 "평가에 반영된다"는 논리가 통하지 않으므로, A형에는 **투자유치 성과 논리로만** 접근해야 한다.

| M-1.3 | 메인 페이지 `meta robots` | noindex 있음 / 없음 |
| M-1.4 | 구조화 데이터(JSON-LD) 존재·문법·타입 | 없음 / 문법 오류 / 타입 오표기 / 정상 |
| M-1.5 | TLS 인증서 체인 검증 | 정상 / 실패 |
| M-1.6 | 응답 지연·속도 제한 | 정상 / 지연 / 차단. **2주 연속 동일 결과일 때만 정식 판정으로 승격** |
| M-1.7 | **판정 불가 사유 코드** | `TIMEOUT` / `MALFORMED` / `PARSE_FAIL` / `SHARED_DOMAIN` |

> **M-1 수행 원칙 — 예의 있는 수집**
>
> 공공 서버에 부하를 주지 않는 최소 요청으로 수행한다. 도메인당 주 1회, 요청 간 충분한 간격, 명시적 User-Agent와 연락처 URL 표기, `robots.txt` 가 우리 수집기를 거부하면 **그 사실만 기록하고 더 이상 요청하지 않는다.** 차단을 우회하지 않는다.

### M-2 · 응답 정확도 (Layer 2 · 3)

- **지명 질문 12문항** — 판정은 `정확 / 부분정확 / 부정확 / 부재` 4단계.
- **무지명 질문 8문항** — 판정은 **등장 여부**, 등장 시 **내용 정확도** 2단계.
- **반복** — 무지명은 최소 3회, Layer 3은 문항당 5회 이상. 결과는 점 추정이 아니라 **구간**으로 제시.
- **조건 기록 (필수)** — AI 서비스명, 모델 버전, 측정 일시, 웹 검색 사용 여부, 언어, 계정 개인화 여부.

### M-3 · 명세 버전 관리

문항·판정 기준·반복 횟수는 `method_version` 으로 관리한다. 모든 관측에 버전을 기록하고, **버전이 다른 관측은 기본적으로 비교하지 않는다.**

| 채점자 편차 | ○△✕를 누가 매기느냐에 따라 결과가 달라짐 | ① 판정 기준을 조작적으로 정의해 공개 ② **일부 관측 교차 채점**해 일치도 산출 ③ 일치도 발표 자료에 함께 기재 | FR-8 |
| 조건 불통제 | AI 종류·버전·개인화·검색 사용이 결과를 바꿈 | ① 조건 필수 입력, 없으면 저장 거부 ② 집계는 동일 조건 내에서만 ③ Layer 2·3 데이터 분리 | FR-6 · FR-7 |
| 모델 드리프트 | AI 모델 갱신으로 시점 간 차이가 발생 — 우리 개선인지 모델 변화인지 구분 불가 | ① 모델 버전 기록 ② **대조군 교차 채점**으로 일치도 산출 ③ 일치도를 발표 자료에 함께 기재 | FR-17 · M-2 |

> **대조군 설계 — 가장 중요한 한 가지**
>
> 어떤 단위의 점수가 좋아졌을 때, 그것이 **우리 개선 때문인지 모델이 좋아져서인지** 구분할 방법이 없으면 이 제품의 성과 주장은 전부 무효다. 해법은 **아무 조치도 하지 않은 단위들을 같은 시점에 같은 방법으로 계속 측정하는 것**이다. 그 집단의 평균 변화가 모델 드리프트이고, 개선 폭은 대조군 대비 차이만큼만 보고한다.

### LC-1 재정리 — 착수 게이트에서 운영 원칙으로 강등

당초 이 문서는 AI 출력물 수집의 약관 적합성을 개발 착수의 선결 조건으로 두었다. **이는 과도한 설정이었다.** 수십 명 규모 패널이 각자의 계정에서 실행한 결과를 스스로 제출하는 행위는 자동화된 대량 수집과 성격이 다르다. 공공기관의 대외 정보가 어떻게 응답되는지를 확인해 공표하는 것은 **공적 검증의 영역**이고, 제출물의 실행 주체는 제출자 본인이다. Layer 3의 자동 측정 역시 상업용 API의 정상적 사용 범위 안에서 이뤄진다.

따라서 남는 것은 규범이 아니라 **편집 책임** 하나다 — **AI 출력 원문을 그대로 공개 아카이브로 재배포하지 않는다.** 이유는 약관이 아니라 오답 원문을 우리가 확산시키는 모양을 만들지 않기 위해서다(NG-3과 동일 취지). → `AGENTS.md` INV-6

> 본 항목은 법률 자문이 아니다. 계약 규모가 커지거나 결과 공표가 언론·의회로 확대되는 시점에는 LC-3·LC-4와 함께 변호사 검토를 받는 것이 안전하다.

### LC-7 — 구조적 이해충돌

측정 방법론을 만든 주체가 그 결과를 근거로 컨설팅을 수주하는 구조는, 개별 계약이 정당하더라도 **규모가 커지면 그 자체로 지적된다.** 완화책은 ① 방법론 전면 공개(FR-8), ② 학회·제3자 검증, ③ 측정 사업과 정비 사업의 계약 주체 분리 검토. 셋 중 최소 ①②는 대외 발표 전에 확보한다.
