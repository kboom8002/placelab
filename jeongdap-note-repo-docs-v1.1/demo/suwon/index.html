✓모두의 정답노트지역 문화 · 수원
기관 확인판 (비공개 자료 포함) — 수원시와 소관 기관 확인용 화면이에요. 확인 기간(10월 20일까지)이 지나도 페이지별 사례는 기관이 동의한 경우에만 공개해요.

첫 대상 수원시 · 사전 관측 2026년 10월 5일 · 지역 문화 10개 항목

외국인이 AI에게 수원을 물으면, 근거 후보 다섯 중 하나만 공식 설명이에요

AI는 질문을 받으면 웹을 검색해 후보 문서를 모으고, 그 가운데서 근거를 골라 답해요. 수원 대표 문화 10개를 영어로 검색해 보니 상위 결과 96건 가운데 정부·지자체·재단·공공기관 페이지는 20건(20.8%)이었어요. 한 칸이 검색 결과 하나예요.

항목을 누르면 실제 상위 결과가 순위대로 펼쳐져요. 가운데가 빈 칸은 질문과 관계없는 결과예요. 빨간 점은 지난 회차·옛 명칭·본문 수신 실패 같은 확인 사항이 있는 공식 페이지예요.

공식 설명이 검색 상위에 있는지, 있다면 지금 정보인지로 나눴어요.

같은 항목도 언어가 바뀌면 달라져요

방화수류정을 영어와 한국어로 같은 방식으로 찾아봤어요. 공식 설명은 이미 있는데, 외국어 검색 후보에 오르지 못하는 것이 수원의 가장 큰 과제로 보여요.

공식 페이지의 본문은 기계에 넘어오나요

검색에 올라도 본문이 넘어오지 않으면 AI는 그 페이지를 근거로 쓰기 어려워요. 공식 페이지 6곳에 본문을 요청해 봤어요.

무엇을 봤나

AI 서비스의 실제 답이 아니라, AI가 답을 만들 때 거치는 “검색하는 길”을 봤어요. 영문 질의 10개(항목당 1개)와 국문 비교 질의 1개의 상위 결과 출처를 분류하고, 공식 페이지 6곳의 본문 전달을 확인했어요.

얼마나 믿을 수 있나

2026년 10월 5일 한 번 본 탐색적 관측이에요. 검색 결과는 지역·시점·도구에 따라 달라져서 일반화하지 않아요. 1차 측정(10월 27일–11월 7일)에서 AI 서비스 3곳에 직접 묻고 두 번씩 반복해 확인해요.

출처는 어떻게 나눴나

공식 기관(정부·지자체·재단·공공기관 누리집), 위키·백과, 블로그·여행·예약·리뷰, 언론, 국제기구·학술·기타의 다섯 가지예요.

지키는 원칙

  1. 순위를 만들지 않아요. 지역·기관·AI 회사별 순위나 점수가 없어요.
  2. 기관에 먼저 알려요. 기관을 특정할 수 있는 결과는 비공개로 통지하고 14일 확인 기간을 둬요.
  3. 방법을 먼저 공개해요.
  4. 기관을 탓하지 않아요. 아무도 재지 않았던 영역이에요.
  5. 범위를 지켜요. 정부 입장 영역, 재난·안전 정보, 개별 업소는 재지 않아요.
  6. 원문을 보존해요. 질의와 결과를 기록으로 남겨요.
