# 용어집

| 용어 | 영문·코드 | 정의 |
| --- | --- | --- |
| 정본 | fact | 공식 자료·담당 확인·현장 확인으로 맞다고 확인한 사실. 대상 + 속성 + 정규화 값 + 유효 구간 + 확인 등급 + 근거 |
| 확인 등급 | fact_grade | 후보(시드) → L1 주민 확인 → L2 담당 확인 → L3 공식 고시. 측정 답안지는 L2 이상 |
| 두 시간 | bitemporal | 유효 시간(언제 맞는가)과 기록 시간(언제 알았는가) |
| 상충 | conflict | 출처끼리 값이 달라 보류된 사실. 판정에 쓰지 않음 |
| 예고된 변화 | scheduled | 시작일이 있는 값. 시작일에 자동 발효 |
| 속성 사전 | attributes | 측정 가능한 속성 목록(6영역 42속성 v0.1), 값 형식·변동성·층·코어·위험 |
| 대상 | entity | 시설·관광지·서비스·기관 |
| 혼동 묶음 | confusion_group | 서로 헷갈리기 쉬운 대상 묶음 (예: 천지연폭포·천제연폭포) |
| 명칭 용어집 | entity_names | 대상의 언어별 공식 표기·별칭·옛 표기·흔한 오기 |
| 답안지 | answer_key | 질문마다 정답 값·허용 변형·옛 값·혼동 값·필수 항목 |
| 질문 칸 | slot | A 공통 코어 · B 층별 기본 · C 지역 특화 · D 주민 제안 · E 통제 |
| 카나리 질문 | canary | 변하지 않는 사실. 결과 급변 = 모델 변화 신호 |
| 최근 변경 질문 | recent change | 최근 바뀐 사실(예: 2026년 7월 개편). 신선도 측정 |
| 질문 세트 | question_set | 지역·층별 질문 묶음, 고정(frozen) 후 해시 공개 = 사전 등록 |
| 회차 | round | 측정 1회 (예: 2026-R1 시범 회차) |
| 패널 측정 | panel | 공식 API로 서비스 × 검색 끔/켬 × 반복 측정 |
| 보정 측정 | calibration | 실제 앱 화면 표본 10% 수동 측정 → API–앱 일치도 |
| 시민 신호 | citizen signals | 신고·제안·투표. 지표에 섞지 않음 |
| 판정 라벨 | label | 정확·옛 정보·없는 사실·혼동·모름·판정 불가 (+ 위험 플래그) |
| 분석 단위 | unit | 질문 × 서비스 (반복 평균) |
| AI 정답 지표 | rate | 판정 가능한 단위 중 정확 비율. “API 기반 대리 지표” |
| 신뢰 구간 | CI | 질문 단위 군집 부트스트랩 95% |
| 검색 이득 | search gain | 정답률(검색 켬) − 정답률(검색 끔) |
| 언어 격차 | language gap | 정답률(한국어) − 정답률(해당 언어), 같은 사실 질문끼리 |
| 명칭 정답률 | name rate | AI가 대상을 바르게 알아본 비율 |
| κ | kappa | 판정 일치도(Cohen). 목표 0.8 |
| 엠바고 | embargo | 판정 완료 후 발행 전 비공개 상태 |
| 발표 전 사실 확인 | fact check / objection | 엠바고 중 지자체가 근거와 의견을 내는 절차 |
| 정정 | correction | 오답 처리 단위. 분류: 정본·수집·출처·다국어 문제 |
| 레지스트리 | regions | 행정구역 정본(유효 구간·승계·옛 이름) |
| 승계 | succession | 통합·분리·개명 관계 (예: 광주광역시+전라남도 → 전남광주통합특별시) |
| 에디션 | edition | 지역 브랜드 설정(브랜드명·공동 표기·언어 묶음) |
| 활성 동 | active dong | 계약·주민 참여가 있어 측정하는 읍면동 |
| 동네 정답 지킴이 | — | 동 단위 주민 확인 참여자 |
| 확인단 / 판정단 | crew / rater | 정본 확인 참여자 / 판정 참여자(당사자 판정단 포함) |
| 원어민 검수단 | native_reviewer | 언어별 2인 이상, 현지화·다국어 정본 검수 |
| 언어 시장 패널 | market panel | 해당 언어권 이용자가 많이 쓰는 AI 서비스 (검토) |
| 쉬운 말 | easy mode | 쉬운 문장·큰 글자 모드 |
