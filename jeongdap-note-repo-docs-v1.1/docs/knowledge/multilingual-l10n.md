## 3. AI + 원어민 검수 6단계
| 단계 | 주체 | 내용 | 통과 |
| --- | --- | --- | --- |
| ① 초벌 | AI | 원문·용어집·원칙 → 표현 2개 | — |
| ② 자동 점검 | AI(다른 모델·설정) | 역번역 의미 보존·용어집·글자 혼용·언어권 표현·유도 표현·자연스러움 | 실패 표시 |
| ③ 원어민 1차 | 원어민 | 승인/수정 + 사유 | — |
| ④ 원어민 2차 | 배경이 다른 원어민 | 독립 검수 | 2인 승인 |
| ⑤ 조정 | 운영 + 언어 조정자 | 불일치·의미 오류, 용어집 갱신 | 기록 |
| ⑥ 사전 등록 | 운영 | 세트에 고정 | 2인 승인 100% |

- **AI는 승인 권한 없음.** 글자 혼용 실패가 남으면 “그대로 승인” 불가.
- 수정 사유 분류: 용어집 · 자연스러움 · 지역 표현 · 의미 오류 · 글자 혼용 → 초안 지침·용어집에 반영.
- 같은 흐름을 다국어 정본 문장·방문객 페이지 문장에 적용.

## 4. 검수 지표 목표
원어민 수정률(언어별 공개·감소), 자동 점검 적중률, 2인 일치율 ≥ 85%, 용어집 준수 100%, 10문항·1언어당 30분 이내.

## 5. 교정
용어집 확정 → 다국어 정본(같은 사실 ID) → 방문객 페이지 `/en·/ja·/zh-hant·/zh-hans`(hreflang·JSON-LD) → 언어별 정정(정정 처리함 `type='multilingual'`, `lang`) → 같은 언어 재측정.

## 6. 언어 시장 패널
간체·일본어는 해당 시장 이용자가 많이 쓰는 AI 서비스를 추가 검토(공식 API·약관·데이터 처리 지역). 기본 패널과 분리 보고.
