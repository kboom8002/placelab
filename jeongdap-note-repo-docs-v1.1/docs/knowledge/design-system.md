# 디자인 시스템 — “노트와 펜”

공책 위 잉크로 쓴 질문, **초록 펜으로 고친 정답**. 비난의 빨간 펜이 아니라 함께 고치는 초록 펜. 공공 서비스답게 차분하되 정답 카드는 기억에 남게.

## 2. 타이포그래피
| 요소 | 규칙 |
| --- | --- |
| 본문 | Noto Sans KR 16px / 1.6 (쉬운 말 19px) |
| 제목 | 700, 22·28·36px |
| 숫자 | tabular-nums, 비율 옆 구간·단위 수 |
| 손글씨 | 정답 카드의 “확인된 정답” 한 줄만 (Nanum Pen Script 등), 같은 내용을 일반 글꼴로도 제공 |
| 다국어 | Noto Sans JP / TC / SC 필요 시 로드 |

## 3. 간격·모양
간격 4·8·12·16·24·32, 모서리 8·12·16, 그림자 거의 없음(종이 느낌).
