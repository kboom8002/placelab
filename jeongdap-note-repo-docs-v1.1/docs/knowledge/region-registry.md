## 4. 규칙
- 지역은 유효 구간이 있는 정본. 개편 시 새 행 + 승계, 이전 행은 `valid_to`.
- 옛 이름은 `region_aliases(kind='old_name')`로 검색 가능, 옛 slug는 새 지역으로 영구 리다이렉트.
- 승계된 결과는 “개편 전 구역 기준” 표시.
- 행정구역 변경 자체가 신선도 측정 주제(E칸 최근 변경 질문).
- 가상 지역(`is_virtual`, 예: 한빛군)은 데모·교육 환경만.
