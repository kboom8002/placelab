## 4. 판정 라벨
| 라벨 | 정의 | 쉬운 말 |
| --- | --- | --- |
| 정확 | 확인된 정답과 같아요. | 맞아요. |
| 옛 정보 | 예전에는 맞았지만 지금은 달라요. | 예전 이야기예요. |
| 없는 사실 | 확인된 근거가 없는 내용이에요. | 사실이 아니에요. |
| 혼동 | 다른 곳이나 다른 것과 섞였어요. | 다른 곳과 헷갈렸어요. |
| 모름 | AI가 모른다고 답했어요. | AI가 몰라요. |
| 위험 | 따르면 안전·건강·이동에 문제가 생길 수 있어요. | 조심하세요. |

## 5. 마이크로카피
| 상황 | 문구 |
| --- | --- |
| AI 답 확인 입력 | AI에게 받은 답을 붙여넣어 주세요. 어느 지역 이야기인지도 알려 주세요. |
| 정본 없음 | 이 내용은 아직 확인된 정답이 없어요. 확인단이 살펴볼 수 있게 알려 주세요. |
| 확인 결과 안내 | 시민 확인 결과는 참고용이에요. 공식 정답률은 정해진 질문 세트로 따로 측정해요. |
| 신고 완료 | 고마워요. 확인단이 공식 자료와 맞춰 볼게요. 결과가 나오면 알려 드릴게요. 알려 주신 내용은 정답률 계산에 넣지 않고, 다음 회차 질문과 정본을 고치는 데 써요. |
| 정답 카드 공유 | AI가 다르게 말한 것을 함께 고쳤어요. 확인된 정답을 나눠 주세요. |
| 의견 질문 | 이 질문은 측정하기 어려워요. 의견이나 추천을 묻는 질문은 정답을 정할 수 없어요. “○○ 운영 시간은?”처럼 확인할 수 있는 사실로 바꿔 볼까요? |
| 중복 투표 | 이미 투표했어요 (지역별 1인 1표). |
| 빈 화면 | 아직 고친 이야기가 없어요. 첫 번째 정답을 함께 찾아 주세요. |
| 측정 예정 | {회차}({기간})에서 {n}문항을 측정해요. 질문 세트를 먼저 공개합니다. |
| 엠바고(공개) | 발표 준비 중이에요. 결과는 지자체 사실 확인을 거쳐 공개해요. |
| 지자체 사실 확인 | 발표 전에 결과를 확인해 주세요. 근거와 함께 남긴 의견은 재판정 기록에 함께 남습니다. 판정은 같은 기준으로 다시 이뤄집니다. |
| 정정 배정 | 이 오답은 정본에 없는 정보 때문이에요. 담당 부서를 정해 주시면 기한과 함께 알려 드릴게요. |
| 수료 전 | 첫 미션 전에 30분 교육을 마쳐 주세요. 확인 기준과 근거 찾는 법을 배워요. |
| 미션 완료 | 확인 1건을 마쳤어요. 오늘 활동 시간에 {n}분이 기록됐어요. |
| 글자 혼용 차단 | 자동 점검이 표시한 글자 혼용이 남아 있어요. 수정해서 승인해 주세요. |
| 미성년 | 만 14세 미만은 보호자 동의가 필요해요. 신고와 질문 제안은 함께할 수 있어요. |
| 오류 | 잠시 연결이 끊겼어요. 적어 주신 내용은 그대로 있어요. 다시 보내 볼까요? |
