| H6 | 지명 사다리는 단조적이다 (L1 → L3로 갈수록 공식 첫 인용이 는다) | 탐색 | 단조 의도가 절반 미만 → 문턱 표기 안 쓰고 프로필만 |
| H7 | 외국어 조건에서 지역 문화 항목의 공식 근거율이 한국어보다 낮다 | 탐색 | 영·중·일의 공식 근거율이 한국어와 같거나 높다 |

## 9. 공개 약속과 중단 규칙

### 9.1 공개 약속

- 결과가 어떻든 **H1–H5의 결과를 11월 17일에 공개**한다. 통과하지 못한 가설도 그대로 적는다.
- 측정 단위의 값은 자체 사업 측정으로서 공개 문서만 읽은 결과이므로 기관 동의 절차 없이 집계·밴드로 공개한다. 단위별 원자료는 내부 분석용으로 두고, 2027년 3월 밴드 지도 공개 전까지 이름 단위 값은 공개하지 않는다.
- 재난·안전 결과는 공개하지 않고 해당 기관에만 통보한다.
- 의원실 등 외부 제출 자료에는 “탐색적 0단계 측정”임과 조건을 첫머리에 적는다.
