# 골디락스 측정·공표안 — 최소 비용, 최대 화제성

Oct 8, 2026 · @주인님

전국 243단위에 500문항을 분기마다 9회 묻는 전수 측정은 분기 약 109만 회·$26,700에 사람 판정 100만 건이 따라붙어 불가능하다. 병목은 API가 아니라 **사람 판정**이다. 그래서 자동 판정으로 끝나는 지표(공식 근거율)는 전국을 얼게 훑고, 사람이 봐야 하는 지표(피해 위험)는 좋게 좋은 문항만 보며, 화제성은 ‘매주 한 질문을 전국에 똑같이’ 묻는 값싼 장치로 만든다. 네 층을 합쳤을 때 분기 API 약 $2,000(약 270만 원), 사람 판정 약 5,000건 — 전수의 7%로 전국 지도와 매주 나오는 뉴스를 둘 다 얻는다.

## 1. 문제와 기준선

전수 측정의 병목은 돈이 아니라 사람이다. API는 분기 $26,700으로 비싸지만 이론상 가능하고, 방법론 3.4가 요구하는 “맞음/다름 사람 전수 판정”은 100만 건이라 어떤 인력으로도 불가능하다. 시민 확인단 20–30명과 운영 매니저 1명의 분기 판정 역량은 약 5,000건이다. 설계는 이 5,000건을 어디에 쓸지를 정하는 문제다.

| 항목 | 전수(243 × 500 × 9회) | 감당 가능선 |
| --- | --- | --- |
| API 호출 | 1,093,500회 / 분기 | — |
| API 비용 (회당 $0.0244, 사전 등록안 단가) | $26,700 / 분기 ≈ 3,600만 원 | 분기 $2,000–3,000 (약 300만 원 안) |
| 사람 판정 (맞음/다름, 3.4) | 약 1,000,000건 | 약 5,000건 / 분기 |
| 정답 원장 작성 | 243 × 500 = 121,500행 | 기준 단위 5곳 × 500 + 전국 코어 60 × 243 = 17,000행 (1회 작성, 분기 갱신 10%) |

세 가지를 지키면서 비용을 내려야 한다. ① 전국 밴드 지도는 243단위 모두에 값이 있어야 한다(표본으로는 지도가 안 나온다). ② 공개 지표 둘(공식 근거율·피해 위험 건수)은 유지한다. ③ 사전 등록·고정 패널·동등화는 유지한다. 다만 지표 둘 중 공식 근거율은 출처 도메인만 보면 되므로 **사람 없이 자동**으로 나오고, 피해 위험 건수만 사람이 필요하다. 이 비대칭이 설계의 출발점이다.

## 3. 수렴 — 선택 기준과 버리는 것

&#91;embedded content: 그림 1. 대안 10개의 비용 × 화제·효용 배치 — 위치는 2장 표의 값을 상대 배치한 것\]

선택 기준은 세 개다. 분기 비용이 API $2,000·사람 5,000건 안에 들 것, 243단위 전부에 값이 있어 지도가 나올 것, 그리고 매주 밖으로 낼 이야기가 있을 것.

- **버린다 — 단위를 줄이는 대안(2 표본·3 순환·8 광역·9 수도권).** 지도가 비거나 1년 뒤에야 완성된다. 밴드 지도의 화제성은 “우리 동네도 있다”에서 나오므로 단위 축소는 비용보다 더 큰 것을 잃는다.
- **버린다 — 측정값이 안 되는 대안(5 이벤트·7 크라우드).** 단, 크라우드는 신고판이라는 이름으로 이미 있고, 이벤트는 주간 1문항의 연 1회 확대판으로 흡수한다.
- **합친다 — 6 + 10 + 4.** 셋은 서로 다른 일을 한다. 10은 지도를 만들고(자동), 4는 사람을 고위험에만 쓰고(지표 둘째), 6은 매주 뉴스를 만든다. 1(전수 축소)은 10의 1단계와 같으므로 흡수된다.
- **거기에 기준 단위 5곳을 덫붙인다.** 500문항 전체·9회는 이 다섯 곳에서만 한다. 사전 등록 가설 검증과 정비 효과 실험은 여기서 나오고, 전국 지도는 이 다섯 곳에서 검증된 코어 60문항으로만 그린다.

## 4. 골디락스 설계 — 네 층

분기 API 약 $2,000, 사람 판정 약 5,000건. 전수 대비 API 7%, 사람 0.5%로 전국 지도·지표 둘·주간 뉴스·사전 등록 실험을 모두 얻는다.

| 층 | 무엇을 | 규모 | 분기 API | 사람 판정 | 내는 것 |
| --- | --- | --- | --- | --- | --- |
| A 전국 스캔 | 243단위 × 코어 60문항(고위험 30 + 고빈도 30) × 3회, 자동 판정만 | 43,740회 | $1,070 | 0 (시민 확인단 무작위 2% = 870건은 품질 감시용) | **공식 근거율** → 전국 밴드 지도(226 기초 + 17 광역) |
| B 피해 위험 정밀 | A의 답변 중 고위험 15문항의 최빈 답을 사람이 판정. 하위 밴드·경계 근처 약 120단위 우선 | API 추가 0 | $0 | 1,800–3,600 | **피해 위험 건수** → 유형별 집계(기관 무순위) |
| C 주간 1문항 전국 | 매주 한 질문을 243단위에 3회. 신고판 수요·시의성에서 선정 | 729회/주, 9,480회/분기 | $230 | 243/주 최빈 답만 = 3,160/분기 | **이번 주 질문 지도** — 매주 발표 |

| 합계 |  | 약 78,000회 | **약 $1,900 (≈ 260만 원)** | **약 5,000–6,800** |  |

**사람 판정 예산이 넘칠 때의 우선순위.** C(주간 질문, 뉴스의 신뢰) → B 하위 밴드·경계(지표 둘째) → D(실험) 순으로 채우고, D는 사람 판정을 표본 30%로 줄여도 가설 검증에 충분하다(효과 추정은 정비 사건이 있는 문항만 전수).

**코어 60은 어떻게 고르나.** 파일럿 5곳에서 다섯 기준을 통과한 문항 중 ① 고위험 30: 피해 위험 등급 ‘고’이고 5곳 모두 공식 문서가 있는 문항(공급 공백이 없어야 전국 비교가 성립) ② 고빈도 30: 신고판·민원 분류에서 질문 빈도가 높고 지자체마다 답이 다른 문항. 12개 생활 영역에 최소 3문항씩 배분. 코어 60은 분기 교체 10% 상한과 앵커 30을 둔다(11.3과 같은 규칙, 숫자만 작다).

**243단위 원장은 어떻게 만드나.** 전국 스캔은 공식 근거율만 내므로 원장이 필요 없다 — 공식 도메인 목록(243개, 1회 작성)만 있으면 된다. B의 고위험 15문항만 243단위 원장이 필요하고(3,645행), 이것은 사람 판정 시점에 판정자가 공식 페이지를 열면서 함께 적는다(판정 = 원장 작성). 주간 질문도 같다.

## 5. 공표안 — 매주 하나, 분기 하나, 해마다 하나

화제성은 빈도에서 나온다. 분기 지도 하나로는 연 4번 기사가 나고 끝나지만, 매주 같은 시간에 “이번 주 질문”이 나가면 52번의 이야기가 쌓이고 신고판이 매주 유입을 받는다. 모든 공개물은 방법론 5.3 규약(밴드 내 무순위·점수 없음·재난 비공개·정비 영업 금지)을 따른다.

| --- | --- | --- | --- | --- |
| 매주 화요 | **이번 주 질문 지도** — “‘대형폐기물 수수료 얼마’에 AI가 공식 근거로 답한 지자체 243곳 중 ○○곳” + 전국 지도(밴드 3색) + 틀린 답의 유형 3가지(기관 익명) | 질문이 생활에 바짝 붙어 공유된다. 신고판에서 다음 주 질문을 투표로 고른다 | 시민: 내 동네 답이 맞는지 확인. 지자체: 어느 문서가 읽히지 않는지 | C |

**첫 공개 일정.** 주간 질문은 2026년 11월 처음 두 회차를 기준 단위 5곳 결과로 시험 발행하고, 12월부터 243곳. 전국 지도는 2027년 3월 첫 공개(방법론 D94 그대로) — 12월·1월 두 번의 전국 스캔을 비공개로 돌려 경계를 고정한 뒤에 공개한다.

**가장 큰 화제성은 지도가 아니라 질문이다.** “전국 AI 정답률 지도”는 한 번 보고 끝나지만, “우리 구 보건소 전화번호를 AI가 틀린다”는 사람마다 자기 질문을 만든다. 주간 질문은 신고판에서 오고, 신고판은 주간 질문 때문에 찾아온다 — 이 순환이 비용 $230짜리다.

## 6. 바뀜는 것과 위험

**방법론 v1.0에서 바뀜는 것.** 3.1 고정 패널 550은 기준 단위에만 적용하고, 전국에는 코어 60을 적용한다(“전국 코어” 층 신설). 3.4 사람 전수 판정은 B·C·D에만 적용하고 A는 자동 판정 + 2% 표본으로 바꾼다. 5.2 공개물에 ‘주간 질문 지도’가 추가된다. 11.3 패널 구조는 유지하되 전국 코어 60의 교체·앵커 규칙을 덧붙인다.

**파일럿과 사전 등록안에서 바뀜는 것.** 파일럿의 산출물에 ‘전국 코어 60 선별’이 추가된다(4장 기준). 사전 등록안 10/20 공개본에 코어 60의 해시와 전국 스캔 일정(12월·1월 비공개 2회 → 2027년 3월 공개)을 함께 등록한다. 1차 측정 일정(10/27–29, 11/3–5, 11/17 집계)은 그대로다.

**위험.**

- 코어 60으로 그린 지도가 “지자체 전체”를 대표하는 것처럼 읽힐 수 있다 → 지도 제목에 “생활 행정 핵심 60문항 기준”을 박고, 문항 목록을 지도 옆에 공개한다.
- 자동 판정(공식 도메인)이 틀릴 수 있다 — 위탁 사이트(시설공단·보건소 별도 도메인)을 공식에서 빠뜨릴 수 있다 → 공식 도메인 목록에 산하 기관 도메인을 포함하고, 2% 표본에서 발견되면 목록을 고친다. 구로구 원장에서 이미 나온 예: guro.nid.or.kr(치매안심센터), cartax.seoul.go.kr(주정차).
- 주간 질문이 특정 지자체를 웃음거리로 만들 수 있다 → 틀린 답은 유형으로만 보여 주고 기관 이름은 지도 밴드에만 남긴다. 재난 문항은 주간 질문에서 제외.
- 사람 판정 5,000건도 시민 확인단이 유지되어야 가능하다 → 주간 질문의 판정을 확인단 공개 활동으로 만들어(이름 공개 선택) 참여 동기를 준다.
- 단가 $0.0244는 가정이다 → 파일럿 첫날 100회 실측로 전 표를 갱신한다. 단가가 2배가 되어도 분기 $4,000으로 감당 범위다.
