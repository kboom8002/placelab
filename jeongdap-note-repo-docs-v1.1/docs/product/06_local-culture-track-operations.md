# 모두의 정답노트 「지역 문화 트랙」 운영안 — 측정·신고와 이해충돌 관리

Oct 5, 2026 · ㈜디지털미디어네트워크 · v0.1 · 내부용 · 관련: 「K-컴처 AI 정본 정비 시범사업」 예산안 기획 보고(2026. 10.)

## 1. 요약

> **모두의 정답노트에 “지역 문화 트랙”을 열어, 지역 문화에 대한 AI 답의 근거를 같은 방법으로 재고(측정판) 시민·재단의 신고를 받아(신고판) 소관 기관에 먼저 알린다.** 「K-컬처 AI 정본 정비 시범사업」 예산 반영의 근거를 넓히는 민간 공익 측정이며, 시범사업의 공식 측정이 아니다. 회사는 측정 쪽(A)에 서고, 그에 따라 정비 영업을 제한한다.

| 항목 | 내용 |
| --- | --- |
| 측정판 | 17개 시·도 × 대표 지역 문화 10개 + 국가 대표 20개 = 약 190개 항목. 1차(11월 초)는 한·영, 에이전트 3곳, 검색 연동 켬, 2회 반복으로 시작 |
| 분류 | 근거 유형(공식 문서 / 민간 매체·블로그·여행 사이트 / 답 없음) + 원인 네 유형(검색 후보 없음 / 본문 미전달 / 다른 문서가 근거 / 공식 문서 없음) — **기획서와 같은 분류** |
| 신고판 | “AI가 우리 지역 문화를 틀리게 말해요” — 재현 확인 → 소관 기관 비공개 통지(14일 확인) → 집계만 공개 |
| 원칙 | 순위표 없음 · 기관 사전 통지 · 방법 사전 공개 · 범위 제외(정부 입장 영역·재난·안전·개별 업소) · 망신 주지 않음 · 응답 원문 보존 · 이해관계 공시 |
| 의원실 | 11월 예비심사용 1차 집계 요약(기관 특정 없음), 부대의견 문구 지원 |
| 이해충돌 (A) | 공식 측정 공개경쟁에는 참여 가능(ENK 확인 후). 선정 6개 지역과 측정 기간의 지역문화재단에는 정비 상품을 팔지 않음. 관문 위원회 불참. 자사 매체는 “관계 매체”로 표시 |

**결정 요청:** ① 지역 문화 트랙 운영 ② 이해충돌 관리 규칙(8장) ③ 10월 20일 캠페인에 트랙 공개 ④ ENK 확인 의뢰(예산 기획 관여와 입찰 참가)

## 2. 목적과 성격

### 2.1 목적

1. **근거 보강:** 기획서의 필요성 근거(2026년 10월 2일 탐색적 관측 1회)를 같은 방법의 반복 측정으로 넓힌다.
2. **수요 확인:** 시민·여행자·재단 실무자가 실제로 겪는 문제를 신고로 모은다 — 재단이 공모에 참여할 동기.
3. **방법의 공개 시연:** “재고 → 알리고 → 고칠 목록을 만든다”는 방식이 실제로 작동함을 보여 준다.

### 2.2 성격 — 무엇이고 무엇이 아닌가

| 이다 | 아니다 |
| --- | --- |
| 민간 공익 측정·시민 참여 신고 | 시범사업의 공식 측정 (공식 측정은 공개경쟁 발주) |
| 탐색적 측정 — 조건을 밝히고 일반화하지 않음 | 정부 기관 평가·순위 |
| 소관 기관에 먼저 알리는 협력 도구 | 고발·망신 캠페인 |
| 같은 분류(근거 유형·원인 네 유형) | AI 회사 규제·검색 순위 조작 |

## 3. 운영 원칙

기획서의 원칙을 그대로 따른다. 정답노트가 먼저 이 원칙을 깨면 시범사업의 협력 기반이 무너진다.

| # | 원칙 | 정답노트에서 |
| --- | --- | --- |
| 1 | 순위표 없음 | 시·도·기관·AI 회사별 순위 공개 금지. 분포와 원인만 |
| 2 | 기관 사전 통지 | 기관을 특정할 수 있는 결과는 소관 기관에 비공개로 먼저 알리고 14일 확인 기간 뒤 공개 |
| 3 | 방법 사전 공개 | 항목 선정 기준·질문·에이전트·언어·조건·반복 횟수를 측정 전에 공개 |
| 4 | 범위 제외 | 정부 입장 영역(독도·동해 등), 재난·안전 정보, 개별 업소 — 측정·신고 대상에서 제외 |
| 5 | 망신 주지 않음 | “아무도 재지 않았던 영역” — 고칠 수 있는 사례를 함께 보여 줌 |
| 6 | 원문 보존 | AI 응답은 요약하지 않고 원문 그대로 보존 |
| 7 | 사이트 예절 | 본문 전달 확인은 robots 규칙 준수, 페이지당 단일 요청 |
| 8 | 이해관계 공시 | 운영사의 관련 사업 참여 가능성을 트랙 첫 화면에 공시 |

## 4. 측정판 설계

### 4.1 항목

- **지역 항목:** 17개 시·도 × 10개 = 170개 — 공개 목록에서 고른다(로컬 100, 국가·시도 지정 유산, 대표 축제). 선정 기준을 공개한다.
- **국가 대표 항목:** 20개 — 온돌·한복·한산모시짜기 등 기획서의 관측 항목을 포함한다.
- **합계:** 약 190개.

### 4.2 질문과 조건

| 항목 | 1차 (2026년 11월 초) | 2차 이후 |
| --- | --- | --- |
| 질문 | 항목당 1문항 (정체성: “○○이 무엇인가”) | +1문항 (유래·시기) |
| 언어 | 한국어·영어 | 중국어(간·번)·일본어 + 1 (기획서의 5개 언어와 맞춤) |
| 에이전트 | 3곳 (검색 연동 켬) | 4–5곳, 검색 연동 켬·끔 |
| 반복 | 2회 | 3회 |
| 지역 조건 | 미국·한국 결과 | 동일 |
| 호출 규모 | 약 2,280회 (190 × 2 언어 × 3곳 × 2회) | 단계적으로 확대 |

### 4.3 판정

| 근거 유형 | 정의 |
| --- | --- |
| 공식 문서 | 정부·공공기관·지역문화재단 등 책임 기관의 설명이 근거 출처에 포함 |
| 민간 매체·블로그·여행 사이트 | 공식 문서 없이 다른 문서만 근거 |
| 답 없음 | “정보를 찾지 못했다” 등 |
| (표시) 사실 확인 | 공식 문서와 대조 가능한 사실(지정 연도 등)만 일치·불일치 표시 |

### 4.4 원인 진단 (공식 문서가 근거가 아닐 때)

1. **검색 후보 없음** — 검색 상위에 공식 문서가 없음
2. **본문 미전달** — 공식 문서는 있으나 기계에 본문이 넘어오지 않음 (단일 요청으로 확인)
3. **다른 문서가 근거** — 공식 문서가 읽히는데도 다른 문서가 선택됨
4. **공식 문서 없음** — 해당 언어의 공식 설명 자체가 없음

### 4.5 산출

- **집계:** 근거 유형 분포, 원인 네 유형 분포 (언어·에이전트별). 시·도별 순위는 없다.
- **사례:** 고칠 수 있는 사례(예: 같은 기관 안에서 페이지마다 다른 상태) — 소관 기관 확인 뒤 공개한다.
- **기관용 비공개 목록:** 항목별 상태와 원인 — “고칠 목록 후보”로 소관 기관에만 전달한다.
- **측정 조건 기록:** 일시, 에이전트, 언어, 지역, 응답 원문.

**자사 매체 표시:** 근거 출처에 LOCALOG 등 운영사 관계 매체가 나오면 “관계 매체”로 표시하고, 판정이나 사례에서 우대하지 않는다.

### 5.2 처리

1. **접수:** 범위 제외 항목(정부 입장 영역·재난·안전·개별 업소)은 접수 단계에서 안내하고 종료한다.
2. **재현 확인:** 확인 데스크가 같은 질문을 같은 조건으로 다시 묻는다. 재현되지 않으면 “재현 안 됨”으로 기록한다.
3. **원인 분류:** 네 유형 가운데 하나로 분류한다.
4. **소관 기관 통지:** 비공개로 알리고 14일 확인 기간을 둔다.
5. **회신 기록:** 고칠 목록 반영, 이견, 무응답을 기록한다.
6. **공개:** 집계만 공개한다. 사례는 기관이 동의한 경우에만 공개한다.

### 5.3 개인정보

연락처는 선택 항목이고, 결과 안내 뒤 6개월 안에 지운다. 신고 내용에 들어 있는 개인정보는 가린 뒤 보관한다.

## 8. 이해충돌 관리 규칙 (측정 쪽 선택)

회사는 **측정 쪽**에 선다. 기획서는 측정 주체와 정비 주체를 나누고, 문서를 고치는 쪽이 효과를 스스로 재지 않는다고 정했다. 우리는 측정(정답노트·MAPS)과 정비(AIHompy·AEOPress·CANON)를 모두 가진 회사라서 아래 규칙을 스스로 둔다.

### 8.1 규칙

| # | 규칙 | 기간 |
| --- | --- | --- |
| 1 | 시범사업 공식 측정에는 공개경쟁으로 참여할 수 있다 — 단, ENK 확인(8.3) 뒤에만 | 공모 시 |
| 2 | **선정 6개 지역**의 시·도·광역문화재단·컨소시엄 기관에 정비 상품·서비스(AIHompy·AEOPress·CANON 정비·문서 개선 컨설팅)를 판매하거나 무상 제공하지 않는다 | 사업 기간 + 이후 1년 |
| 3 | 측정을 수행하는 동안 **그 밖의 지역문화재단**에도 정비 영업을 하지 않는다 — 2028년 확대 대상이 될 수 있다 | 측정 수행 기간 |
| 4 | 관문 위원회·심사위원회에 참여하지 않는다 | 상시 |
| 5 | 측정 데이터(기관별 상태·원인)를 영업에 쓰지 않는다 — 측정팀 접근 권한 분리 | 상시 |
| 6 | 자사 관계 매체(LOCALOG 등)가 근거 출처에 나오면 “관계 매체”로 표시하고 우대하지 않는다 | 상시 |
| 7 | 정답노트 트랙 첫 화면과 모든 대외 자료에 이해관계를 공시한다 | 상시 |

### 8.2 다른 사업과의 관계

| 사업 | 영향 |
| --- | --- |
| K-뷰티·피부과·숙박 등 상업 고객 | 영향 없음 — 지역 문화 공식 문서 정비가 아니다 |
| 제주 (특별자치도가 선정될 수 있음) | 제주 브랜드·숙박·상품 사업은 유지. 제주도·제주 문화재단 대상 문화 콘텐츠 정비 영업은 하지 않는다 |
| 서귀포신문·충북일보 등 지역 언론 제휴 | 유지 — 언론 편집 기사는 공식 문서 정비가 아니다. 단, 언론 기사를 “공식 문서”로 분류하지 않는다 |
| LOCALOG 지역 매거진 | 민간 매체로 유지, 측정에서는 관계 매체 표시 |

### 8.3 ENK 확인 사항

1. 예산 기획 자료 작성에 관여한 회사가 공개경쟁 측정 용역에 참여할 때의 제한 여부 — 제안요청서 작성 관여자의 입찰 참가 제한 등
2. 민간 공익 측정 결과를 국회에 제공할 때의 표시·책임
3. 신고판 운영의 개인정보·명예훼손 위험
4. 공공기관 사이트 본문 전달 확인의 적법 범위(robots 규칙·요청 빈도)

**ENK가 측정 용역 참여를 제한해야 한다고 판단하면:** 정답노트 트랙은 공익 활동(C)으로 유지하고, 공식 측정 입찰은 하지 않는다.
