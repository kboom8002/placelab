# 지역 문화 AI 답 상태 — 민간 공익 측정 계획 (참고자료)

Oct 5, 2026 · 보고처: ○○○ 의원실(문화체육관광위원회) · 작성: ㈜디지털미디어네트워크(모두의 정답노트)

## 요지

> **「K-컬처 AI 정본 정비 시범사업」 기획의 필요성 근거(2026. 10. 2. 탐색적 관측 1회)를 넓히기 위해, 민간 공익 플랫폼 “모두의 정답노트”가 지역 문화에 대한 AI 답의 근거를 같은 분류로 측정하고 시민 신고를 받습니다.** 시범사업의 공식 측정이 아니며, 기관 평가·순위를 만들지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 17개 시·도 × 대표 지역 문화 10개 + 국가 대표 20개 = 약 190개 항목 |
| 1차 측정 | 2026. 10. 27. \~ 11. 7. — 한국어·영어, AI 서비스 3곳(검색 연동), 2회 반복 |
| 분류 | 기획서와 같은 분류 — 근거 유형(공식 문서 / 민간 문서 / 답 없음)과 원인 네 유형 |
| 제공 | 11월 중순, 문체위 예비심사용 1차 집계 요약 (기관을 특정하지 않음) |
| 성격 | 민간 공익 측정·탐색적 — 조건을 밝히고 일반화하지 않음 |

## 1. 무엇을 재나

- **질문:** 외국인과 국민이 AI에게 지역 문화를 물을 때, 답의 근거로 정부·지역의 공식 설명이 쓰이는가?
- **항목:** 공개 목록(로컬 100, 국가·시도 지정 유산, 대표 축제)에서 시·도별 10개, 국가 대표 20개(기획서 관측 항목 포함)를 고르고, 선정 기준을 공개합니다.
- **신고:** 시민·여행자·재단 실무자가 “AI가 우리 지역 문화를 틀리게 말한다”고 신고하면 재현을 확인한 뒤 소관 기관에 비공개로 알립니다.

## 2. 어떻게 재나

| 단계 | 내용 |
| --- | --- |
| 묻기 | 항목마다 같은 질문을 같은 조건(서비스·언어·검색 연동·지역)으로 묻고, 응답 원문을 그대로 보존 |
| 근거 판정 | 근거 출처가 ① 공식 문서 ② 민간 매체·블로그·여행 사이트 ③ 답 없음 가운데 무엇인지 |
| 원인 진단 | 공식 문서가 근거가 아닐 때 ① 검색 후보에 없음 ② 본문이 기계에 전달되지 않음(단일 요청·robots 준수) ③ 다른 문서가 근거로 쓰임 ④ 공식 문서 자체가 없음 |
| 범위 제외 | 정부 입장 영역(독도·동해 등), 재난·안전 정보, 개별 업소 |

1차 측정 규모는 약 2,280회 질의(190개 항목 × 2개 언어 × 3개 서비스 × 2회)입니다. 2차부터 기획서와 같은 5개 언어와 검색 연동 켬·끔으로 넓힙니다.

## 3. 지키는 원칙

기획서의 원칙을 그대로 따릅니다.

1. **순위표를 만들지 않습니다** — 시·도·기관·AI 회사별 순위나 점수 없이 분포와 원인만 공개합니다.
2. **소관 기관에 먼저 알립니다** — 기관을 특정할 수 있는 결과는 비공개로 통지하고 14일 확인 기간을 둡니다.
3. **방법을 먼저 공개합니다** — 항목 기준·질문·조건을 측정 전에 공개합니다(10월 20일).
4. **기관을 탓하지 않습니다** — 개별 기관의 소홀이 아니라 아무도 재지 않았던 영역이며, 같은 기관 안에서도 페이지마다 상태가 달라 고칠 수 있다는 점을 함께 보여 줍니다.
5. **일반화하지 않습니다** — 결과는 측정 조건과 함께만 인용합니다.

## 5. 이해관계 공시

- 이 측정은 민간 공익 측정(탐색적)이며, 시범사업의 공식 측정이 아닙니다. 공식 측정은 기획서대로 공개경쟁으로 발주되는 별도 기관이 맡습니다.
- 운영사 ㈜디지털미디어네트워크는 AI 답 측정 기술을 보유하고 있으며, **향후 공개경쟁 측정 용역에 참여할 수 있습니다**(관련 법령 검토 후).
- 측정과 정비를 분리하는 기획서 원칙에 따라, 운영사는 **선정 지역의 문서 정비 사업에 참여하지 않으며** 관문 위원회·심사위원회에도 참여하지 않습니다.
- 측정 결과에 운영사 관계 매체가 근거로 나오면 “관계 매체”로 표시하고 우대하지 않습니다.
